# Data Model: Full System Specification

## Entities

-   **Chapter**: Represents a single textbook topic with content, goals, learning outcomes, diagrams, labs, quiz style, and RAG metadata.
    -   Attributes: `id`, `title`, `content_markdown`, `goals`, `learning_outcomes`, `diagram_references`, `lab_references`, `quiz_style`, `rag_metadata_schema`.
    -   Relationships: Has many `Document Chunk`s.

-   **User Profile**: Contains information for personalizing content and tracking progress, including language preferences.
    -   Attributes: `id`, `username`, `email`, `language_preference` (e.g., 'en', 'ur'), `learning_progress` (e.g., map of chapter IDs to completion status).

-   **AI Query**: Represents a user's question to the AI, potentially linked to selected text within a chapter.
    -   Attributes: `id`, `user_id`, `chapter_id` (optional), `selected_text` (optional), `query_text`, `response_text`, `timestamp`.
    -   Relationships: Belongs to `User Profile`.

-   **Quiz**: A set of multiple-choice questions for a specific chapter, generated by `quiz_agent`.
    -   Attributes: `id`, `chapter_id`, `question_text`, `options` (list of strings), `correct_answer_index`, `user_attempt` (optional).
    -   Relationships: Belongs to `Chapter`.

-   **Lab**: A hands-on task for specific chapters (4-11), managed by `lab_agent`.
    -   Attributes: `id`, `chapter_id`, `title`, `description_markdown`, `tasks` (list of strings), `solution_template` (optional), `user_submission` (optional), `feedback` (optional).
    -   Relationships: Belongs to `Chapter`.

-   **Embedding**: Vector representation of text chunks, stored in Qdrant.
    -   Attributes: `id`, `vector_data`, `document_chunk_id`.
    -   Relationships: Belongs to `Document Chunk`.

-   **Document Chunk**: A segment of a chapter's content with associated metadata, used for RAG.
    -   Attributes: `id`, `chapter_id`, `text_content`, `start_line`, `end_line`, `metadata` (including: `topic`, `section_title`, `sub_section`, `learning_outcome_id`, `difficulty_level`, `diagram_present`, `lab_reference_id`, `quiz_question_type`, `keywords`).
    -   Relationships: Belongs to `Chapter`, has one `Embedding`.
