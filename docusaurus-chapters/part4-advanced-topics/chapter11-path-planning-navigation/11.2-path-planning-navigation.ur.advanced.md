# Path Planning & Navigation (English Advanced Version)

## Chapter Overview

Path planning and navigation represent a sophisticated mathematical framework grounded in differential geometry, optimal control theory, and stochastic processes for enabling autonomous robotic systems to efficiently navigate complex environments. Advanced path planning encompasses geometric and topological approaches including configuration space analysis, motion manifolds, and variational optimization methods. Navigation systems implement Kalman filtering, particle filtering, and Bayesian state estimation for localization, and integrate multiple sensor modalities through sensor fusion. The field integrates differential equations, functional analysis, and optimization theory to solve complex path planning and navigation problems.

### Mathematical Foundations

The path planning problem can be formulated as an optimal control problem in configuration space:

min_τ ∫_0^T L(τ(t), τ̇(t), t) dt

Subject to:
- ġ(τ) = 0 (holonomic constraints)
- ġ(τ, τ̇) = 0 (non-holonomic constraints)  
- τ(0) = τ_start
- τ(T) = τ_goal
- ||τ(t) - τ_obstacle|| ≥ r_collision ∀ t ∈ [0,T]

Where τ(t) is the configuration trajectory, L is the Lagrangian (cost function), and r_collision is the collision margin.

### Configuration Space Formalization

For an n-DOF robot, the configuration space C ⊂ R^n (or SE(3) for floating base) is:
- **Free space**: C_free = C \ C_obstacle
- **Obstacle space**: C_obstacle = {τ ∈ C | robot(τ) ∩ obstacle ≠ ∅}

The topology of C_free determines the existence of collision-free paths between configurations, analyzed through homotopy groups and fundamental groups in algebraic topology.

## Advanced Motion Planning Algorithms

### Rapidly-Exploring Random Trees (RRT*) - Asymptotic Optimality Analysis

RRT* extends RRT with asymptotic optimality guarantees by using optimal rewiring:

**Optimality Principle**: Every subpath of an optimal path is optimal.

**RRT* Algorithm**:
```
1. Initialize tree T with root τ_start
2. FOR k = 1 to ∞:
   a. Sample random configuration τ_rand
   b. Find nearest node τ_near in T using distance metric d
   c. Extend from τ_near toward τ_rand to get τ_new
   d. IF τ_new is collision-free:
      i. Determine neighbors within radius r_k = γ (log k / k)^(1/n)
      ii. Rewire neighborhood to improve path costs
      iii. Add τ_new to tree with parent minimizing path cost
3. RETURN best path found
```

**Asymptotic Optimality**: As k → ∞, RRT* converges to optimal solution with probability 1.

**Radius Selection**: 
r_k = γ (log k / k)^(1/n) where γ > (µ(C_free) (1 + 1/n) / ζ(n))^(1/n)

Where µ(C_free) is measure of free space and ζ(n) is volume of n-dimensional unit ball.

```python
import numpy as np
import heapq
from collections import defaultdict

class RRTStar:
    def __init__(self, start, goal, bounds, obstacles, step_size=0.1, gamma=32.0, max_iter=10000):
        self.start = np.array(start)
        self.goal = np.array(goal) 
        self.bounds = bounds  # [[min_x, max_x], [min_y, max_y], ...]
        self.obstacles = obstacles
        self.step_size = step_size
        self.gamma = gamma  # Optimal radius constant
        self.max_iter = max_iter
        
        # Tree representation
        self.vertices = [self.start]
        self.edges = defaultdict(list)  # vertex -> [(neighbor, cost)]
        self.costs = {tuple(self.start): 0}  # cost from start
        self.parents = {tuple(self.start): None}
        
    def distance(self, q1, q2):
        """Euclidean distance between configurations"""
        return np.linalg.norm(np.array(q1) - np.array(q2))
    
    def sample_free_space(self):
        """Sample configuration in free space"""
        while True:
            # Sample random point in bounds
            q_rand = np.array([np.random.uniform(bound[0], bound[1]) 
                              for bound in self.bounds])
            
            # Check collision
            if not self.is_in_collision(q_rand):
                return q_rand
    
    def nearest_vertex(self, q):
        """Find nearest vertex in tree to q"""
        distances = [self.distance(q, v) for v in self.vertices]
        min_idx = np.argmin(distances)
        return self.vertices[min_idx]
    
    def steer(self, q_from, q_to):
        """Steer from q_from toward q_to"""
        direction = np.array(q_to) - np.array(q_from)
        distance = np.linalg.norm(direction)
        
        if distance <= self.step_size:
            return q_to
        else:
            direction = direction / distance
            q_new = q_from + self.step_size * direction
            return q_new
    
    def is_in_collision(self, q):
        """Check if configuration q collides with obstacles"""
        for obs in self.obstacles:
            if obs.contains(q):
                return True
        return False
    
    def near_vertices(self, q_new):
        """Find near vertices within adaptive radius"""
        n = len(self.vertices)
        if n == 0:
            return []
        
        # Adaptive radius based on theoretical bounds
        volume_free = self.compute_free_volume()
        ball_volume = np.pi**(self.dimensions/2) / math.gamma(self.dimensions/2 + 1)
        radius = self.gamma * (np.log(n) / (n * ball_volume))**(1.0/self.dimensions)
        
        near = []
        for v in self.vertices:
            if self.distance(q_new, v) <= radius:
                near.append(v)
        return near
    
    def compute_free_volume(self):
        """Estimate free space volume"""
        total_volume = 1.0
        for bound in self.bounds:
            total_volume *= (bound[1] - bound[0])
        
        # Subtract estimated obstacle volume
        obstacle_volume = sum(obs.volume() for obs in self.obstacles)
        return max(total_volume - obstacle_volume, 0.1 * total_volume)
    
    def plan(self):
        """Execute RRT* planning"""
        best_cost = float('inf')
        solution_path = None
        
        for k in range(self.max_iter):
            # Sample random configuration
            q_rand = self.sample_free_space()
            
            # Find nearest vertex
            q_near = self.nearest_vertex(q_rand)
            
            # Steer toward random configuration
            q_new = self.steer(q_near, q_rand)
            
            if not self.is_in_collision(q_new):
                # Find near vertices
                near_vertices = self.near_vertices(q_new)
                
                # Choose parent to minimize cost
                min_parent = q_near
                min_cost = self.costs[tuple(q_near)] + self.distance(q_near, q_new)
                
                for q_neighbor in near_vertices:
                    candidate_cost = self.costs[tuple(q_neighbor)] + self.distance(q_neighbor, q_new)
                    if candidate_cost < min_cost and not self.line_collision(q_neighbor, q_new):
                        min_cost = candidate_cost
                        min_parent = q_neighbor
                
                # Add new vertex to tree
                self.vertices.append(q_new)
                self.costs[tuple(q_new)] = min_cost
                self.parents[tuple(q_new)] = tuple(min_parent)
                
                # Update edges
                self.edges[tuple(min_parent)].append((tuple(q_new), self.distance(min_parent, q_new)))
                
                # Rewire near vertices if cheaper path found
                for q_neighbor in near_vertices:
                    if tuple(q_neighbor) != tuple(min_parent):  # Skip parent
                        candidate_cost = min_cost + self.distance(q_new, q_neighbor)
                        if (candidate_cost < self.costs[tuple(q_neighbor)] and
                            not self.line_collision(q_new, q_neighbor)):
                            # Update parent of neighbor
                            old_parent = self.parents[tuple(q_neighbor)]
                            if old_parent:
                                # Remove old edge
                                self.edges[old_parent] = [
                                    (nbr, cost) for nbr, cost in self.edges[old_parent]
                                    if nbr != tuple(q_neighbor)
                                ]
                            
                            # Add new parent relationship
                            self.parents[tuple(q_neighbor)] = tuple(q_new)
                            self.costs[tuple(q_neighbor)] = candidate_cost
                            self.edges[tuple(q_new)].append(
                                (tuple(q_neighbor), self.distance(q_new, q_neighbor))
                            )
                
                # Check if goal is reached
                if self.distance(q_new, self.goal) < self.step_size:
                    if min_cost < best_cost:
                        best_cost = min_cost
                        solution_path = self.extract_path(tuple(q_new))
        
        return solution_path, best_cost
    
    def extract_path(self, goal_vertex):
        """Extract path from goal to start using parent pointers"""
        path = [self.goal]
        current = goal_vertex
        
        while current != tuple(self.start):
            parent = self.parents[current]
            if parent is None:
                return None  # No path found
            path.append(parent)
            current = parent
        
        path.reverse()
        return path
```

### Probabilistic Roadmap (PRM*) - Asymptotic Optimality

PRM* extends PRM with asymptotic optimality:

**PRM* Algorithm**:
1. Sample n configurations in C_free using informed sampling
2. Connect each configuration to r_n nearest neighbors using collision checking
3. IF collision-free, add edge with cost = geodesic distance
4. Compute shortest path using Dijkstra's algorithm
5. As n → ∞, path converges to optimal with probability 1

**Connectivity Radius**: r_n = β ((log n / n)^(1/d)) for asymptotic completeness and optimality.

N_samples ∝ (R/ε)^d

Where R is the configuration space extent and ε is the desired resolution.

## Optimal Control Theory in Path Planning

### Continuous-Time Optimal Control

The fundamental optimal control problem for path planning:

min_u ∫_0^T L(x(t), u(t), t) dt + Φ(x(T))

Subject to: ẋ(t) = f(x(t), u(t), t), x(0) = x₀

**Hamilton-Jacobi-Bellman Equation**:
-∂V/∂t = min_u [L(x,u,t) + ∇V·f(x,u,t)]

Where V(x,t) is the optimal cost-to-go function.

### Model Predictive Path-Integrated Control (MPPI)

**Stochastic Optimal Control Formulation**:
min_π E_π[∫_0^T L(x_t, u_t) dt + φ(x_T) | x_0]

**MPPI Control Law**:
u_{t|t} = (Σ_{i=1}^N ω_i^t û_{t|t}^i) / (Σ_{i=1}^N ω_i^t)

Where:
ω_i^t = exp(-(1/λ)[S(x_{0:T}^i) - φ̄_t])
S(x_{0:T}^i) = ∫_0^T l(x_s^i, u_s^i) ds + φ(x_T^i)
φ̄_t = min_i S(x_{t:T}^i)

```python
import torch
import torch.nn as nn

class ModelPredictivePathIntegral:
    def __init__(self, dynamics_model, cost_function, num_samples=1000, 
                 noise_sigma=0.1, lambda_param=1.0):
        self.dynamics = dynamics_model
        self.cost_fn = cost_function
        self.N = num_samples
        self.noise_sigma = noise_sigma
        self.lambda_param = lambda_param
    
    def compute_control(self, state, horizon=20):
        """Compute optimal control using MPPI"""
        # Sample control sequences
        noise_sequences = torch.randn(
            self.N, horizon, self.dynamics.control_dim
        ) * self.noise_sigma
        
        # Initialize control sequence from previous
        nominal_controls = torch.zeros(horizon, self.dynamics.control_dim)
        
        total_costs = torch.zeros(self.N)
        trajectories = []
        
        for i in range(self.N):
            # Perturb nominal control
            perturbed_controls = nominal_controls + noise_sequences[i]
            
            # Simulate trajectory
            current_state = state.clone()
            trajectory_cost = 0
            trajectory = [current_state.clone()]
            
            for t in range(horizon):
                # Apply control and step dynamics
                next_state = self.dynamics.step(current_state, perturbed_controls[t])
                cost = self.cost_fn(current_state, perturbed_controls[t])
                
                trajectory_cost += cost
                current_state = next_state
                trajectory.append(next_state.clone())
            
            # Add terminal cost
            terminal_cost = self.cost_fn(current_state, torch.zeros_like(current_state))
            trajectory_cost += terminal_cost
            
            total_costs[i] = trajectory_cost
            trajectories.append(trajectory)
        
        # Compute importance weights
        min_cost = torch.min(total_costs)
        weights = torch.exp(-1.0/self.lambda_param * (total_costs - min_cost))
        
        # Compute weighted average control
        weighted_controls = torch.zeros_like(nominal_controls)
        for i in range(self.N):
            weighted_controls += weights[i] * perturbed_controls[i]
        
        optimal_control = weighted_controls / torch.sum(weights)
        return optimal_control[0]  # Return first control in sequence
```

## Kinodynamic Planning

Kinodynamic planning considers both kinematic and dynamic constraints:

**Problem Formulation**:
min_τ,u ∫_0^T L(τ, τ̇, τ̈, u, t) dt

Subject to:
- τ̈ = f(τ, τ̇, u) (dynamic equations of motion)
- g(τ, τ̇, u) ≤ 0 (inequality constraints)
- τ(0) = τ_start, τ(T) = τ_goal
- τ̇(0) = τ̇_start, τ̇(T) = τ̇_goal

### Minimum Snap Trajectory Generation

For quadrotors and other dynamic platforms, minimum snap trajectories ensure smooth motion:

**Objective**: min ∫_0^T (d⁴x/dt⁴)² dt

This results in a polynomial trajectory with continuous derivatives up to order 3.

```python
class MinimumSnapTrajectory:
    def __init__(self, order=7, constraints=None):
        self.order = order  # Polynomial order (7th order for minimum snap)
        self.constraints = constraints or {}
    
    def generate_trajectory(self, start_state, goal_state, duration):
        """
        Generate minimum snap trajectory
        start_state = [position, velocity, acceleration, jerk]
        goal_state = [position, velocity, acceleration, jerk]
        """
        # Boundary conditions: position, velocity, acceleration, jerk at start/end
        boundary_conditions = self.formulate_boundary_conditions(
            start_state, goal_state, duration
        )
        
        # Cost function: minimize integral of squared snap
        Q = self.formulate_cost_matrix(duration)
        
        # Solve QP: min 0.5 * coeff^T * Q * coeff
        # subject to A * coeff = b (boundary conditions)
        coeffs = self.solve_qp(Q, boundary_conditions)
        
        return coeffs
    
    def formulate_boundary_conditions(self, start_state, goal_state, T):
        """Formulate boundary conditions matrix"""
        # For 7th order polynomial: x(t) = Σ a_i * t^i
        # Constraints: x(0), ẋ(0), ẍ(0), x(4)(0), x(T), ẋ(T), ẍ(T), x(4)(T)
        A = np.zeros((8, 8))  # 8 constraints for 8 coefficients
        b = np.zeros(8)
        
        # At t=0 (start)
        A[0, :] = [1, 0, 0, 0, 0, 0, 0, 0]  # x(0)
        A[1, :] = [0, 1, 0, 0, 0, 0, 0, 0]  # ẋ(0)
        A[2, :] = [0, 0, 2, 0, 0, 0, 0, 0]  # ẍ(0)
        A[3, :] = [0, 0, 0, 6, 0, 0, 0, 0]  # x(3)(0) (jerk)
        
        # At t=T (goal)
        powers_of_T = [T**i for i in range(8)]
        factorial_factors = [np.math.factorial(i) if i >= 2 else 1 for i in range(8)]
        
        A[4, :] = powers_of_T  # x(T)
        A[5, :] = [i * T**(i-1) if i > 0 else 0 for i in range(8)]  # ẋ(T)
        A[6, :] = [i * (i-1) * T**(i-2) if i >= 2 else 0 for i in range(8)]  # ẍ(T)
        A[7, :] = [i * (i-1) * (i-2) * T**(i-3) if i >= 3 else 0 for i in range(8)]  # x(3)(T) (jerk)
        
        # Boundary values
        b[0] = start_state[0]  # Position
        b[1] = start_state[1]  # Velocity
        b[2] = start_state[2]  # Acceleration
        b[3] = start_state[3]  # Jerk
        b[4] = goal_state[0]   # Position
        b[5] = goal_state[1]   # Velocity
        b[6] = goal_state[2]   # Acceleration
        b[7] = goal_state[3]   # Jerk
        
        return A, b
    
    def formulate_cost_matrix(self, T):
        """Formulate cost matrix for minimum snap"""
        # Cost = ∫(d⁴x/dt⁴)² dt = coeff^T * Q * coeff
        Q = np.zeros((8, 8))
        
        for i in range(4, 8):  # Only terms where 4th derivative is non-zero
            for j in range(4, 8):
                if i >= 4 and j >= 4:
                    # 4th derivative of t^i is (i!/(i-4)!) * t^(i-4)
                    # So integral from 0 to T of product is factor * T^(i+j-7) / (i+j-7)
                    factorial_i = np.math.factorial(i) / np.math.factorial(i-4)
                    factorial_j = np.math.factorial(j) / np.math.factorial(j-4)
                    
                    if i + j - 7 > 0:
                        Q[i, j] = (factorial_i * factorial_j * T**(i+j-7)) / (i+j-7)
                    else:  # Handle case where integral is ln(T) or other special functions
                        Q[i, j] = factorial_i * factorial_j
        
        return Q
```

## Multi-Modal Path Planning

### Belief Space Planning

In partially observable environments, track belief over states:

**Belief Update**:
b'(s') = η * P(o|s') * Σ_s P(s'|s,a) * b(s)

**POMCP (Partially Observable Monte Carlo Planning)**:
- Monte Carlo tree search in belief space
- Particle filter representation of beliefs
- Upper Confidence bounds for belief-dependent rewards

```python
class BeliefSpacePlanner:
    def __init__(self, transition_model, observation_model, reward_model):
        self.transition = transition_model
        self.observation = observation_model
        self.reward = reward_model
        self.particles = []  # Particles representing belief state
        self.weights = []    # Weights for particle filtering
    
    def update_belief(self, action, observation):
        """Update belief using particle filter"""
        # Predict step: propagate particles through dynamics
        new_particles = []
        new_weights = []
        
        for i, (particle, weight) in enumerate(zip(self.particles, self.weights)):
            # Sample next state from transition model
            next_state = self.transition.sample_next_state(particle, action)
            new_particles.append(next_state)
            
            # Update weight based on observation likelihood
            obs_likelihood = self.observation.likelihood(observation, next_state)
            new_weights.append(weight * obs_likelihood)
        
        # Normalize weights
        total_weight = sum(new_weights)
        if total_weight > 0:
            new_weights = [w / total_weight for w in new_weights]
        
        # Resample particles if diversity is too low (effective sample size)
        effective_particles = 1.0 / sum(w**2 for w in new_weights)
        if effective_particles < len(new_particles) * 0.5:
            new_particles, new_weights = self.resample(new_particles, new_weights)
        
        self.particles = new_particles
        self.weights = new_weights
    
    def resample(self, particles, weights):
        """Stratified resampling to avoid particle depletion"""
        n = len(particles)
        new_particles = []
        new_weights = [1.0 / n] * n  # Uniform weights after resampling
        
        # Stratified sampling
        cumulative_weights = np.cumsum(weights)
        u = np.random.uniform(0, 1.0/n)
        
        i, j = 0, 0
        while i < n:
            while u > cumulative_weights[j]:
                j += 1
            new_particles.append(particles[j])
            u += 1.0 / n
            i += 1
        
        return new_particles, new_weights
    
    def plan_in_belief_space(self, horizon=10):
        """Plan sequence of actions in belief space"""
        # Use POMCP or similar algorithm to plan in belief space
        # This is a high-level implementation
        
        best_sequence = None
        best_expected_value = float('-inf')
        
        # Sample random action sequences
        for _ in range(1000):  # Sample 1000 action sequences
            action_sequence = [
                self.sample_random_action() for _ in range(horizon)
            ]
            
            # Evaluate sequence by simulating in belief space
            expected_value = self.evaluate_action_sequence(
                action_sequence, self.particles, self.weights
            )
            
            if expected_value > best_expected_value:
                best_expected_value = expected_value
                best_sequence = action_sequence[:]
        
        return best_sequence[0] if best_sequence else None  # Return first action
```

## Navigation and Localization Integration

### Simultaneous Localization and Mapping (SLAM)

SLAM estimates both robot trajectory and map using only sensor data:

**Mathematical Formulation**:
p(x_{0:t}, m | z_{1:t}, u_{1:t}, c_{1:t})

Where:
- x_{0:t}: Robot trajectory (poses)
- m: Map of environment
- z_{1:t}: Sensor observations
- u_{1:t}: Odometry/control inputs
- c_{1:t}: Data associations

**EKF SLAM Formulation**:
State: X = [x_robot, m₁, m₂, ..., m_n] (robot pose + feature poses)

Process model: X_{t+1} = f(X_t, u_t) + w_t

Observation model: z_t = h(X_t) + v_t

**Graph-based SLAM**:
min_θ Σ_e ρ(d(x_i, x_j, z_e)^T Ω_e d(x_i, x_j, z_e))

Where ρ is a robust kernel function, d is the error function, and Ω is the information matrix.

```python
class GraphSLAM:
    def __init__(self, initial_pose, initial_map_features=None):
        self.graph = nx.Graph()  # Pose graph
        self.odometry_edges = []
        self.constraint_edges = []
        self.information_matrices = {}
        
        # Add initial node
        self.graph.add_node(0, pose=initial_pose)
        self.current_node = 0
    
    def add_odometry_constraint(self, from_node, to_node, relative_pose, information_mat):
        """Add odometry-based constraint between poses"""
        self.graph.add_edge(
            from_node, to_node, 
            type='odometry',
            relative_pose=relative_pose,
            information=information_mat
        )
        self.odometry_edges.append((from_node, to_node))
        self.information_matrices[(from_node, to_node)] = information_mat
    
    def add_landmark_constraint(self, pose_node, landmark_node, observation, information_mat):
        """Add landmark-based constraint"""
        self.graph.add_edge(
            pose_node, landmark_node,
            type='landmark',
            observation=observation,
            information=information_mat
        )
        self.constraint_edges.append((pose_node, landmark_node))
    
    def optimize(self):
        """Optimize pose graph using Gauss-Newton or Levenberg-Marquardt"""
        # Formulate optimization problem: min ||r(x)||²
        # where r(x) is the vector of all constraint residuals
        
        # Jacobian-based optimization
        for iteration in range(100):  # Max iterations
            # Compute residual vector
            r = self.compute_residuals()
            
            # Compute Jacobian matrix
            J = self.compute_jacobian()
            
            # Solve normal equations: J^T * Omega * J * dx = -J^T * r
            H = J.T @ self.information_matrix @ J
            b = -J.T @ self.information_matrix @ r
            
            # Solve for pose updates
            dx = np.linalg.solve(H, b)
            
            # Update poses
            self.update_poses(dx)
            
            # Check for convergence
            if np.linalg.norm(dx) < 1e-6:
                break
    
    def compute_residuals(self):
        """Compute residuals for all constraints"""
        residuals = []
        
        # Odometry residuals
        for edge in self.odometry_edges:
            from_node, to_node = edge
            actual_relative = self.compute_relative_pose(from_node, to_node)
            expected_relative = self.graph.edges[edge]['relative_pose']
            residual = self.pose_difference(expected_relative, actual_relative)
            residuals.extend(residual)
        
        # Landmark residuals
        for edge in self.constraint_edges:
            pose_node, landmark_node = edge
            predicted_obs = self.predict_observation(pose_node, landmark_node)
            actual_obs = self.graph.edges[edge]['observation']
            residual = actual_obs - predicted_obs
            residuals.extend(residual)
        
        return np.array(residuals)
```

### Advanced Localization Techniques

#### Particle Filter (Monte Carlo Localization)

For non-Gaussian uncertainty distributions:

**Algorithm**:
1. Initialize particles with prior distribution
2. For each observation:
   a. Predict particle motion based on control
   b. Update particle weights based on observation likelihood
   c. Resample particles proportional to weights
   d. Estimate state from particle distribution

```python
class ParticleFilter:
    def __init__(self, num_particles=1000, state_dim=3):
        self.num_particles = num_particles
        self.state_dim = state_dim
        self.particles = np.random.randn(num_particles, state_dim) * 0.1  # Initial uncertainty
        self.weights = np.ones(num_particles) / num_particles
    
    def predict(self, control, process_noise_std=0.1):
        """Predict particle motion based on control input"""
        # Add noise to motion model
        noise = np.random.normal(0, process_noise_std, (self.num_particles, self.state_dim))
        self.particles += control + noise
    
    def update(self, observation, observation_model, measurement_noise_std=0.1):
        """Update particle weights based on observation"""
        for i in range(self.num_particles):
            # Compute expected observation for this particle
            expected_obs = observation_model(self.particles[i])
            
            # Compute likelihood of actual observation given expected
            error = observation - expected_obs
            likelihood = self.gaussian_likelihood(error, measurement_noise_std)
            
            # Update weight
            self.weights[i] *= likelihood
        
        # Normalize weights
        if np.sum(self.weights) > 0:
            self.weights /= np.sum(self.weights)
        else:
            # Reset uniform weights if all weights became zero
            self.weights = np.ones(self.num_particles) / self.num_particles
    
    def resample(self):
        """Resample particles based on weights"""
        # Systematic resampling
        indices = self.systematic_resample()
        self.particles = self.particles[indices]
        self.weights = np.ones(self.num_particles) / self.num_particles
    
    def systematic_resample(self):
        """Systematic resampling implementation"""
        positions = (np.arange(self.num_particles) + np.random.random()) / self.num_particles
        cumulative_sum = np.cumsum(self.weights)
        indices = np.zeros(self.num_particles, dtype=int)
        i, j = 0, 0
        while i < self.num_particles:
            while cumulative_sum[j] < positions[i]:
                j += 1
            indices[i] = j
            i += 1
        return indices
    
    def estimate_state(self):
        """Estimate state as weighted average of particles"""
        return np.average(self.particles, axis=0, weights=self.weights)
    
    def gaussian_likelihood(self, error, std):
        """Compute likelihood under Gaussian assumption"""
        variance = std ** 2
        return np.exp(-0.5 * (error**2) / variance) / np.sqrt(2 * np.pi * variance)
```

## Multi-Agent Path Planning

### Conflict-Based Search (CBS)

CBS is a two-level algorithm for multi-agent pathfinding:

**High Level**: Treats conflicts as constraints
**Low Level**: Re-plans individual paths when conflicts arise

**Mathematical Formulation**:
min_Π Σ_{i=1}^N cost(π_i)

Subject to:
- π_i ∈ Π_i^feasible (each path feasible individually)
- (π_i, π_j) ∈ Π_ij^collision_free ∀ i,j (pairwise collision freedom)
- Temporal consistency constraints

```python

    def plan(self):

        root = CBSNode()
        
        # Initialize with individual paths (ignoring other agents)
        for i in range(len(self.agents)):
            path = self.find_individual_path(i, self.starts[i], self.goals[i])

            return root.paths  # Solution found

        open_nodes = [root]
```

### Prioritized Planning

Simple but effective approach for multi-agent coordination:

**Algorithm**:
1. Order agents by priority (e.g., based on arrival time)
2. Plan path for highest priority agent
3. Treat other agents' paths as dynamic obstacles
4. Plan for next agent considering previous paths
5. Continue until all agents planned

**Limitations**: Solution quality depends on ordering, may be suboptimal.

## Navigation System Architecture

### Perception-Action Loop

Advanced navigation systems implement a sophisticated perception-action loop:

**State Estimation Module**:
- Fusion of multiple sensors (LiDAR, cameras, IMU, GPS)
- SLAM or localization algorithms
- Dynamic obstacle tracking

**Path Planning Module**:
- Global planner (A*, RRT, etc.) for long-term routes
- Local planner (DWA, RRT*, etc.) for immediate path planning
- Dynamic replanning when necessary

**Control Module**:
- Trajectory following controllers
- Obstacle avoidance behaviors
- Low-level actuator commands

```python
class HierarchicalNavigator:
```
