# ڈیپ لرننگ (اردو ایڈوانسڈ ورژن)

## باب کا جائزہ

ڈیپ لرننگ اعلیٰ تکنیکی ریاضیاتی فریم ورکس پر مشتمل ہے جو ڈفیوئنئل جیومیٹری، معلوماتی نظریہ، فنکشنل اینالیسز، اور آپٹیمائزیشن تھیوری کو ایک جامع کمپیوٹیشنل ڈھانچہ میں جوڑتا ہے تاکہ متعدد سطحوں کی خود سے سیکھنے والی نمائندگیاں تلاش کی جا سکیں۔ اعلیٰ تکنیکی معماریاں متعدد ریاضیاتی کارروائیوں کو لاگو کرتی ہیں جن میں ٹینسر کنٹریکشنز، گروپ-ایکویورئنٹ ٹرانسفارمیشنز، اور لیٹنٹ ویریبل ماڈلز میں ویریئشنل انفریس شامل ہیں۔ نظریاتی بنیادوں میں یونیورسل ایپروکسیمیشن تھیورم، کنکنٹریشن انیکویلینس، اور ہائیپر بولک ڈیفیوئلی کے ذریعے سافٹ میکسمم اصول شامل ہیں۔

### ریاضیاتی بنیادیں

ڈیپ نیورل نیٹ ورک کا عام ڈھانچہ درج ذیل ہے:

f(x; θ) = σ_L(W_L σ_{L-1}(W_{L-1} ... σ_1(W_1 x + b_1) ... + b_{L-1}) + b_L)

جہاں σ_i غیر لکیری ایکٹیویشن فنکشن ہے اور θ = {W_i, b_i} تمام نیٹ ورک کے پیرامیٹرز کی نمائندگی کرتا ہے۔

**یونیورسل ایپروکسیمیشن تھیورم**:
Lipschitz-مسل اور کمپیکٹلی سپورٹڈ فنکشن f کے لیے، کوئی 2 لیئر نیٹ ورک F وجود رکھتا ہے جو ہر ε > 0 کے لیے ||f - F||_∞ < ε کو مطمئن کرے:

F(x) = Σ_{i=1}^N c_i σ(w_i^T x + b_i)

جہاں σ ایک غیر لکیری ایکٹیویشن فنکشن ہے، w_i, b_i نیٹ ورک کے پیرامیٹرز ہیں، اور c_i آؤٹ پٹ کے وزن ہیں۔

**آپٹیمائزیشن ڈھانچہ**:

Empirical Risk Minimization (ERM) کا مسئلہ درج ذیل شکل میں ہے:

min_θ (1/n) Σ_{i=1}^n L(f_θ(x_i), y_i) + λ/2 ||θ||²₂

جہاں L نقصان کا فنکشن ہے، f_θ ماڈل ہے، اور λ ریگولرائزیشن کا پیرامیٹر ہے۔

### ڈیفیوئنیل جیومیٹری کی بنیاد

نیورل نیٹ ورکس ہائیرآرکیکل منیفولڈز کی نمائندگی کرتے ہیں جہاں ہر لیئر خود سے سیکھنے والی کوآرڈینیٹ سسٹم کو ایڈجسٹ کرتا ہے:

**منیفولڈ ہائیپوتھیسز**: اہم ڈیٹا کی خصوصیات کم بعدی منیفولڈز پر موجود ہوتی ہیں

**ریمنانیان گیومیٹری میں،** فنکشن f کے لیے، گریڈیئن کو اس طرح تعریف کیا جاتا ہے:

grad f = g^{ij} ∂f/∂x^i ∂/∂x^j

جہاں g^{ij} متعد میٹرک ٹینسر کا معاکس ہے۔

## اعلیٰ تکنیکی آرکیٹیکچر

### کنولوشنل نیورل نیٹ ورکس (CNNs) - نظریاتی تجزیات

CNNs گروپ تھیوری اور ہارمونک اینالیسز کے مطابق کام کرتے ہیں:

**گروپ کوواریئنس**: کنولوشن آپریشنز گروپ ایکشن کے تحت کوواریئنٹ ہوتے ہیں:

f(g·x) = (ρ(g) * f)(x)

جہاں ρ گروپ ایکشن ہے اور ρ(g) اس کا ریPRESENTATION ہے۔

**گروپ ایکویورئنٹ نیٹ ورکس**: ہر لیئر گروپ ٹرانسفارمیشنز کے تحت ایکویورئنٹ ہوتا ہے:

Φ(g·x) = ρ(g)·Φ(x)

جہاں Φ نیٹ ورک فنکشن ہے، g گروپ عناصر ہے، اور ρ(g) ہدف سپیس میں ریPRESENTATION ہے۔

### ResNet - ریاضیاتی تجزیہ

ResNets تبدیلی کو سنبھالتے ہیں جو گہرائی کو ممکن بناتا ہے:

y = F(x, {W_i}) + x

ResNet بلاک میں، جیکوبین کا مسئلہ ہے:

∂y/∂x = ∂F/∂x + I

اگر ||∂F/∂x|| < 1، تو گریڈیئن کا نورم 1 سے کم ہے، جو وینشینگ گریڈیئن کو روکتا ہے۔

```python
import torch
import torch.nn as nn

class GroupEquiVariantCNN(nn.Module):
    def __init__(self, input_channels, output_channels, group_size):
        super(GroupEquiVariantCNN, self).__init__()
        
        # 90-degree rotation and reflection گروپ
        self.group_size = group_size
        
        # گروپ کے ذریعے کنولوشنز
        self.group_convs = nn.ModuleList([
            nn.Conv2d(input_channels, output_channels // group_size, 
                     kernel_size=3, padding=1, bias=False)
            for _ in range(group_size)
        ])
        
        # گروپ کے ذریعے گروپ ایکشنز کے لیے ویٹ سلیکشن میکنزم
        self.group_transformer = GroupActionTransformer()
    
    def forward(self, x):
        group_outputs = []
        
        for i, conv_layer in enumerate(self.group_convs):
            # ہر گروپ عنصر کے لیے مختلف کنولوشن
            transformed_x = self.apply_group_action(x, i)
            conv_output = conv_layer(transformed_x)
            group_outputs.append(conv_output)
        
        # گروپ کے ذریعے آؤٹ پٹ کو ضم کریں
        combined_output = self.combine_group_outputs(group_outputs)
        
        return combined_output
    
    def apply_group_action(self, x, group_element_index):
        """Apply group transformation to input"""
        # 90-degree rotations and reflections
        if group_element_index == 0:
            return x  # Identity
        elif group_element_index == 1:
            return torch.rot90(x, 1, [2, 3])  # 90° rotation
        elif group_element_index == 2:
            return torch.rot90(x, 2, [2, 3])  # 180° rotation
        elif group_element_index == 3:
            return torch.rot90(x, 3, [2, 3])  # 270° rotation
        # Add reflections for larger groups
```

### ڈینس نیٹ ورکس - ریاضیاتی تجزیہ

DenseNets میں، ہر لیئر اس کے سبھی بعد والے لیئرز سے مربوط ہوتا ہے:

x_l = H_l([x_0, x_1, ..., x_{l-1}])

جہاں [·] کنکیٹینیشن کو ظاہر کرتا ہے اور H_l ایک کمپوزیٹ فنکشن ہے:

H_l = BN ∘ ReLU ∘ Conv(1×1) ∘ BN ∘ ReLU ∘ Conv(3×3)

#### توجہ والے میکنزمز - معلوماتی تھیوری کی بنیاد

**scaled dot-product attention**:

Attention(Q, K, V) = softmax(QK^T / √d_k)V

**ریاضیاتی تجزیہ**:
- Q، K، V سوال، کلید، اور قدر میٹرکسز کی نمائندگی کرتے ہیں
- d_k کیو کے بعد کا سائز ہے
- softmax امکانات کی تقسیم پیدا کرتا ہے

**میوزیکل انفارمیشن**:

I(X;Y) = Σ_x Σ_y P(x,y) log(P(x,y)/(P(x)P(y)))

توجہ والے میکنزمز میوزیکل انفارمیشن کو بڑھاتے ہیں تاکہ ماڈل مفید ان پٹس پر توجہ مرکوز کر سکے۔

### ٹرانسفارمر آرکیٹیکچر - کیلکولس کی بنیاد

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads, dropout=0.1):
        super(MultiHeadAttention, self).__init__()
        assert d_model % num_heads == 0
        
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads  # Head dimension
        self.dropout = nn.Dropout(dropout)
        
        # لیئرز برائے Q، K، V
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def scaled_dot_product_attention(self, Q, K, V, mask=None):
        """
        Scaled dot-product attention mechanism
        """
        # QK^T compute attention scores
        scores = torch.matmul(Q, K.transpose(-2, -1))  # [batch, heads, seq_len, seq_len]
        scores = scores / math.sqrt(self.d_k)
        
        if mask is not None:
            scores.masked_fill_(mask == 0, -1e9)  # Apply mask (set masked positions to large negative value)
        
        # Apply softmax to get attention weights
        attention_weights = F.softmax(scores, dim=-1)
        attention_weights = self.dropout(attention_weights)
        
        # Multiply weights with values
        output = torch.matmul(attention_weights, V)  # [batch, heads, seq_len, d_v]
        return output, attention_weights
    
    def forward(self, query, key, value, mask=None):
        batch_size = query.size(0)
        
        # Linear projections
        Q = self.W_q(query)  # [batch, seq_len, d_model]
        K = self.W_k(key)
        V = self.W_v(value)
        
        # Reshape for multi-head attention
        Q = Q.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)  # [batch, heads, seq_len, d_k]
        K = K.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        
        # Apply scaled dot-product attention
        attention_output, attention_weights = self.scaled_dot_product_attention(Q, K, V, mask)
        
        # Reshape back to original dimensions
        attention_output = attention_output.transpose(1, 2).contiguous().view(
            batch_size, -1, self.d_model
        )
        
        # Final linear projection
        output = self.W_o(attention_output)
        
        return output, attention_weights

class TransformerBlock(nn.Module):
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super(TransformerBlock, self).__init__()
        
        # Multi-head self-attention
        self.self_attention = MultiHeadAttention(d_model, num_heads, dropout)
        
        # Feed-forward network
        self.feed_forward = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
        
        # Layer normalization
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        
        # Dropout for regularization
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)
    
    def forward(self, x, mask=None):
        # Self-attention with residual connection
        attn_output, attention_weights = self.self_attention(x, x, x, mask)
        x = self.norm1(x + self.dropout1(attn_output))
        
        # Feed-forward with residual connection
        ff_output = self.feed_forward(x)
        x = self.norm2(x + self.dropout2(ff_output))
        
        return x, attention_weights
```

## اعلیٰ تکنیکی آپٹیمائزیشن

### بیچ نارملائزیشن - ریاضیاتی تجزیہ

Batch normalization نیٹ ورک کے اندر کوواریئٹ شفٹ کو کم کرتا ہے:

**Normalization Formula**:
x̂ = (x - μ_B) / √(σ²_B + ε)

Where μ_B = (1/m) Σ x_i (batch mean)
σ²_B = (1/m) Σ (x_i - μ_B)² (batch variance)

**Gradient Analysis**:
∂L/∂x_i = (1/m√(σ²_B + ε))[m ∂L/∂x̂_i - Σ_j ∂L/∂x̂_j - x̂_i Σ_j x̂_j (∂L/∂x̂_j)]

### گریڈیئنٹ کلپنگ اور نارم مینجمنٹ

```python
class GradientClipping:
    def __init__(self, max_norm=1.0, norm_type=2.0):
        self.max_norm = max_norm
        self.norm_type = float(norm_type)

    def clip_gradients(self, parameters):
        """Clip gradients to prevent gradient explosion"""
        # Compute total gradient norm
        total_norm = 0
        param_count = 0
        for p in parameters:
            if p.grad is not None:
                param_norm = p.grad.data.norm(self.norm_type)
                total_norm += param_norm.item() ** self.norm_type
                param_count += 1
        
        total_norm = total_norm ** (1. / self.norm_type)
        
        # Scale gradients if norm exceeds threshold
        clip_coef = self.max_norm / (total_norm + 1e-6)
        if clip_coef < 1:
            for p in parameters:
                if p.grad is not None:
                    p.grad.data.mul_(clip_coef)
        
        return total_norm

def adaptive_learning_rate_scheduler(optimizer, current_loss, previous_loss):
    """Adjust learning rate based on loss improvement"""
    if current_loss < previous_loss:
        # Reduce learning rate if loss is decreasing
        for param_group in optimizer.param_groups:
            param_group['lr'] *= 0.95
    else:
        # Increase learning rate if loss is increasing
        for param_group in optimizer.param_groups:
            param_group['lr'] *= 1.05
    
    # Ensure learning rate stays within bounds
    for param_group in optimizer.param_groups:
        param_group['lr'] = max(min(param_group['lr'], 1e-2), 1e-6)
```

### ایڈام اور دیگر ایڈاپٹیو آپٹیمائزرز

```python
class AdamOptimizer:
    """
    Adam: A Method for Stochastic Optimization
    """
    def __init__(self, params, lr=1e-3, betas=(0.9, 0.999), eps=1e-8):
        self.params = list(params)
        self.lr = lr
        self.beta1, self.beta2 = betas
        self.eps = eps
        
        # Initialize first and second moment estimates
        self.m = [torch.zeros_like(p) for p in self.params]
        self.v = [torch.zeros_like(p) for p in self.params]
        self.t = 0  # Timestep
    
    def step(self):
        self.t += 1
        beta1, beta2 = self.beta1, self.beta2
        
        # Bias-corrected learning rate
        bias_correction1 = 1 - beta1 ** self.t
        bias_correction2 = 1 - beta2 ** self.t
        step_size = self.lr * math.sqrt(bias_correction2) / bias_correction1
        
        for i, param in enumerate(self.params):
            if param.grad is None:
                continue
            
            grad = param.grad
            
            # Update biased first moment estimate
            self.m[i] = beta1 * self.m[i] + (1 - beta1) * grad
            # Update biased second raw moment estimate
            self.v[i] = beta2 * self.v[i] + (1 - beta2) * grad.pow(2)
            
            # Compute bias-corrected first moment estimate
            m_hat = self.m[i] / bias_correction1
            # Compute bias-corrected second raw moment estimate
            v_hat = self.v[i] / bias_correction2
            
            # Update parameters
            param.data.addcdiv_(-step_size, m_hat, torch.sqrt(v_hat) + self.eps)
```

## ویریئشنل آٹو اینکوڈرز (VAEs) - اعلیٰ تکنیکی تھیوری

VAEs ریاضیاتی طور پر ویریئشنل انفریس کے ذریعے لیٹنٹ ویریبل ماڈلز کو سیکھتے ہیں:

**Evidence Lower Bound (ELBO)**:

L(θ, φ; x) = E_{q_φ(z|x)}[log p_θ(x|z)] - KL[q_φ(z|x) || p(z)]

جہاں:
- E_{q_φ(z|x)}[log p_θ(x|z)] = reconstruction term
- KL[q_φ(z|x) || p(z)] = regularization term

**KL Divergence Term**:

KL(q||p) = ∫ q(z) log(q(z)/p(z)) dz

For Gaussian distributions, KL divergence has a closed form:

KL[N(μ, σ²) || N(0, I)] = -½ Σ(1 + log(σ²) - μ² - σ²)

```python
class VariationalAutoencoder(nn.Module):
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super(VariationalAutoencoder, self).__init__()
        self.latent_dim = latent_dim
        
        # Encoder network
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Separate layers for mean and log variance
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        
        # Decoder network
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid()  # Assuming normalized input
        )
    
    def encode(self, x):
        h = self.encoder(x)
        return self.fc_mu(h), self.fc_logvar(h)
    
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std
    
    def decode(self, z):
        return self.decoder(z)
    
    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

def vae_loss(recon_x, x, mu, logvar, beta=1.0):
    """
    Variational lower bound loss
    """
    # Reconstruction loss (assuming binary cross entropy)
    BCE = F.binary_cross_entropy(
        recon_x.view(-1, recon_x.size(-1)), 
        x.view(-1, x.size(-1)), 
        reduction='sum'
    )
    
    # KL divergence loss between approximate posterior and prior
    KLD = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    
    return BCE + beta * KLD
```

## جنریٹو ایڈورسل نیٹ ورکس (GANs) - گیم تھیوری کی بنیاد

GANs گیم تھیوری میں مین میکس ایڈیویسیریل گیم کے بطور فارمولیٹ کیا جاتا ہے:

min_G max_D V(D, G) = E_{x∼p_data(x)}[log D(x)] + E_{z∼p_z(z)}[log(1 - D(G(z)))]

**Optimal Discriminator**:

D*(x) = p_data(x) / (p_data(x) + p_g(x))

**Global Optimality**:
When D is optimal, the objective becomes:

C(G) = -log(4) + 2 * JS-divergence(p_data || p_g)

Where JS-divergence is the Jensen-Shannon divergence.

### Wasserstein GAN - ارتھا میٹک ٹرانسپورٹ تھیوری

WGANs Earth Mover's distance (Wasserstein-1 metric) کا استعمال کرتا ہے:

W(P_r, P_g) = inf_{γ∈∏(P_r, P_g)} E_{(x,y)∼γ}[||x - y||]

جہاں ∏(P_r, P_g) P_r اور P_g کے ساتھ مارجنلز والے تمام مشترکہ تقسیم کا سیٹ ہے۔

**Kantorovich-Rubinstein Duality**:

W(P_r, P_g) = sup_{||f||_L ≤ 1} E_{x∼P_r}[f(x)] - E_{x∼P_g}[f(x)]

جہاں ||f||_L لیپشیٹز نارم ہے۔

```python
class WassersteinGAN:
    def __init__(self, generator, discriminator, clip_value=0.01):
        self.generator = generator
        self.discriminator = discriminator
        self.clip_value = clip_value
        
        # Optimizers
        self.gen_optimizer = torch.optim.RMSprop(self.generator.parameters(), lr=5e-5)
        self.disc_optimizer = torch.optim.RMSprop(self.discriminator.parameters(), lr=5e-5)
    
    def train_discriminator(self, real_data, fake_data):
        self.disc_optimizer.zero_grad()
        
        # Real data loss
        real_output = self.discriminator(real_data)
        real_loss = -torch.mean(real_output)
        
        # Fake data loss
        fake_output = self.discriminator(fake_data.detach())
        fake_loss = torch.mean(fake_output)
        
        # Total discriminator loss
        disc_loss = real_loss + fake_loss
        
        # Backpropagation
        disc_loss.backward()
        self.disc_optimizer.step()
        
        # Weight clipping to enforce 1-Lipschitz constraint
        for p in self.discriminator.parameters():
            p.data.clamp_(-self.clip_value, self.clip_value)
        
        return disc_loss.item()
    
    def train_generator(self, fake_data):
        self.gen_optimizer.zero_grad()
        
        # Generator loss (negative because we want to maximize discriminator loss on fake data)
        fake_output = self.discriminator(fake_data)
        gen_loss = -torch.mean(fake_output)
        
        # Backpropagation
        gen_loss.backward()
        self.gen_optimizer.step()
        
        return gen_loss.item()
```

## ڈیپ ری انفورسمنٹ لرننگ - ریاضیاتی فارمولیشن

### پالیسی گریڈیئنٹ تھیورم

The policy gradient theorem states:

∇_θ J(π_θ) = E_π_θ[∇_θ log π_θ(s,a) Q^π_θ(s,a)]

Where:
- J(π_θ) is the expected return under policy π_θ
- ∇_θ log π_θ(s,a) is the policy gradient
- Q^π_θ(s,a) is the action-value function

**Proof Outline**:
The theorem is proved using the likelihood ratio trick and properties of Markov chains, showing that the gradient of the expected return equals the expected gradient of the log-policy times the value function.

### ایڈوانسڈ RL الگورتھم

#### Soft Actor-Critic (SAC) - ماکسیمم اینٹروپی RL

SAC maximum entropy RL کے اصولوں پر مبنی ہے:

J(π) = E[Σ_t r(s_t, a_t) + αH(π(·|s_t))]

Where H(π(·|s_t)) = -∫ π(a|s_t) log π(a|s_t) da is the entropy of the policy.

The algorithm simultaneously learns:
- A policy π_θ(a|s)
- Two Q-functions Q_{φ₁}(s,a) and Q_{φ₂}(s,a)  
- A value function V_ψ(s)
- Temperature parameter α

**Loss Functions**:

Critic Loss:
L_φ = E[(Q_φ(s,a) - (r(s,a,s') + γ(V_ψ(s') - α log π_θ(·|s'))))²]

Actor Loss:
L_θ = E[α log π_θ(a|s) - Q_{φ₁}(s, π_θ(s))]

Temperature Loss:
L_α = E[-α(log π_θ(a|s) + H)]

```python
class SoftActorCritic:
    def __init__(self, state_dim, action_dim, hidden_dim=256, alpha=0.2):
        # Policy network
        self.actor = GaussianPolicy(state_dim, action_dim, hidden_dim)
        
        # Two Q-networks for double Q-learning
        self.critic1 = QNetwork(state_dim, action_dim, hidden_dim)
        self.critic2 = QNetwork(state_dim, action_dim, hidden_dim)
        
        # Target networks for stability
        self.critic1_target = copy.deepcopy(self.critic1)
        self.critic2_target = copy.deepcopy(self.critic2)
        
        # Optimizers
        self.actor_optimizer = torch.optim.Adam(self.actor.parameters(), lr=3e-4)
        self.critic_optimizer = torch.optim.Adam(
            list(self.critic1.parameters()) + list(self.critic2.parameters()), 
            lr=3e-4
        )
        
        # Temperature parameter
        self.target_entropy = -torch.prod(torch.Tensor(action_dim)).item()
        self.log_alpha = torch.zeros(1, requires_grad=True)
        self.alpha_optimizer = torch.optim.Adam([self.log_alpha], lr=3e-4)
        self.alpha = alpha

    def train_step(self, replay_buffer, batch_size=256):
        state, action, reward, next_state, done = replay_buffer.sample(batch_size)
        
        # Critic update
        with torch.no_grad():
            next_action, next_log_prob, _ = self.actor.sample(next_state)
            next_q1 = self.critic1_target(next_state, next_action)
            next_q2 = self.critic2_target(next_state, next_action)
            next_v = torch.min(next_q1, next_q2) - self.alpha * next_log_prob
            target_q = reward + (1 - done) * 0.99 * next_v
        
        current_q1 = self.critic1(state, action)
        current_q2 = self.critic2(state, action)
        critic_loss = F.mse_loss(current_q1, target_q) + F.mse_loss(current_q2, target_q)
        
        self.critic_optimizer.zero_grad()
        critic_loss.backward()
        self.critic_optimizer.step()
        
        # Actor update
        pi, log_prob, _ = self.actor.sample(state)
        q1_pi = self.critic1(state, pi)
        q2_pi = self.critic2(state, pi)
        min_q_pi = torch.min(q1_pi, q2_pi)
        
        actor_loss = (self.alpha * log_prob - min_q_pi).mean()
        
        self.actor_optimizer.zero_grad()
        actor_loss.backward()
        self.actor_optimizer.step()
        
        # Alpha update
        alpha_loss = -(self.log_alpha * (log_prob + self.target_entropy).detach()).mean()
        self.alpha_optimizer.zero_grad()
        alpha_loss.backward()
        self.alpha_optimizer.step()
        self.alpha = self.log_alpha.exp()
```

### ملٹی-ایجنٹ RL - گیم تھیوری کی بنیاد

Multi-agent RL گیم تھیوری، نش ایکولبرم، اور کوآپریٹو گیم تھیوری کے تصورات کو اسکیل کرتا ہے۔

**Nash Equilibrium in Multi-Agent Systems**:

For N agents with policies π₁, π₂, ..., πₙ, a Nash equilibrium exists when:
∀i: J(π*_i, π*_{-i}) ≥ J(π_i, π*_{-i})

Where π*_{-i} represents policies of all agents except agent i.

```python
class MultiAgentDDPG:
    def __init__(self, n_agents, state_dims, action_dims, hidden_dim=256):
        self.n_agents = n_agents
        
        # Each agent has its own actor and critic
        self.actors = [Actor(state_dims[i], action_dims[i], hidden_dim) 
                      for i in range(n_agents)]
        self.critics = [Critic(sum(state_dims), sum(action_dims), hidden_dim) 
                       for _ in range(n_agents)]
        
        # Target networks for stability
        self.target_actors = [copy.deepcopy(actor) for actor in self.actors]
        self.target_critics = [copy.deepcopy(critic) for critic in self.critics]
        
        # Optimizers
        self.actor_optimizers = [torch.optim.Adam(
            actor.parameters(), lr=1e-4
        ) for actor in self.actors]
        
        self.critic_optimizers = [torch.optim.Adam(
            critic.parameters(), lr=1e-3
        ) for critic in self.critics]
    
    def centralized_critic_update(self, states, actions, rewards, next_states):
        """
        Centralized training with decentralized execution (CTDE)
        """
        all_states = torch.cat(states, dim=-1)
        all_actions = torch.cat(actions, dim=-1)
        
        for i in range(self.n_agents):
            # Compute target Q-value using target networks
            with torch.no_grad():
                next_actions = []
                for j in range(self.n_agents):
                    next_action = self.target_actors[j](next_states[j])
                    next_actions.append(next_action)
                
                all_next_actions = torch.cat(next_actions, dim=-1)
                all_next_states = torch.cat(next_states, dim=-1)
                
                next_q1 = self.target_critics[i](all_next_states, all_next_actions)
                target_q = rewards[i] + 0.99 * next_q1
            
            # Compute current Q-value
            current_q = self.critics[i](all_states, all_actions)
            
            # Critic loss
            critic_loss = F.mse_loss(current_q, target_q.detach())
            
            # Update critic
            self.critic_optimizers[i].zero_grad()
            critic_loss.backward()
            self.critic_optimizers[i].step()
        
        # Actor update (centralized critic, decentralized actor)
        for i in range(self.n_agents):
            # Get action from current actor
            current_action = self.actors[i](states[i])
            
            # Replace agent i's action in the action list
            all_actions_modified = all_actions.clone()
            start_idx = sum(action_dims[:i])
            end_idx = start_idx + action_dims[i]
            all_actions_modified[:, start_idx:end_idx] = current_action
            
            # Compute Q-value with modified actions
            current_q = self.critics[i](all_states, all_actions_modified)
            
            # Actor loss (maximize Q-value)
            actor_loss = -current_q.mean()
            
            # Update actor
            self.actor_optimizers[i].zero_grad()
            actor_loss.backward()
            self.actor_optimizers[i].step()
```

## ہیرارکیکل RL - تفریقی گیم تھیوری

Option-Critic Architecture:

An "option" is a temporally extended action defined by:
- **Policy**: π_ω(a|s) (within-option policy)
- **Termination Condition**: β(s) (probability of terminating)
- **Initiation Set**: I_ω ⊆ S (states where option can be initiated)

The option-value function:
Q_π_ω(s, ω) = E[Σ_{t=0}^τ γ^t r_t | s_0 = s, ω chosen]

**Option-Critic Algorithm**:

The gradient of option-value function:
∇_θ Q_π_ω(s, ω) = E[Σ_{t=0}^τ ∇_θ log π_ω(a_t|s_t) A_π(s_t, a_t)]

Where A_π is the advantage function.

```python
class OptionCritic(nn.Module):
    def __init__(self, state_dim, action_dim, n_options, hidden_dim=256):
        super(OptionCritic, self).__init__()
        
        # Feature extractor
        self.feature_extractor = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Option policies (one for each option)
        self.option_policies = nn.ModuleList([
            nn.Sequential(
                nn.Linear(hidden_dim + 1, hidden_dim),  # +1 for option identifier
                nn.ReLU(),
                nn.Linear(hidden_dim, action_dim),
                nn.Softmax(dim=-1)
            ) for _ in range(n_options)
        ])
        
        # Option termination functions
        self.termination_nets = nn.ModuleList([
            nn.Sequential(
                nn.Linear(hidden_dim, hidden_dim),
                nn.ReLU(),
                nn.Linear(hidden_dim, 1),
                nn.Sigmoid()  # Probability of termination
            ) for _ in range(n_options)
        ])
        
        # Option-value function
        self.option_q = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, n_options)
        )
    
    def forward(self, state, option):
        features = self.feature_extractor(state)
        
        # Get policy for specific option
        option_id = F.one_hot(option, num_classes=self.n_options).float()
        policy_input = torch.cat([features, option_id], dim=-1)
        action_probs = self.option_policies[option](policy_input)
        
        # Get termination probability for specific option
        termination_prob = self.termination_nets[option](features)
        
        # Get all option Q-values
        option_values = self.option_q(features)
        
        return action_probs, termination_prob, option_values
```

## ڈسٹری بیوشنل RL - اطلاعاتی جیومیٹری

Distributional RL returns کی مکمل تقسیم سیکھتا ہے، فقط م expectations کے بجائے:

The distributional Bellman equation:
Z^π(s,a) =_D R(s,a) + γZ^π(S', A')

Where Z^π(s,a) is the random return and =_D denotes equality in distribution.

Categorical DQN (C51) represents the distribution as:

Z(x,a) ~ Σ_i p_i δ(z_i)

Where δ(z_i) is a Dirac delta function at z_i, and p_i is the probability at atom i.

```python
class CategoricalDQN(nn.Module):
    def __init__(self, state_dim, action_dim, n_atoms=51, v_min=-10.0, v_max=10.0):
        super(CategoricalDQN, self).__init__()
        self.n_atoms = n_atoms
        self.v_min = v_min
        self.v_max = v_max
        self.action_dim = action_dim
        
        # Support for the categorical distribution
        self.register_buffer('support', torch.linspace(v_min, v_max, n_atoms))
        self.delta_z = (v_max - v_min) / (n_atoms - 1)
        
        # Network outputs probability distribution over atoms
        self.network = nn.Sequential(
            nn.Linear(state_dim, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, action_dim * n_atoms),
            nn.Softmax(dim=-1)  # Ensure valid probability distribution
        )
    
    def forward(self, state):
        logits = self.network(state)
        # Reshape to separate actions and atoms
        probs = logits.view(-1, self.action_dim, self.n_atoms)
        return probs
    
    def compute_q_values(self, state):
        """Compute expected Q-values from the distribution"""
        probs = self.forward(state)
        # Expected value: sum of support values weighted by probabilities
        q_values = torch.sum(probs * self.support, dim=2)
        return q_values
    
    def project_distribution(self, next_dists, rewards, dones):
        """Project next-step distributions to current-step support"""
        batch_size = next_dists.size(0)
        
        # Compute projection of next distribution
        rewards = rewards.view(-1, 1, 1)
        dones = dones.view(-1, 1, 1)
        
        # Projection: Tz = R + γ(1-done)z
        Tz = rewards + (1 - dones) * 0.99 * self.support.unsqueeze(0)
        # Clamp to support range
        Tz = Tz.clamp(min=self.v_min, max=self.v_max)
        
        # Compute projection weights
        b = (Tz - self.v_min) / self.delta_z
        l = b.floor().long()
        u = b.ceil().long()
        
        # Create projected distribution
        proj_dist = torch.zeros_like(next_dists)
        offset = torch.linspace(
            0, batch_size * self.n_atoms - self.n_atoms, 
            batch_size
        ).long().unsqueeze(1).expand(batch_size, self.n_atoms)
        
        proj_dist.view(-1).index_add_(0, (l + offset).view(-1), 
                                      (next_dists * (u.float() - b)).view(-1))
        proj_dist.view(-1).index_add_(0, (u + offset).view(-1), 
                                      (next_dists * (b - l.float())).view(-1))
        return proj_dist
```

```python
class SafeRLAgent:
    def __init__(self, policy_network, safety_critic, barrier_function=None):
        self.policy = policy_network
        self.safety_critic = safety_critic
        self.barrier_function = barrier_function  # Control barrier function

    def safe_action_selection(self, state):
        """Select action that satisfies safety constraints"""
        with torch.no_grad():
            # Get policy action
            raw_action = self.policy(state)
            
            # Evaluate safety
            safety_score = self.safety_critic(state, raw_action)
            
            if safety_score >= self.safety_threshold:
                return raw_action
            else:
                # Compute safe fallback action using barrier function
                safe_action = self.compute_safe_action(state, raw_action)
                return safe_action
    
    def compute_safe_action(self, state, unsafe_action):
        """Compute safe action using control barrier functions"""
        if self.barrier_function:
            # Solve optimization problem: minimize ||a - a_unsafe||^2 
            # subject to h(x) ≥ 0 and ∂h/∂x·f(x) + ∂h/∂x·g(x)a ≥ -γh(x)
            
            # This would typically involve solving a quadratic program
            # For simplicity, we'll use a projected gradient approach
            action = unsafe_action.clone().detach().requires_grad_(True)
            
            optimizer = torch.optim.SGD([action], lr=0.01)
            
            for _ in range(10):  # Iterative projection
                barrier_value = self.barrier_function(state, action)
                
                # Constraint: barrier function should be non-negative
                if barrier_value < 0:
                    # Compute gradient of barrier function
                    barrier_gradient = torch.autograd.grad(
                        barrier_value, action, retain_graph=True
                    )[0]
                    
                    # Project action to satisfy constraint
                    action = action + 0.1 * barrier_gradient
                    action = torch.clamp(action, -1, 1)  # Ensure action bounds
                else:
                    break
            
            return action
        else:
            # Fallback: simple clamping
            return torch.clamp(unsafe_action, -0.5, 0.5)
```

```python
class ModelAgnosticMetaLearning:
    def __init__(self, model, meta_lr=1e-3, inner_lr=1e-2):
        self.model = model
        self.meta_optimizer = torch.optim.Adam(model.parameters(), lr=meta_lr)
        self.inner_lr = inner_lr
        self.k = 20  # Number of inner loop updates
    
    def meta_update(self, tasks):
        """Perform one step of meta-update across multiple tasks"""
        meta_loss = 0
        
        for task in tasks:
            # Sample support and query sets
            support_data, query_data = task['support'], task['query']
            
            # Clone model for task-specific adaptation
            adapted_model = copy.deepcopy(self.model)
            
            # Inner loop: adapt to specific task
            for _ in range(self.k):
                support_loss = self.compute_loss(adapted_model, support_data)
                
                # Compute gradients
                grads = torch.autograd.grad(support_loss, adapted_model.parameters())
                
                # Update adapted model parameters
                for param, grad in zip(adapted_model.parameters(), grads):
                    param.data = param.data - self.inner_lr * grad
            
            # Compute meta-loss on query set
            query_loss = self.compute_loss(adapted_model, query_data)
            meta_loss += query_loss
        
        # Update original model with meta-gradient
        self.meta_optimizer.zero_grad()
        meta_loss.backward()
        self.meta_optimizer.step()
        
        return meta_loss.item()
    
    def compute_loss(self, model, data):
        """Compute loss for given model and data"""
        states, actions, rewards = data
        predictions = model(states)
        loss = F.mse_loss(predictions, rewards)
        return loss
```

## ڈیل کی لینئر ایل جبرا - ڈیپ لرننگ کیلئے

### ٹینسرز اور ان کے کنٹریکشنز

Tensor operations in deep learning:

**Tensor Contraction**:
For tensors A ∈ R^(m×n) and B ∈ R^(n×p), their contraction along the shared dimension n yields C ∈ R^(m×p):

C_ij = Σ_k A_ik B_kj

**Higher-Order Contractions**:
For tensors T ∈ R^(d₁×d₂×...×d_n) and S ∈ R^(d₂×d₃×...×d_n×d_{n+1}), the contraction along dimensions d₂ through d_n yields a tensor in R^(d₁×d_{n+1}):

R_i₁,i_{n+1} = Σ_{i₂,i₃,...,i_n} T_i₁,i₂,...,i_n S_i₂,i₃,...,i_n,i_{n+1}

### کنولوشن کے طور پر ٹینسرز

A convolution operation can be viewed as a specific tensor contraction:

For input tensor X ∈ R^(C_in×H×W) and kernel K ∈ R^(C_out×C_in×K_h×K_w), the convolution operation yields output Y ∈ R^(C_out×H'×W'):

Y[c_out, h', w'] = Σ_{c_in,k_h,k_w} X[c_in, h'+k_h, w'+k_w] × K[c_out, c_in, k_h, k_w]

Where h'+k_h and w'+k_w are constrained by padding and stride parameters.

## جدید ترین تکنیکس

### نارملائزیشن فلوز - ڈیفیوئنئل ایکویشن کا استعمال

Normalizing flows transform a simple distribution to a complex one through invertible transformations:

**Change of Variables Formula**:
p_X(x) = p_Z(f⁻¹(x)) |det J_f(f⁻¹(x))|

Where J_f is the Jacobian matrix of transformation f.

**Affine Coupling Layer**:
y₁:d = x₁:d  (unchanged part)
y_{d+1:D} = x_{d+1:D} ⊙ exp(s(x₁:d)) + t(x₁:d) (transformed part)

Where s and t are neural networks (scale and translation functions).

```python
class RealNVP(nn.Module):
    """Real-valued Non-Volume Preserving flow"""
    def __init__(self, dim, hidden_dim=256):
        super(RealNVP, self).__init__()
        
        self.dim = dim
        self.mid_dim = dim // 2
        
        # Scale and translation networks for coupling layers
        self.scale_net1 = nn.Sequential(
            nn.Linear(self.mid_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, dim - self.mid_dim)
        )
        
        self.translate_net1 = nn.Sequential(
            nn.Linear(self.mid_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, dim - self.mid_dim)
        )
        
        self.scale_net2 = nn.Sequential(
            nn.Linear(dim - self.mid_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, self.mid_dim)
        )
        
        self.translate_net2 = nn.Sequential(
            nn.Linear(dim - self.mid_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, self.mid_dim)
        )
    
    def forward(self, x):
        """Forward transformation: x -> z"""
        x1, x2 = x[:, :self.mid_dim], x[:, self.mid_dim:]
        
        # First coupling layer
        s1 = self.scale_net1(x1)
        t1 = self.translate_net1(x1)
        y2 = x2 * torch.exp(s1) + t1
        
        # Second coupling layer
        s2 = self.scale_net2(y2)
        t2 = self.translate_net2(y2)
        y1 = x1 * torch.exp(s2) + t2
        
        return torch.cat([y1, y2], dim=1)
    
    def inverse(self, y):
        """Inverse transformation: z -> x"""
        y1, y2 = y[:, :self.mid_dim], y[:, self.mid_dim:]
        
        # Inverse of second coupling layer
        s2 = self.scale_net2(y2)
        t2 = self.translate_net2(y2)
        x1 = (y1 - t2) * torch.exp(-s2)
        
        # Inverse of first coupling layer
        s1 = self.scale_net1(x1)
        t1 = self.translate_net1(x1)
        x2 = (y2 - t1) * torch.exp(-s1)
        
        return torch.cat([x1, x2], dim=1)
    
    def log_det_jacobian(self, x):
        """Compute log determinant of Jacobian"""
        x1, x2 = x[:, :self.mid_dim], x[:, self.mid_dim:]
        
        s1 = self.scale_net1(x1)
        s2 = self.scale_net2(x2 * torch.exp(s1) + self.translate_net1(x1))
        
        log_det = torch.sum(s1, dim=1) + torch.sum(s2, dim=1)
        return log_det
```

```python
class PACTQuantization(nn.Module):
    """
    PACT: Parameterized Clipping Activation for Quantized Neural Networks
    """
    def __init__(self, bit_width=8, init_alpha=6.0):
        super(PACTQuantization, self).__init__()
        self.bit_width = bit_width
        self.alpha = nn.Parameter(torch.tensor(init_alpha))
        self.register_buffer('delta', torch.tensor(0.0))
        self.register_buffer('zero_point', torch.tensor(0.0))
    
    def forward(self, x):
        # Clamp input to [0, alpha]
        x_clamped = torch.clamp(x, 0, self.alpha.item())

        self.delta = self.alpha / (2**self.bit_width - 1)
        self.zero_point = torch.tensor(0.0)  # For unsigned integers
        
        # Quantize: map to integer range
        x_quantized = torch.round(x_clamped / self.delta)
        
        # Dequantize: map back to floating point
        x_dequantized = x_quantized * self.delta
        
        return x_dequantized
```

**سیمیولیشن کارکردگی**:
- **سیمیولیشن سٹیپس فی سیکنڈ (SPS)**: سیمیولیشن کی رفتار
- **نمونہ کارکردگی**: نیٹ ورک کی کارکردگی کو اصل کے ساتھ موازنہ کریں
- **ذیلی پالیسی کارکردگی**: اس بات کی جانچ کریں کہ نیٹ ورک حقیقی دنیا میں کیسے کام کرتا ہے

**سیکھنے کا معیار**:
- **ہم گامی رفتار**: اس چیز کو تلاش کرنے کی رفتار کیسے
- **سیمیولیشن کے مقابلے حقیقی دنیا کا تناسب**: پیش گوئی کا معیار
- **ہم آہنگی**: مختلف شروع کی حالت کے ساتھ کارکردگی کیسے متغیر ہے

### جائزہ کے طریقے

**پچیدہ ڈیٹا کے ساتھ جائزہ**:
- جامع ٹیسٹ ماحول
- مختلف شروع کی حالت
- نوائز والے سینسرز کا تجزیہ

**سیم ٹو ریل ٹرانسفر کی جانچ**:
- جامع سیمیولیشن کی ترتیبات
- حقیقی ڈیوائس پر جانچ
- کارکردگی کا تناسب کیا ہے

## کلیدی نکات

- ڈیپ لرننگ کے نیورل نیٹ ورکس ہائیرآرکیکل منیفولڈز کے قابل تکمیل نمائندگیاں سیکھتے ہیں
- ٹرانسفارمرز اور اٹینشن میکنزمز طویل سیکوئنسز پر کام کرنے کے قابل بناتے ہیں
- ری ایکٹمنٹ لرننگ ایجنٹس کو انعامات کی بنیاد پر سیکھنے کے قابل بناتا ہے
- ویریئشنل آٹو اینکوڈرز لیٹنٹ ریپریزنٹیشنز کو سیکھنے کے قابل بناتے ہیں
- جنریٹو ماڈلز حقیقی ڈیٹا کے نمونے تیار کرنے کے قابل ہوتے ہیں
- گیم تھیوری متعدد ایجنٹ تعاملات کے لیے ریاضیاتی ڈھانچہ فراہم کرتی ہے
- میٹا لرننگ کم ڈیٹا کے ساتھ نئے کاموں کے لیے تیز ایڈجسٹمنٹ کو فعال کرتا ہے
- روبوٹکس کے لیے محفوظی اور کارکردگی کے معیار اہم ہیں
