# ڈیپ لرننگ آرکیٹیکچر (اردو ایڈوانسڈ ورژن)

## باب کا جائزہ

ڈیپ لرننگ آرکیٹیکچر جدید مصنوعی ذہانت کے نظام کے لیے جامع ریاضیاتی فریم ورکس کی نمائندگی کرتے ہیں جو کمپیوٹیشنل گریف، خودکار ڈیفرینشیشن، اور تقسیم شدہ آپٹیمائزیشن کا استعمال کرتے ہوئے پیچیدہ مسائل حل کرتے ہیں۔ یہ آرکیٹیکچر فنکشنل اینالیسز، ڈیفرینشل جیومیٹری، اور انفارمیشن تھیوری کے اعلیٰ تصورات کو لاگو کرتے ہیں تاکہ سلسلہ وار فیچر لرننگ، توجہ کے میکنزمز، اور جنریٹو ماڈلنگ کو فعال کیا جا سکے۔ نظریاتی بنیادوں میں یونیورسل ایپروکسیمیشن تھیورم، ریپریزنٹیشن لرننگ تھیوری، اور آپٹیمائزیشن جیومیٹری شامل ہیں۔

### ریاضیاتی بنیادیں

اصل ڈیجیٹل نیورل نیٹ ورک کا عام روپ ایک مکمل غیر لکیری ٹرانسفارمیشنز کی ترکیب کے طور پر ظاہر کیا جا سکتا ہے:

f(x) = f_L ∘ f_{L-1} ∘ ... ∘ f_1(x)

جہاں ہر f_i ایک لیئر ٹرانسفارمیشن کی نمائندگی کرتا ہے:
```
f_i(x) = σ(W_i x + b_i)
```

جہاں σ ایکٹیویشن فنکشن ہے، W_i وزن میٹرکس ہے، اور b_i بائیس ویکٹر ہے۔

### آپٹیمائزیشن فریم ورک

گہرے نیٹ ورکس کو عام طور پر ایک تجرباتی خسارہ کو کم کرنے کے لیے تربیت دی جاتی ہے:

min_θ E[Loss(f_θ(x), y)]

جہاں θ تمام نیٹ ورک پیرامیٹر کی نمائندگی کرتا ہے، (x, y) تربیت کے امتحانات ہیں، اور امکان ڈیٹا تقسیم پر ہے۔

## کنولوشنل نیورل نیٹ ورکس (CNNs) - جدید ترین تجزیہ

### نظریاتی بنیادیں

CNNs گروپ تھیوری اور ہارمونک اینالیسز کے متن میں کنولوشن آپریشنز کی ریاضیاتی خصوصیات کا فائدہ اٹھاتے ہیں:

**ٹرانسلیشن ایکویوریئنس**: کنولوشن آپریشنز جگہی تعلقات کو بناوٹ کے فرق کے بغیر برقرار رکھتے ہیں

**مقامی رابطہ**: ہر فلٹر ایک مقامی ریسیپٹو فیلڈ پر کام کرتا ہے، جو سلسلہ وار فیچر نکالنے کو فعال کرتا ہے

**پیرامیٹر شیئرنگ**: فلٹر整个 spatial domain پر لاگو ہوتے ہیں، جو پیرامیٹر کی تعداد کو کم کرتا ہے

### جدید ترین CNN آرکیٹیکچر

#### ریزیڈوئل نیٹ ورکس (ResNets)

ResNets وینشین گریڈینٹ کے مسئلہ کو سکپ کنکشنز کے ذریعے حل کرتے ہیں:

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super(ResidualBlock, self).__init__()
        
        self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, 
                               stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, 
                               stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, kernel_size=1, 
                          stride=stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )
    
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)  # سکپ ککشن
        out = torch.relu(out)
        return out
```

#### ڈینس نیٹ ورکس (DenseNets)

DenseNets فیچر دوبارہ استعمال کو فروغ دیتے ہیں ہر لیئر کو تمام بعد کے لیئرز سے منسلک کرکے:

```python
class DenseLayer(nn.Module):
    def __init__(self, in_channels, growth_rate):
        super(DenseLayer, self).__init__()
        self.conv = nn.Conv2d(in_channels, growth_rate, kernel_size=3, 
                              padding=1, bias=False)
        self.bn = nn.BatchNorm2d(in_channels)
    
    def forward(self, x):
        new_features = self.conv(torch.relu(self.bn(x)))
        return torch.cat([x, new_features], 1)  # فیچرز کو جوڑ دیں
```

#### توجہ-مبنی CNNs

ماڈرن آرکیٹیکچر توجہ والے میکنزمز کو شامل کرتے ہیں:

```python
class SqueezeAndExcitation(nn.Module):
    def __init__(self, channels, reduction=16):
        super(SqueezeAndExcitation, self).__init__()
        self.fc1 = nn.Linear(channels, channels // reduction)
        self.fc2 = nn.Linear(channels // reduction, channels)
    
    def forward(self, x):
        batch, channels, _, _ = x.size()
        y = torch.nn.functional.adaptive_avg_pool2d(x, (1, 1)).view(batch, channels)
        y = torch.relu(self.fc1(y))
        y = torch.sigmoid(self.fc2(y))
        return x * y.view(batch, channels, 1, 1)
```

## ریکرینٹ نیورل نیٹ ورکس (RNNs) - جدید ترین تجزیہ

### ریاضیاتی فارمولیشن

RNNs اسٹیٹ فل کمپیوٹیشنز کو نافذ کرتے ہیں جن کے عام روپ میں ہے:

h_t = f(h_{t-1}, x_t; θ)
y_t = g(h_t; θ')

جہاں h_t پوشیدہ حالت ہے، x_t ان پٹ ہے، اور f اور g سیکھے گئے فنکشنز ہیں۔

### لمبی مدت کی مختصر میموری (LSTM)

LSTMs وینشین گریڈینٹ کے مسئلہ کو گیٹڈ میموری میکنزمز کے ذریعے حل کرتے ہیں:

```python
class LSTMCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super(LSTMCell, self).__init__()
        self.hidden_size = hidden_size
        
        # ان پٹ، فورگیٹ، اور آؤٹ پٹ گیٹس
        self.input_gate = nn.Linear(input_size + hidden_size, hidden_size)
        self.forget_gate = nn.Linear(input_size + hidden_size, hidden_size)
        self.output_gate = nn.Linear(input_size + hidden_size, hidden_size)
        
        # امکانی یاد دہانی
        self.candidate_cell = nn.Linear(input_size + hidden_size, hidden_size)
    
    def forward(self, x, hidden_state):
        h_prev, c_prev = hidden_state
        
        # ان پٹ اور پچھلی پوشیدہ حالت کو جوڑیں
        combined = torch.cat([x, h_prev], dim=1)
        
        # گیٹ ایکٹویشن کمپیوٹ کریں
        f_gate = torch.sigmoid(self.forget_gate(combined))
        i_gate = torch.sigmoid(self.input_gate(combined))
        o_gate = torch.sigmoid(self.output_gate(combined))
        
        # امکانی سیل حالت کمپیوٹ کریں
        c_tilde = torch.tanh(self.candidate_cell(combined))
        
        # نئی سیل حالت کمپیوٹ کریں
        c_new = f_gate * c_prev + i_gate * c_tilde
        
        # نئی پوشیدہ حالت کمپیوٹ کریں
        h_new = o_gate * torch.tanh(c_new)
        
        return h_new, (h_new, c_new)
```

### گیٹڈ ریکرینٹ یونٹ (GRU)

GRUs LSTMs کو سادہ بناتے ہیں جبکہ موثر ہوتے رہتے ہیں:

```python
class GRUCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super(GRUCell, self).__init__()
        self.hidden_size = hidden_size
        
        # اپ ڈیٹ اور ری سیٹ گیٹس
        self.update_gate = nn.Linear(input_size + hidden_size, hidden_size)
        self.reset_gate = nn.Linear(input_size + hidden_size, hidden_size)
        
        # نئی یاد کا مواد
        self.new_memory = nn.Linear(input_size + hidden_size, hidden_size)
    
    def forward(self, x, h_prev):
        # ان پٹ اور پچھلی پوشیدہ حالت کو جوڑیں
        combined = torch.cat([x, h_prev], dim=1)
        
        # گیٹ ایکٹویشن کمپیوٹ کریں
        z = torch.sigmoid(self.update_gate(combined))
        r = torch.sigmoid(self.reset_gate(combined))
        
        # امکانی پوشیدہ حالت کمپیوٹ کریں
        combined_r = torch.cat([x, r * h_prev], dim=1)
        h_tilde = torch.tanh(self.new_memory(combined_r))
        
        # نئی پوشیدہ حالت کمپیوٹ کریں
        h_new = (1 - z) * h_prev + z * h_tilde
        
        return h_new, h_new
```

## ٹرانسفارمر آرکیٹیکچر

### خود-توجہ کا میکنزم

خود-توجہ کا میکنزم ایک ترتیب کے تمام مقامات کے درمیان تعلقات کمپیوٹ کرتا ہے:

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super(MultiHeadAttention, self).__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # کویریز، کیز، ویلیوز، اور آؤٹ پٹ کے لیے لکیری پروجیکشنز
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def scaled_dot_product_attention(self, Q, K, V, mask=None):
        """
        سکیلڈ ڈوٹ-پروڈکٹ توجہ کا میکنزم
        """
        # توجہ کے اسکور کمپیوٹ کریں
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            scores.masked_fill_(mask == 0, -1e9)
        
        # توجہ کے وزن حاصل کرنے کے لیے سافٹ میکس لاگو کریں
        attention_weights = torch.softmax(scores, dim=-1)
        
        # توجہ کے وزن ویلیوز پر لاگو کریں
        output = torch.matmul(attention_weights, V)
        return output, attention_weights
    
    def forward(self, Q, K, V, mask=None):
        batch_size = Q.size(0)
        
        # لکیری پروجیکشنز
        Q = self.W_q(Q)  # (batch_size, seq_len, d_model)
        K = self.W_k(K)
        V = self.W_v(V)
        
        # ملٹی-ہیڈ توجہ کے لیے ری شیپ
        Q = Q.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        
        # سکیلڈ ڈوٹ-پروڈکٹ توجہ لاگو کریں
        attention_output, attention_weights = self.scaled_dot_product_attention(
            Q, K, V, mask
        )
        
        # اصل ابعاد پر واپس ری شیپ
        attention_output = attention_output.transpose(1, 2).contiguous().view(
            batch_size, -1, self.d_model
        )
        
        # حتمی لکیری پروجیکشن
        output = self.W_o(attention_output)
        return output, attention_weights
```

### ٹرانسفارمر اینکوڈر-ڈیکوڈر آرکیٹیکچر

```python
class TransformerBlock(nn.Module):
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super(TransformerBlock, self).__init__()
        self.attention = MultiHeadAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)
        
        # فیڈ- فارورڈ نیٹ ورک
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
    
    def forward(self, x):
        # خود- توجہ_residual connection کے ساتھ
        attn_output, _ = self.attention(x, x, x)
        x = self.norm1(x + self.dropout1(attn_output))
        
        # فیڈ- فارورڈ_residual connection کے ساتھ
        ff_output = self.ffn(x)
        x = self.norm2(x + self.dropout2(ff_output))
        
        return x

class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super(PositionalEncoding, self).__init__()
        
        # پوزیشنل انکوڈنگ میٹرکس تخلیق کریں
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len).unsqueeze(1).float()
        
        # سائنوسوئڈل انکوڈنگ لاگو کریں
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                            -(math.log(10000.0) / d_model))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        
        # بطور بفر رجسٹر کریں (پیرامیٹر نہیں)
        self.register_buffer('pe', pe.unsqueeze(0))
    
    def forward(self, x):
        return x + self.pe[:, :x.size(1)]
```

## ڈیپ ری انفورسمنٹ لرننگ آرکیٹیکچرز

### ڈیپ Q-نیٹ ورک (DQN) جدید تکنیکس کے ساتھ

```python
class DuelingDQN(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super(DuelingDQN, self).__init__()
        
        # مشترکہ فیچر ایکسٹریکٹر
        self.feature_extractor = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # فائدہ سٹریم
        self.advantage_stream = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim)
        )
        
        # ویلیو سٹریم
        self.value_stream = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )
    
    def forward(self, state):
        features = self.feature_extractor(state)
        
        # ویلیو اور فائدہ کمپیوٹ کریں
        value = self.value_stream(features)
        advantage = self.advantage_stream(features)
        
        # ڈویل کردارکی استعمال سے جوڑیں: Q = V + (A - mean(A))
        q_values = value + (advantage - advantage.mean(dim=1, keepdim=True))
        return q_values

class DistributionalDQN(nn.Module):
    """
    Distibutional DQN Q-ویلیوز کے پورے تقسیم کو سیکھتا ہے،
    فقط متوقع قیمت کے بجائے
    """
    def __init__(self, state_dim, action_dim, n_atoms=51, v_min=-10, v_max=10):
        super(DistributionalDQN, self).__init__()
        self.n_atoms = n_atoms
        self.v_min = v_min
        self.v_max = v_max
        self.action_dim = action_dim
        
        # زمرہ کے تقسیم کے لیے سپورٹ
        self.register_buffer('support', torch.linspace(v_min, v_max, n_atoms))
        self.delta_z = (v_max - v_min) / (n_atoms - 1)
        
        # ایکشن-ویلیو تقسیم کو آؤٹ پٹ کرنے والے نیٹ ورک
        self.network = nn.Sequential(
            nn.Linear(state_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, action_dim * n_atoms)
        )
    
    def forward(self, state):
        logits = self.network(state)
        logits = logits.view(-1, self.action_dim, self.n_atoms)
        probs = torch.softmax(logits, dim=-1)
        return probs
    
    def compute_q_values(self, state):
        """تقسیم سے متوقع Q-ویلیوز کمپیوٹ کریں"""
        probs = self.forward(state)
        q_values = torch.sum(probs * self.support, dim=2)
        return q_values
```

### ایکٹر-کریٹک طریقے

```python
class Soft Actor-Critic (SAC):
    """
    SAC ایک آف پالیسی زیادہ سے زیادہ اینٹروپی الگورتھم ہے جو سیکھتا ہے 
    قیمت اور پالیسی دونوں فنکشنز
    """
    def __init__(self, state_dim, action_dim, hidden_dim=256, alpha=0.2):
        super(SAC, self).__init__()
        
        # پالیسی نیٹ ورک (گاؤسین پالیسی)
        self.actor = GaussianPolicy(state_dim, action_dim, hidden_dim)
        
        # ڈبل Q-لرننگ کے لیے دو Q-نیٹ ورکس
        self.critic1 = QNetwork(state_dim, action_dim, hidden_dim)
        self.critic2 = QNetwork(state_dim, action_dim, hidden_dim)
        
        # استحکام کے لیے ہدف نیٹ ورکس
        self.critic1_target = copy.deepcopy(self.critic1)
        self.critic2_target = copy.deepcopy(self.critic2)
        
        # خودکار اینٹروپی ٹیوننگ
        self.target_entropy = -torch.prod(torch.Tensor(action_dim)).item()
        self.log_alpha = torch.log(torch.tensor(alpha))
        self.alpha_optimizer = torch.optim.Adam([self.log_alpha], lr=3e-4)
    
    def update(self, replay_buffer, batch_size=256, gamma=0.99, tau=0.005):
        # ریپلے بفر سے بیچ مثال نمونہ
        state, action, reward, next_state, done = replay_buffer.sample(batch_size)
        
        # Q-فنکشنز کو اپ ڈیٹ کریں
        with torch.no_grad():
            next_action, next_log_prob, _ = self.actor.sample(next_state)
            next_q1 = self.critic1_target(next_state, next_action)
            next_q2 = self.critic2_target(next_state, next_action)
            next_v = torch.min(next_q1, next_q2) - self.alpha * next_log_prob
            target_q = reward + (1 - done) * gamma * next_v
        
        current_q1 = self.critic1(state, action)
        current_q2 = self.critic2(state, action)
        
        q_loss = F.mse_loss(current_q1, target_q) + F.mse_loss(current_q2, target_q)
        
        # Q-نیٹ ورکس کو اپ ڈیٹ کریں
        self.critic_optim.zero_grad()
        q_loss.backward()
        self.critic_optim.step()
        
        # پالیسی کو اپ ڈیٹ کریں
        pi, log_prob, _ = self.actor.sample(state)
        q1_pi = self.critic1(state, pi)
        q2_pi = self.critic2(state, pi)
        min_q_pi = torch.min(q1_pi, q2_pi)
        
        policy_loss = ((self.alpha * log_prob) - min_q_pi).mean()
        
        self.actor_optim.zero_grad()
        policy_loss.backward()
        self.actor_optim.step()
        
        # اینٹروپی کا عدد اپ ڈیٹ کریں
        self.alpha_optimizer.zero_grad()
        alpha_loss = -(self.log_alpha * (log_prob + self.target_entropy).detach()).mean()
        alpha_loss.backward()
        self.alpha_optimizer.step()
        self.alpha = self.log_alpha.exp()
        
        # ہدف نیٹ ورکس کو اپ ڈیٹ کریں
        for param, target_param in zip(self.critic.parameters(), 
                                     self.critic_target.parameters()):
            target_param.data.copy_(tau * param.data + (1 - tau) * target_param.data)
```

### ویری ایشنل آٹو اینکوڈر (VAE)

```python
class VAE(nn.Module):
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super(VAE, self).__init__()
        self.latent_dim = latent_dim
        
        # اینکوڈر
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # اوسط اور لاگ ویرینس کے لیے الگ الگ لیئرز
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        
        # ڈیکوڈر
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid()  # فرض کریں کہ نارملائزڈ ان پٹ
        )
    
    def encode(self, x):
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar
    
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std
    
    def decode(self, z):
        return self.decoder(z)
    
    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

def vae_loss(recon_x, x, mu, logvar, beta=1.0):
    """متغیر نچلی حد"""
    # دوبارہ تعمیر کا نقصان
    recon_loss = F.binary_cross_entropy(recon_x, x, reduction='sum')
    
    # KL تقسیم نقصان (ریگولرائزیشن ٹرم)
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    
    return recon_loss + beta * kl_loss
```

class DCGAN(nn.Module):
    """ڈیجی کنولوشنل GAN"""
    def __init__(self, latent_dim, img_channels, img_size):
        super(DCGAN, self).__init__()
        
        # جنریٹر
        self.generator = nn.Sequential(
            # ان پٹ: N x latent_dim x 1 x 1
            nn.ConvTranspose2d(latent_dim, 512, 4, 1, 0, bias=False),
            nn.BatchNorm2d(512),
            nn.ReLU(True),
            # N x 512 x 4 x 4
            nn.ConvTranspose2d(512, 256, 4, 2, 1, bias=False),
            nn.BatchNorm2d(256),
            nn.ReLU(True),
            # N x 256 x 8 x 8
            nn.ConvTranspose2d(256, 128, 4, 2, 1, bias=False),
            nn.BatchNorm2d(128),
            nn.ReLU(True),
            # N x 128 x 16 x 16
            nn.ConvTranspose2d(128, img_channels, 4, 2, 1, bias=False),
            nn.Tanh()
            # N x img_channels x 32 x 32
        )
        
        # ڈسکریمنیٹر
        self.discriminator = nn.Sequential(
            # ان پٹ: N x img_channels x img_size x img_size
            nn.Conv2d(img_channels, 64, 4, 2, 1, bias=False),
            nn.LeakyReLU(0.2, inplace=True),
            # N x 64 x 16 x 16
            nn.Conv2d(64, 128, 4, 2, 1, bias=False),
            nn.BatchNorm2d(128),
            nn.LeakyReLU(0.2, inplace=True),
            # N x 128 x 8 x 8
            nn.Conv2d(128, 256, 4, 2, 1, bias=False),
            nn.BatchNorm2d(256),
            nn.LeakyReLU(0.2, inplace=True),
            # N x 256 x 4 x 4
            nn.Conv2d(256, 1, 4, 1, 0, bias=False),
            nn.Sigmoid()
        )
    
    def forward(self, z):
        # جعلی تصاویر تیار کریں
        fake_imgs = self.generator(z)
        # جعلی/اصلی کا فیصلہ کریں
        validity = self.discriminator(fake_imgs)
        return fake_imgs, validity

class ConditionalGAN(nn.Module):
    """ Conditional GAN جو کلاس لیبلز لیتا ہے"""
    def __init__(self, latent_dim, n_classes, img_channels, img_size):
        super(ConditionalGAN, self).__init__()
        
        # کلاس لیبلز کے لیے ایمبیڈنگ
        self.label_emb = nn.Embedding(n_classes, n_classes)
        
        # کنڈیشنل ان پٹ کے ساتھ جنریٹر
        self.generator = nn.Sequential(
            nn.Linear(latent_dim + n_classes, 256),
            nn.LeakyReLU(0.2),
            nn.Linear(256, 512),
            nn.BatchNorm1d(512),
            nn.LeakyReLU(0.2),
            nn.Linear(512, 1024),
            nn.BatchNorm1d(1024),
            nn.LeakyReLU(0.2),
            nn.Linear(1024, img_channels * img_size * img_size),
            nn.Tanh()
        )
    
    def forward(self, noise, labels):
        # ایمبیڈ اور لیبلز کو نوائز کے ساتھ جوڑیں
        label_embedding = self.label_emb(labels)
        gen_input = torch.cat([noise, label_embedding], dim=1)
        img = self.generator(gen_input)
        img = img.view(img.size(0), -1, img_size, img_size)
        return img
```

### ویژن ٹرانسفارمر (ViT)

class PatchEmbedding(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_channels=3, embed_dim=768):
        super(PatchEmbedding, self).__init__()
        self.img_size = img_size
        self.patch_size = patch_size
        self.grid_size = img_size // patch_size
        self.num_patches = self.grid_size ** 2
        
        # پیچ پروجیکشن
        self.projection = nn.Conv2d(in_channels, embed_dim, 
                                   kernel_size=patch_size, stride=patch_size)
    
    def forward(self, x):
        # x: (batch_size, 3, img_size, img_size)
        x = self.projection(x)  # (batch_size, embed_dim, grid_size, grid_size)
        x = x.flatten(2)  # (batch_size, embed_dim, num_patches)
        x = x.transpose(1, 2)  # (batch_size, num_patches, embed_dim)
        return x

class VisionTransformer(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_channels=3, 
                 num_classes=1000, embed_dim=768, depth=12, num_heads=12, 
                 mlp_ratio=4, dropout=0.1, attention_dropout=0.1):
        super(VisionTransformer, self).__init__()
        
        # پیچ ایمبیڈنگ
        self.patch_embed = PatchEmbedding(img_size, patch_size, in_channels, embed_dim)
        
        # کلاس ٹوکن اور پوزیشنل ایمبیڈنگ
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, self.patch_embed.num_patches + 1, embed_dim))
        self.pos_drop = nn.Dropout(dropout)
        
        # ٹرانسفارمر بلاکس
        self.blocks = nn.ModuleList([
            TransformerBlock(embed_dim, num_heads, int(embed_dim * mlp_ratio), dropout, attention_dropout)
            for _ in range(depth)
        ])
        
        # کلاسیفیکیشن ہیڈ
        self.norm = nn.LayerNorm(embed_dim)
        self.head = nn.Linear(embed_dim, num_classes)
    
    def forward(self, x):
        B = x.shape[0]
        x = self.patch_embed(x)
        
        # کلاس ٹوکن شامل کریں
        cls_tokens = self.cls_token.expand(B, -1, -1)
        x = torch.cat([cls_tokens, x], dim=1)
        
        # پوزیشنل ایمبیڈنگ شامل کریں
        x = x + self.pos_embed
        x = self.pos_drop(x)
        
        # ٹرانسفارمر بلاکس لاگو کریں
        for block in self.blocks:
            x = block(x)
        
        # کلاس ٹوکن کو کلاسیفیکیشن کے لیے استعمال کریں
        x = self.norm(x[:, 0])
        x = self.head(x)
        return x
```

```python
from torch.cuda.amp import GradScaler, autocast

class MixedPrecisionTrainer:
    def __init__(self, model, optimizer):
        self.model = model
        self.optimizer = optimizer
        self.scaler = GradScaler()
    
    def train_step(self, data, target):
        self.optimizer.zero_grad()
        
        # خودکار مکسڈ پریسیژن کا استعمال کریں
        with autocast():
            output = self.model(data)
            loss = F.cross_entropy(output, target)
        
        # نقصان کو اسکیل اور بیک پروپیگیٹ کریں
        self.scaler.scale(loss).backward()
        self.scaler.step(self.optimizer)
        self.scaler.update()
        
        return loss.item()
```

#### گریڈینٹ کلپنگ

```python
def train_with_gradient_clipping(model, data_loader, optimizer, max_grad_norm=1.0):
    total_loss = 0
    for batch_idx, (data, target) in enumerate(data_loader):
        optimizer.zero_grad()
        output = model(data)
        loss = F.cross_entropy(output, target)
        loss.backward()
        
        # گریڈینٹس کو ایکسپلوڈنگ گریڈینٹس کو روکنے کے لیے کلپ کریں
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_grad_norm)
        
        optimizer.step()
        total_loss += loss.item()
    
    return total_loss / len(data_loader)
```

    ddp_model = DDP(model, device_ids=[device])
    
    for epoch in range(num_epochs):
        for batch_idx, (data, target) in enumerate(train_loader):
            data, target = data.to(device), target.to(device)

            loss = F.cross_entropy(output, target)
            loss.backward()
            
            optimizer.step()
