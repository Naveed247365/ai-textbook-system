# Deep Learning Architectures (English Advanced Version)

## Chapter Overview

Deep learning architectures represent sophisticated mathematical frameworks that leverage computational graphs, automatic differentiation, and distributed optimization to solve complex problems. These architectures implement advanced concepts from functional analysis, differential geometry, and information theory to enable hierarchical feature learning, attention mechanisms, and generative modeling. The theoretical foundations include universal approximation theorems, representation learning theory, and optimization geometry.

### Mathematical Foundations

The general form of a deep neural network can be expressed as a composition of nonlinear transformations:

f(x) = f_L ∘ f_{L-1} ∘ ... ∘ f_1(x)

Where each f_i represents a layer transformation:
```
f_i(x) = σ(W_i x + b_i)
```

Where σ is the activation function, W_i are weight matrices, and b_i are bias vectors.

### Optimization Framework

Deep networks are typically trained by minimizing an empirical risk:

min_θ E[Loss(f_θ(x), y)]

Where θ represents all network parameters, (x, y) are training examples, and the expectation is over the data distribution.

## Convolutional Neural Networks (CNNs) - Advanced Analysis

### Theoretical Underpinnings

CNNs leverage the mathematical properties of convolution operations in the context of group theory and harmonic analysis:

**Translation Equivariance**: Convolution operations maintain spatial relationships regardless of translation

**Local Connectivity**: Each filter operates on a local receptive field, enabling hierarchical feature extraction

**Parameter Sharing**: Filters are applied across the entire spatial domain, reducing parameter count

### Advanced CNN Architectures

#### Residual Networks (ResNets)

ResNets address the vanishing gradient problem through skip connections:

```python
import torch
import torch.nn as nn

class ResidualBlock(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super(ResidualBlock, self).__init__()
        
        self.conv1 = nn.Conv2d(in_channels, out_channels, kernel_size=3, 
                               stride=stride, padding=1, bias=False)
        self.bn1 = nn.BatchNorm2d(out_channels)
        self.conv2 = nn.Conv2d(out_channels, out_channels, kernel_size=3, 
                               stride=1, padding=1, bias=False)
        self.bn2 = nn.BatchNorm2d(out_channels)
        
        self.shortcut = nn.Sequential()
        if stride != 1 or in_channels != out_channels:
            self.shortcut = nn.Sequential(
                nn.Conv2d(in_channels, out_channels, kernel_size=1, 
                          stride=stride, bias=False),
                nn.BatchNorm2d(out_channels)
            )
    
    def forward(self, x):
        out = torch.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        out += self.shortcut(x)  # Skip connection
        out = torch.relu(out)
        return out
```

#### Dense Networks (DenseNets)

DenseNets promote feature reuse by connecting each layer to all subsequent layers:

```python
class DenseLayer(nn.Module):
    def __init__(self, in_channels, growth_rate):
        super(DenseLayer, self).__init__()
        self.conv = nn.Conv2d(in_channels, growth_rate, kernel_size=3, 
                              padding=1, bias=False)
        self.bn = nn.BatchNorm2d(in_channels)
    
    def forward(self, x):
        new_features = self.conv(torch.relu(self.bn(x)))
        return torch.cat([x, new_features], 1)  # Concatenate features
```

## Recurrent Neural Networks (RNNs) - Advanced Analysis

### Mathematical Formulation

RNNs implement stateful computations with the general form:

h_t = f(h_{t-1}, x_t; θ)
y_t = g(h_t; θ')

Where h_t is the hidden state, x_t is the input, and f and g are learned functions.

### Long Short-Term Memory (LSTM)

LSTMs address the vanishing gradient problem through gated memory mechanisms:

```python
class LSTMCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super(LSTMCell, self).__init__()
        self.hidden_size = hidden_size
        
        # Input, forget, and output gates
        self.input_gate = nn.Linear(input_size + hidden_size, hidden_size)
        self.forget_gate = nn.Linear(input_size + hidden_size, hidden_size)
        self.output_gate = nn.Linear(input_size + hidden_size, hidden_size)
        
        # Candidate memory cell
        self.candidate_cell = nn.Linear(input_size + hidden_size, hidden_size)
    
    def forward(self, x, hidden_state):
        h_prev, c_prev = hidden_state
        
        # Concatenate input and previous hidden state
        combined = torch.cat([x, h_prev], dim=1)
        
        # Compute gate activations
        f_gate = torch.sigmoid(self.forget_gate(combined))
        i_gate = torch.sigmoid(self.input_gate(combined))
        o_gate = torch.sigmoid(self.output_gate(combined))
        
        # Compute candidate cell state
        c_tilde = torch.tanh(self.candidate_cell(combined))
        
        # Compute new cell state
        c_new = f_gate * c_prev + i_gate * c_tilde
        
        # Compute new hidden state
        h_new = o_gate * torch.tanh(c_new)
        
        return h_new, (h_new, c_new)
```

### Gated Recurrent Unit (GRU)

GRUs simplify LSTMs while maintaining effectiveness:

```python
class GRUCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super(GRUCell, self).__init__()
        self.hidden_size = hidden_size
        
        # Update and reset gates
        self.update_gate = nn.Linear(input_size + hidden_size, hidden_size)
        self.reset_gate = nn.Linear(input_size + hidden_size, hidden_size)
        
        # New memory content
        self.new_memory = nn.Linear(input_size + hidden_size, hidden_size)
    
    def forward(self, x, h_prev):
        # Concatenate input and previous hidden state
        combined = torch.cat([x, h_prev], dim=1)
        
        # Compute gate activations
        z = torch.sigmoid(self.update_gate(combined))
        r = torch.sigmoid(self.reset_gate(combined))
        
        # Compute candidate hidden state
        combined_r = torch.cat([x, r * h_prev], dim=1)
        h_tilde = torch.tanh(self.new_memory(combined_r))
        
        # Compute new hidden state
        h_new = (1 - z) * h_prev + z * h_tilde
        
        return h_new, h_new
```

## Transformer Architecture

### Self-Attention Mechanism

The self-attention mechanism computes relationships between all positions in a sequence:

```python
class MultiHeadAttention(nn.Module):
    def __init__(self, d_model, num_heads):
        super(MultiHeadAttention, self).__init__()
        self.d_model = d_model
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        
        # Linear projections for queries, keys, values, and output
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)
        self.W_o = nn.Linear(d_model, d_model)
    
    def scaled_dot_product_attention(self, Q, K, V, mask=None):
        """
        Scaled dot-product attention mechanism
        """
        # Compute attention scores
        scores = torch.matmul(Q, K.transpose(-2, -1)) / math.sqrt(self.d_k)
        
        if mask is not None:
            scores.masked_fill_(mask == 0, -1e9)
        
        # Apply softmax to get attention weights
        attention_weights = torch.softmax(scores, dim=-1)
        
        # Apply attention weights to values
        output = torch.matmul(attention_weights, V)
        return output, attention_weights
    
    def forward(self, Q, K, V, mask=None):
        batch_size = Q.size(0)
        
        # Linear projections
        Q = self.W_q(Q)  # (batch_size, seq_len, d_model)
        K = self.W_k(K)
        V = self.W_v(V)
        
        # Reshape for multi-head attention
        Q = Q.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        K = K.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        V = V.view(batch_size, -1, self.num_heads, self.d_k).transpose(1, 2)
        
        # Apply scaled dot-product attention
        attention_output, attention_weights = self.scaled_dot_product_attention(
            Q, K, V, mask
        )
        
        # Reshape back to original dimensions
        attention_output = attention_output.transpose(1, 2).contiguous().view(
            batch_size, -1, self.d_model
        )
        
        # Final linear projection
        output = self.W_o(attention_output)
        return output, attention_weights
```

### Transformer Encoder-Decoder Architecture

```python
class TransformerBlock(nn.Module):
    def __init__(self, d_model, num_heads, d_ff, dropout=0.1):
        super(TransformerBlock, self).__init__()
        self.attention = MultiHeadAttention(d_model, num_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.dropout1 = nn.Dropout(dropout)
        self.dropout2 = nn.Dropout(dropout)
        
        # Feed-forward network
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(d_ff, d_model),
            nn.Dropout(dropout)
        )
    
    def forward(self, x):
        # Self-attention with residual connection
        attn_output, _ = self.attention(x, x, x)
        x = self.norm1(x + self.dropout1(attn_output))
        
        # Feed-forward with residual connection
        ff_output = self.ffn(x)
        x = self.norm2(x + self.dropout2(ff_output))
        
        return x

class PositionalEncoding(nn.Module):
    def __init__(self, d_model, max_len=5000):
        super(PositionalEncoding, self).__init__()
        
        # Create positional encoding matrix
        pe = torch.zeros(max_len, d_model)
        position = torch.arange(0, max_len).unsqueeze(1).float()
        
        # Apply sinusoidal encoding
        div_term = torch.exp(torch.arange(0, d_model, 2).float() * 
                            -(math.log(10000.0) / d_model))
        
        pe[:, 0::2] = torch.sin(position * div_term)
        pe[:, 1::2] = torch.cos(position * div_term)
        
        # Register as buffer (not a parameter)
        self.register_buffer('pe', pe.unsqueeze(0))
    
    def forward(self, x):
        return x + self.pe[:, :x.size(1)]
```

## Deep Reinforcement Learning Architectures

### Deep Q-Network (DQN) with Advanced Techniques

```python
class DuelingDQN(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super(DuelingDQN, self).__init__()
        
        # Shared feature extractor
        self.feature_extractor = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Advantage stream
        self.advantage_stream = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim)
        )
        
        # Value stream
        self.value_stream = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )
    
    def forward(self, state):
        features = self.feature_extractor(state)
        
        # Compute value and advantage
        value = self.value_stream(features)
        advantage = self.advantage_stream(features)
        
        # Combine using dueling architecture: Q = V + (A - mean(A))
        q_values = value + (advantage - advantage.mean(dim=1, keepdim=True))
        return q_values

class DistributionalDQN(nn.Module):
    """
    Distributional DQN learns the full distribution of Q-values,
    not just the expected value
    """
    def __init__(self, state_dim, action_dim, n_atoms=51, v_min=-10, v_max=10):
        super(DistributionalDQN, self).__init__()
        self.n_atoms = n_atoms
        self.v_min = v_min
        self.v_max = v_max
        self.action_dim = action_dim
        
        # Support for the categorical distribution
        self.register_buffer('support', torch.linspace(v_min, v_max, n_atoms))
        self.delta_z = (v_max - v_min) / (n_atoms - 1)
        
        # Network to output action-value distribution
        self.network = nn.Sequential(
            nn.Linear(state_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, action_dim * n_atoms)
        )
    
    def forward(self, state):
        logits = self.network(state)
        logits = logits.view(-1, self.action_dim, self.n_atoms)
        probs = torch.softmax(logits, dim=-1)
        return probs
    
    def compute_q_values(self, state):
        """Compute expected Q-values from the distribution"""
        probs = self.forward(state)
        q_values = torch.sum(probs * self.support, dim=2)
        return q_values
```

### Actor-Critic Methods

```python
class Soft Actor-Critic (SAC):
    """
    SAC is an off-policy maximum entropy algorithm that learns 
    both value and policy functions
    """
    def __init__(self, state_dim, action_dim, hidden_dim=256, alpha=0.2):
        super(SAC, self).__init__()
        
        # Policy network (Gaussian policy)
        self.actor = GaussianPolicy(state_dim, action_dim, hidden_dim)
        
        # Two Q-networks for double Q-learning
        self.critic1 = QNetwork(state_dim, action_dim, hidden_dim)
        self.critic2 = QNetwork(state_dim, action_dim, hidden_dim)
        
        # Target networks for stability
        self.critic1_target = copy.deepcopy(self.critic1)
        self.critic2_target = copy.deepcopy(self.critic2)
        
        # Automatic entropy tuning
        self.target_entropy = -torch.prod(torch.Tensor(action_dim)).item()
        self.log_alpha = torch.log(torch.tensor(alpha))
        self.alpha_optimizer = torch.optim.Adam([self.log_alpha], lr=3e-4)
    
    def update(self, replay_buffer, batch_size=256, gamma=0.99, tau=0.005):
        # Sample batch from replay buffer
        state, action, reward, next_state, done = replay_buffer.sample(batch_size)
        
        # Update Q-functions
        with torch.no_grad():
            next_action, next_log_prob, _ = self.actor.sample(next_state)
            next_q1 = self.critic1_target(next_state, next_action)
            next_q2 = self.critic2_target(next_state, next_action)
            next_v = torch.min(next_q1, next_q2) - self.alpha * next_log_prob
            target_q = reward + (1 - done) * gamma * next_v
        
        current_q1 = self.critic1(state, action)
        current_q2 = self.critic2(state, action)
        
        q_loss = F.mse_loss(current_q1, target_q) + F.mse_loss(current_q2, target_q)
        
        # Update Q-networks
        self.critic_optim.zero_grad()
        q_loss.backward()
        self.critic_optim.step()
        
        # Update policy
        pi, log_prob, _ = self.actor.sample(state)
        q1_pi = self.critic1(state, pi)
        q2_pi = self.critic2(state, pi)
        min_q_pi = torch.min(q1_pi, q2_pi)
        
        policy_loss = ((self.alpha * log_prob) - min_q_pi).mean()
        
        self.actor_optim.zero_grad()
        policy_loss.backward()
        self.actor_optim.step()
        
        # Update entropy coefficient
        self.alpha_optimizer.zero_grad()
        alpha_loss = -(self.log_alpha * (log_prob + self.target_entropy).detach()).mean()
        alpha_loss.backward()
        self.alpha_optimizer.step()
        self.alpha = self.log_alpha.exp()
        
        # Update target networks
        for param, target_param in zip(self.critic.parameters(), 
                                     self.critic_target.parameters()):
            target_param.data.copy_(tau * param.data + (1 - tau) * target_param.data)
```

## Generative Models

### Variational Autoencoder (VAE)

```python
class VAE(nn.Module):
    def __init__(self, input_dim, hidden_dim, latent_dim):
        super(VAE, self).__init__()
        self.latent_dim = latent_dim
        
        # Encoder
        self.encoder = nn.Sequential(
            nn.Linear(input_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Separate layers for mean and log variance
        self.fc_mu = nn.Linear(hidden_dim, latent_dim)
        self.fc_logvar = nn.Linear(hidden_dim, latent_dim)
        
        # Decoder
        self.decoder = nn.Sequential(
            nn.Linear(latent_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, input_dim),
            nn.Sigmoid()  # Assuming normalized input
        )
    
    def encode(self, x):
        h = self.encoder(x)
        mu = self.fc_mu(h)
        logvar = self.fc_logvar(h)
        return mu, logvar
    
    def reparameterize(self, mu, logvar):
        std = torch.exp(0.5 * logvar)
        eps = torch.randn_like(std)
        return mu + eps * std
    
    def decode(self, z):
        return self.decoder(z)
    
    def forward(self, x):
        mu, logvar = self.encode(x)
        z = self.reparameterize(mu, logvar)
        return self.decode(z), mu, logvar

def vae_loss(recon_x, x, mu, logvar, beta=1.0):
    """Variational lower bound"""
    # Reconstruction loss
    recon_loss = F.binary_cross_entropy(recon_x, x, reduction='sum')
    
    # KL divergence loss (regularization term)
    kl_loss = -0.5 * torch.sum(1 + logvar - mu.pow(2) - logvar.exp())
    
    return recon_loss + beta * kl_loss
```

class DCGAN(nn.Module):

            nn.Tanh()
            # N x img_channels x 32 x 32
        )
        
        # Discriminator
        self.discriminator = nn.Sequential(
            # Input: N x img_channels x img_size x img_size
            nn.Conv2d(img_channels, 64, 4, 2, 1, bias=False),
            nn.LeakyReLU(0.2, inplace=True),

            nn.Conv2d(128, 256, 4, 2, 1, bias=False),
            nn.BatchNorm2d(256),
            nn.LeakyReLU(0.2, inplace=True),
            # N x 256 x 4 x 4
            nn.Conv2d(256, 1, 4, 1, 0, bias=False),
            nn.Sigmoid()
        )
    
    def forward(self, z):
        # Generate fake images
        fake_imgs = self.generator(z)
        # Discriminate real/fake
        validity = self.discriminator(fake_imgs)
        return fake_imgs, validity

### Vision Transformer (ViT)

```python
class PatchEmbedding(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_channels=3, embed_dim=768):
        super(PatchEmbedding, self).__init__()
        self.img_size = img_size
        self.patch_size = patch_size
        self.grid_size = img_size // patch_size
        self.num_patches = self.grid_size ** 2
        
        # Patch projection
        self.projection = nn.Conv2d(in_channels, embed_dim, 
                                   kernel_size=patch_size, stride=patch_size)
    
    def forward(self, x):
        # x: (batch_size, 3, img_size, img_size)
        x = self.projection(x)  # (batch_size, embed_dim, grid_size, grid_size)
        x = x.flatten(2)  # (batch_size, embed_dim, num_patches)
        x = x.transpose(1, 2)  # (batch_size, num_patches, embed_dim)
        return x

class VisionTransformer(nn.Module):
    def __init__(self, img_size=224, patch_size=16, in_channels=3, 
                 num_classes=1000, embed_dim=768, depth=12, num_heads=12, 
                 mlp_ratio=4, dropout=0.1, attention_dropout=0.1):
        super(VisionTransformer, self).__init__()
        
        # Patch embedding
        self.patch_embed = PatchEmbedding(img_size, patch_size, in_channels, embed_dim)
        
        # Class token and positional embedding
        self.cls_token = nn.Parameter(torch.zeros(1, 1, embed_dim))
        self.pos_embed = nn.Parameter(torch.zeros(1, self.patch_embed.num_patches + 1, embed_dim))
        self.pos_drop = nn.Dropout(dropout)
        
        # Transformer blocks
        self.blocks = nn.ModuleList([
            TransformerBlock(embed_dim, num_heads, int(embed_dim * mlp_ratio), dropout, attention_dropout)
            for _ in range(depth)
        ])
        
        # Classification head
        self.norm = nn.LayerNorm(embed_dim)
        self.head = nn.Linear(embed_dim, num_classes)
    
    def forward(self, x):
        B = x.shape[0]
        x = self.patch_embed(x)
        
        # Add class token
        cls_tokens = self.cls_token.expand(B, -1, -1)
        x = torch.cat([cls_tokens, x], dim=1)
        
        # Add positional embedding
        x = x + self.pos_embed
        x = self.pos_drop(x)
        
        # Apply transformer blocks
        for block in self.blocks:
            x = block(x)
        
        # Use class token for classification
        x = self.norm(x[:, 0])
        x = self.head(x)
        return x
```

### Advanced Training Techniques

#### Automatic Mixed Precision Training

```python
from torch.cuda.amp import GradScaler, autocast

class MixedPrecisionTrainer:
    def __init__(self, model, optimizer):
        self.model = model
        self.optimizer = optimizer
        self.scaler = GradScaler()
    
    def train_step(self, data, target):
        self.optimizer.zero_grad()
        
        # Use automatic mixed precision
        with autocast():
            output = self.model(data)
            loss = F.cross_entropy(output, target)
        
        # Scale loss and backpropagate
        self.scaler.scale(loss).backward()
        self.scaler.step(self.optimizer)
        self.scaler.update()
        
        return loss.item()
```

#### Gradient Clipping

```python
def train_with_gradient_clipping(model, data_loader, optimizer, max_grad_norm=1.0):
    total_loss = 0
    for batch_idx, (data, target) in enumerate(data_loader):
        optimizer.zero_grad()
        output = model(data)
        loss = F.cross_entropy(output, target)
        loss.backward()
        
        # Clip gradients to prevent exploding gradients
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_grad_norm)
        
        optimizer.step()
        total_loss += loss.item()
    
    return total_loss / len(data_loader)
```

def setup_distributed():
    """Initialize distributed training"""

def train_distributed(model, train_loader, optimizer, device):

    ddp_model = DDP(model, device_ids=[device])
    
    for epoch in range(num_epochs):
        for batch_idx, (data, target) in enumerate(train_loader):
            data, target = data.to(device), target.to(device)

            loss = F.cross_entropy(output, target)

            optimizer.step()
