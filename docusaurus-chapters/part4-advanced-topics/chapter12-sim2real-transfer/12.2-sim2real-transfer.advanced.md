# Simulation to Reality Transfer (English Advanced Version)

## Chapter Overview

Simulation to reality transfer (Sim-to-Real) represents a fundamental challenge in robotics that bridges control theory, system identification, domain adaptation, and causal inference. The mathematical framework encompasses probability shift theory, covariate shift correction, and transfer risk minimization to address the systematic differences between synthetic and authentic environments. Advanced techniques include domain randomization, adaptive control, system identification, and causal modeling to achieve robust policy transfer. The theoretical foundations draw from information theory, optimal transport, and generalization bounds in statistical learning theory.

### Mathematical Formulation

The sim-to-real transfer problem can be formulated as adapting a policy π_sim learned in simulation to be effective in the real environment:

min_π_real E_{real}[∑_t γ^t r(s_t, π_real(s_t))]

Subject to:
- π_real ≈ π_sim (transfer constraint)
- ||p_real - p_sim|| ≤ δ (distribution mismatch bound)

Where p_sim and p_real are the simulation and real-world state distributions, and δ bounds the allowed discrepancy.

### Domain Adaptation Framework

In the domain adaptation perspective:

**Source Domain**: D_sim = {X_sim, P_sim(X,Y)}
**Target Domain**: D_real = {X_real, P_real(X,Y)}
**Objective**: Minimize E_{(x,y)~P_real}[L(π(x), y)] using samples from P_sim

The domain adaptation loss with discrepancy metric HΔH can be expressed as:
L_target(π) ≤ L_source(π) + disc_HΔH(P_sim, P_real) + λ

Where λ is a constant dependent on optimal joint error.

## Advanced Domain Randomization Techniques

### Distributional Domain Randomization

Instead of uniform randomization, use learned distributions:

**Learned Distribution Priors**:
Let θ be domain parameters (physics properties, visual properties, etc.)
p(θ) ~ N(μ_θ, Σ_θ) # Learn distribution over simulation parameters

**Adversarial Domain Randomization**:
min_π max_θ_adv L_sim(π, θ) + β D_JS(P_sim(θ), P_real)

Where D_JS is Jensen-Shannon divergence between simulation and real distributions.

class SensitivityGuidedRandomization:
    def __init__(self, simulation_model, parameter_bounds):
        self.model = simulation_model
        self.bounds = parameter_bounds
        
        # Compute parameter sensitivity using adjoint method
        self.sensitivity_matrix = self.compute_sensitivity_matrix()
        
        # Determine randomization ranges based on sensitivity
        self.randomization_ranges = self.compute_adaptive_ranges(
            self.sensitivity_matrix
        )
    
    def compute_sensitivity_matrix(self):
        """
        Compute sensitivity matrix using adjoint method:
        S_{ij} = ∂J/∂θ_i where J is performance metric and θ_i is parameter i
        """
        sensitivity_matrix = np.zeros((self.parameter_dim, self.parameter_dim))
        
        # For each parameter, compute gradient of performance
        for i in range(self.parameter_dim):
            # Perturb parameter θ_i slightly
            param_perturbed = self.nominal_params.copy()
            param_perturbed[i] += 1e-6
            
            # Compute performance change
            perf_original = self.evaluate_performance(self.nominal_params)
            perf_perturbed = self.evaluate_performance(param_perturbed)
            
            sensitivity_matrix[:, i] = (perf_perturbed - perf_original) / 1e-6
        
        return sensitivity_matrix
    
    def compute_adaptive_ranges(self, sensitivity_matrix):
        """Compute randomization ranges based on parameter sensitivity"""
        ranges = []
        for i in range(self.parameter_dim):
            # Higher sensitivity → wider randomization range
            sensitivity_norm = np.linalg.norm(sensitivity_matrix[i, :])
            
            # Base range multiplied by sensitivity factor
            base_range = self.bounds[i][1] - self.bounds[i][0]
            adaptive_range = base_range * (1 + np.tanh(sensitivity_norm))
            
            ranges.append(adaptive_range)
        return ranges
    
    def randomize_simulation(self):
        """Apply sensitivity-guided randomization to simulation"""
        randomized_params = []
        for i, (param_min, param_max) in enumerate(self.bounds):
            # Use sensitivity-adaptive range
            adaptive_range = self.randomization_ranges[i]
            center = (param_min + param_max) / 2.0
            range_half = adaptive_range / 2.0
            
            # Randomize around center with adaptive range
            param_value = np.random.uniform(
                max(param_min, center - range_half),
                min(param_max, center + range_half)
            )
            randomized_params.append(param_value)
        
        return np.array(randomized_params)

from scipy.optimize import minimize
import autograd.numpy as anp
from autograd import grad, jacobian

class PhysicsParameterEstimator:
    def __init__(self, robot_model):
        self.model = robot_model
        self.parameters = ['mass', 'friction', 'inertia', 'gear_ratio']
    
    def likelihood_function(self, params, observations):
        """
        Compute negative log-likelihood for parameter estimation
        """
        # Set model parameters
        for i, param_name in enumerate(self.parameters):
            setattr(self.model, param_name, params[i])
        
        # Compute prediction errors
        total_neg_log_likelihood = 0
        for obs in observations:
            predicted_state = self.model.predict(
                obs['state'], obs['action'], obs['dt']
            )
            error = obs['next_state'] - predicted_state
            
            # Assume Gaussian noise
            noise_variance = getattr(self.model, 'noise_variance', 0.01)
            log_likelihood = -0.5 * error**2 / noise_variance
            total_neg_log_likelihood -= log_likelihood
        
        return total_neg_log_likelihood
    
    def estimate_parameters(self, real_robot_data, initial_guess=None):
        """Estimate physics parameters using MLE"""
        if initial_guess is None:
            initial_guess = [1.0] * len(self.parameters)  # Default values
        
        # Optimize parameters to minimize negative log-likelihood
        result = minimize(
            fun=self.likelihood_function,
            x0=initial_guess,
            args=(real_robot_data,),
            method='BFGS',
            jac=grad(self.likelihood_function)
        )
        
        return result.x  # Optimal parameters

class BayesianSystemIdentification:
    """
    Bayesian approach to system identification

    def __init__(self, dynamics_model, prior_distribution):
        self.model = dynamics_model
        self.prior = prior_distribution  # Prior over parameters
        self.posterior_samples = []
    
    def posterior_sampling(self, real_data, n_samples=1000):
        """
        Sample from posterior distribution using MCMC
        """
        # Initialize with MAP estimate
        current_params = self.find_map_estimate(real_data)
        accepted_samples = [current_params]
        
        for i in range(n_samples):
            # Propose new parameters (Metropolis-Hastings)
            proposal = current_params + np.random.normal(0, 0.1, len(current_params))
            
            # Compute acceptance probability
            acceptance_prob = min(1.0, self.compute_acceptance_ratio(
                proposal, current_params, real_data
            ))
            
            if np.random.random() < acceptance_prob:
                current_params = proposal
                accepted_samples.append(current_params.copy())
        
        self.posterior_samples = accepted_samples
        return accepted_samples
    
    def compute_acceptance_ratio(self, proposal, current, data):
        """Compute Metropolis-Hastings acceptance ratio"""
        # Prior ratio
        prior_proposal = self.prior.logpdf(proposal)
        prior_current = self.prior.logpdf(current)
        prior_ratio = prior_proposal - prior_current
        
        # Likelihood ratio
        likelihood_proposal = self.compute_likelihood(proposal, data)
        likelihood_current = self.compute_likelihood(current, data)
        likelihood_ratio = likelihood_proposal - likelihood_current
        
        return np.exp(prior_ratio + likelihood_ratio)
    
    def compute_likelihood(self, params, data):
        """Compute log-likelihood of data given parameters"""
        log_likelihood = 0
        for obs in data:
            # Set parameters and compute prediction
            self.model.set_parameters(params)
            predicted = self.model.predict(obs['state'], obs['action'])
            
            # Compute likelihood of observation
            error = obs['measurement'] - predicted
            noise_cov = self.model.noise_covariance
            log_likelihood += -0.5 * error.T @ np.linalg.inv(noise_cov) @ error
        
        return log_likelihood

import ot  # Python Optimal Transport library

class OptimalTransportAdapter:
    def __init__(self, sim_data, real_data):
        self.sim_data = sim_data
        self.real_data = real_data
        
        # Compute optimal transport mapping
        self.transport_mapping = self.compute_transport_mapping()
    
    def compute_transport_mapping(self):
        """
        Compute optimal transport map between sim and real distributions
        """
        # Compute cost matrix (typically Euclidean distance squared)
        n_sim, n_real = len(self.sim_data), len(self.real_data)
        C = np.zeros((n_sim, n_real))
        
        for i in range(n_sim):
            for j in range(n_real):
                C[i, j] = np.sum((self.sim_data[i] - self.real_data[j])**2)
        
        # Compute optimal transport plan using Sinkhorn algorithm
        # Add entropic regularization for stability
        reg = 0.1  # Entropy regularization parameter
        a = np.ones(n_sim) / n_sim  # Sim marginal
        b = np.ones(n_real) / n_real  # Real marginal
        
        transport_plan = ot.sinkhorn(a, b, C, reg)
        
        return transport_plan
    
    def adapt_simulation_data(self, sim_samples):
        """
        Transform simulation data to match real distribution using OT mapping
        """
        adapted_samples = []
        
        for sim_sample in sim_samples:
            # Find closest real samples and interpolate
            sim_idx = self.find_closest_sim_sample(sim_sample)
            
            # Use transport plan for probabilistic mapping
            transport_row = self.transport_mapping[sim_idx, :]
            
            # Weighted combination based on transport plan
            adapted_sample = np.zeros_like(sim_sample)
            for real_idx, weight in enumerate(transport_row):
                if weight > 1e-6:  # Significant transport weight
                    contribution = weight * self.real_data[real_idx]
                    adapted_sample += contribution
            
            adapted_samples.append(adapted_sample)
        
        return np.array(adapted_samples)
    
    def compute_sim_to_real_loss(self):
        """Compute Wasserstein distance between distributions"""
        # Define cost matrix
        C = np.zeros((len(self.sim_data), len(self.real_data)))
        for i in range(len(self.sim_data)):
            for j in range(len(self.real_data)):
                C[i, j] = np.sum((self.sim_data[i] - self.real_data[j])**2)
        
        # Compute regularized Wasserstein distance
        reg = 0.1
        a = np.ones(len(self.sim_data)) / len(self.sim_data)
        b = np.ones(len(self.real_data)) / len(self.real_data)
        
        wasserstein_dist = ot.sinkhorn2(a, b, C, reg)
        return wasserstein_dist

### Model Reference Adaptive Control (MRAC)

MRAC adapts control parameters to compensate for model uncertainties:

```python
class ModelReferenceAdaptiveControl:
    def __init__(self, reference_model, plant_model, adaptation_gain=0.1):
        self.reference_model = reference_model
        self.plant_model = plant_model
        self.gamma = adaptation_gain
        
        # Adaptive parameter estimates
        self.theta_hat = np.zeros(plant_model.parameter_dim)
        
        # Adaptation state
        self.error_integrator = np.zeros(plant_model.state_dim)
    
    def control_law(self, state, reference_state):
        """
        MRAC control law with parameter adaptation
        """
        # Tracking error
        e = reference_state - state
        
        # Reference model control (ideal behavior)
        u_mr = self.reference_model.get_command(state, reference_state)
        
        # Adaptive compensation
        phi = self.regresor_function(state)  # Regressor vector
        u_adaptive = phi.T @ self.theta_hat  # Adaptive control term
        
        # Total control
        u = u_mr + u_adaptive
        
        # Parameter update law (gradient descent)
        s = self.error_integrator + e  # Augmented error
        param_update = self.gamma * np.outer(s, phi)  # Parameter adaptation
        
        # Update adaptive parameters
        self.theta_hat += param_update.flatten() * self.dt
        
        return u
    
    def regressor_function(self, state):
        """
        Regressor function that captures unknown dynamics
        """
        # Example: nonlinear terms in dynamics
        phi = np.array([
            state[0]**2,  # x^2 term
            state[1]**2,  # y^2 term
            state[0] * state[1],  # xy cross-term
            np.sin(state[0]),  # sin(x) term
            np.cos(state[1])   # cos(y) term
        ])
        return phi
```

        self.feature_extractor = nn.Sequential(
            nn.Linear(input_dim, 512),
            nn.ReLU(),
            nn.Linear(512, feature_dim),
            nn.ReLU(),
            nn.Linear(feature_dim, feature_dim),
            nn.ReLU()
        )
        
        # Task prediction network
        self.task_predictor = nn.Sequential(
            nn.Linear(feature_dim, 256),
            nn.ReLU(),
            nn.Linear(256, output_dim)
        )
        
        # Domain classifier
        self.domain_classifier = nn.Sequential(
            nn.Linear(feature_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 1),
            nn.Sigmoid()
        )
        
        # Gradient reversal layer
        self.gradient_reversal = GradientReversalFn.apply
    
    def forward(self, x, alpha=1.0):
        """
        Forward pass with domain confusion
        alpha: adaptation strength parameter
        """
        # Extract features
        features = self.feature_extractor(x)
        
        # Task prediction
        task_output = self.task_predictor(features)
        
        # Domain confusion (reverse gradients)
        reversed_features = self.gradient_reversal(features, alpha)
        domain_output = self.domain_classifier(reversed_features)
        
        return task_output, domain_output

class GradientReversalFn(torch.autograd.Function):
    """
    Gradient Reversal Layer - forwards input unchanged,
    reverses gradients during backprop
    """
    @staticmethod
    def forward(ctx, input, alpha):
        ctx.alpha = alpha
        return input

    @staticmethod
    def backward(ctx, grad_output):
        output = grad_output.neg() * ctx.alpha
        return output, None

def domain_adversarial_training(model, sim_loader, real_loader, epochs=100):
    """
    Train model with domain adversarial loss
    """
    task_criterion = nn.MSELoss()
    domain_criterion = nn.BCELoss()
    
    optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
    
    for epoch in range(epochs):
        for (sim_batch, real_batch) in zip(sim_loader, real_loader):
            # Prepare data (alternating between sim and real)
            combined_data = torch.cat([sim_batch.x, real_batch.x])
            sim_labels = torch.zeros(len(sim_batch.x))
            real_labels = torch.ones(len(real_batch.x))
            domain_labels = torch.cat([sim_labels, real_labels])
            
            # Forward pass
            task_pred, domain_pred = model(combined_data)
            
            # Task-specific loss (on sim data only)
            task_loss = task_criterion(task_pred[:len(sim_batch)], sim_batch.targets)
            
            # Domain confusion loss
            domain_loss = domain_criterion(domain_pred.squeeze(), domain_labels)
            
            # Combined loss
            total_loss = task_loss - domain_loss  # Note: minus sign for adversarial
            
            # Update parameters
            optimizer.zero_grad()
            total_loss.backward()
            optimizer.step()

    physics_params = torch.tensor(
        [1.0, 0.1, 0.5],  # mass, friction, etc.
        requires_grad=True
    )
    
    optimizer = torch.optim.Adam([physics_params], lr=1e-2)
    
    for iteration in range(n_iterations):
        # Reset simulation with current parameters
        sim_env.update_physics_parameters(physics_params)
        
        # Rollout policy in simulation
        sim_trajectory = rollout_policy(sim_env, policy_network)
        
        # Compare with real robot trajectory
        real_trajectory = collect_real_trajectory(real_robot, policy_network)
        
        # Compute trajectory matching loss
        loss = compute_trajectory_mismatch(sim_trajectory, real_trajectory)
        
        # Backpropagate through simulation
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        
        if iteration % 10 == 0:
            print(f"Iteration {iteration}: Loss = {loss.item():.4f}")
    
    return physics_params.detach().numpy()

        # Apply action to both simulation and real robot
        self.sim_env.apply_action(action)
        self.real_actuators.execute(action)
        
        # Step both systems
        self.sim_env.step(self.dt)
        
        # Wait for real system to respond (based on real_time_factor)
        self.wait_for_real_system_response()
        
        # Validate consistency between sim and real
        consistency_error = self.validate_consistency()
        return consistency_error
    
    def sync_simulation_to_real(self, real_sensor_data):
        """
        Synchronize simulation state with real robot state
        """
        # Map real sensor data to simulation state
        sim_state = self.map_sensors_to_state(real_sensor_data)
        
        # Update simulation to match real state
        self.sim_env.set_state(sim_state)

        """
        sim_sensor_data = self.sim_env.get_sensor_data()
        real_sensor_data = self.acquire_real_sensor_data()
        
        # Compute consistency error
        error = np.mean((sim_sensor_data - real_sensor_data)**2)

def compute_maximum_mean_discrepancy(sim_samples, real_samples, kernel='rbf', sigma=1.0):
    """
    Compute Maximum Mean Discrepancy (MMD) between sim and real distributions
    """
    def rbf_kernel(x1, x2, sigma=sigma):
        """Radial basis function kernel"""
        return np.exp(-np.linalg.norm(x1 - x2)**2 / (2 * sigma**2))
    
    # Compute MMD using kernel mean embeddings
    n_sim, n_real = len(sim_samples), len(real_samples)
    
    # Within-domain similarities
    sim_sim = 0
    for i in range(n_sim):
        for j in range(n_sim):
            if i != j:  # Exclude diagonal
                sim_sim += rbf_kernel(sim_samples[i], sim_samples[j])
    sim_sim /= n_sim * (n_sim - 1)
    
    real_real = 0
    for i in range(n_real):
        for j in range(n_real):
            if i != j:  # Exclude diagonal
                real_real += rbf_kernel(real_samples[i], real_samples[j])
    real_real /= n_real * (n_real - 1)
    
    # Between-domain similarities
    sim_real = 0
    for i in range(n_sim):
        for j in range(n_real):
            sim_real += rbf_kernel(sim_samples[i], real_samples[j])
    sim_real /= n_sim * n_real
    
    # MMD formula
    mmd = sim_sim + real_real - 2 * sim_real
    return mmd

def compute_transfer_ratio(sim_performance, real_performance):
    """
    Compute transfer ratio to quantify how well sim transfers to reality
    """
    # Normalized performance: ratio of achieved performance to maximum possible
    normalized_sim = sim_performance / sim_performance.max()
    normalized_real = real_performance / real_performance.max()
    
    # Transfer ratio (higher means better transfer)
    transfer_ratio = normalized_real / normalized_sim
    return transfer_ratio

class MetaLearningSim2Real:
    """
    Model-Agnostic Meta-Learning (MAML) adapted for sim-to-real transfer
    """
    def __init__(self, base_policy, sim_envs, real_env):
        self.policy = base_policy
        self.sim_envs = sim_envs  # Multiple simulation environments
        self.real_env = real_env
        self.meta_lr = 0.01
        self.inner_lr = 0.001
        self.k = 20  # Number of inner updates
    
    def meta_training_step(self):
        """
        One step of meta-training across simulation environments
        """
        meta_loss = 0
        
        for sim_env in self.sim_envs:
            # Clone policy for environment-specific adaptation
            adapted_policy = copy.deepcopy(self.policy)
            
            # Inner loop: adapt to specific simulation environment
            for _ in range(self.k):
                # Sample trajectory in simulation
                sim_trajectory = self.collect_trajectory(sim_env, adapted_policy)
                
                # Compute loss and update adapted policy
                loss = self.compute_trajectory_loss(sim_trajectory)
                policy_grad = torch.autograd.grad(loss, adapted_policy.parameters())
                
                # Update adapted policy parameters
                for param, grad in zip(adapted_policy.parameters(), policy_grad):
                    param.data = param.data - self.inner_lr * grad
            
            # Test adapted policy on real environment
            real_trajectory = self.collect_trajectory(self.real_env, adapted_policy)
            real_loss = self.compute_trajectory_loss(real_trajectory)
            
            meta_loss += real_loss
        
        # Outer loop: update base policy
        meta_loss /= len(self.sim_envs)
        meta_loss.backward()
        
        return meta_loss.item()
    
    def adapt_to_real_world(self, real_experience):
        """
        Adapt policy to real world using meta-learned initialization
        """
        # Fine-tune policy with real experience
        for _ in range(10):  # Few adaptation steps
            real_loss = self.compute_experience_loss(real_experience)
            real_loss.backward()
            
            # Small learning rate for adaptation
            for param in self.policy.parameters():
                param.data = param.data - self.inner_lr * param.grad
                param.grad.zero_()
        
        return self.policy

class TransferValidator:
    def __init__(self, sim_env, real_env, policy_network):
        self.sim_env = sim_env
        self.real_env = real_env
        self.policy = policy_network
        self.metrics = []
    
    def validate_transfer(self):
        """
        Comprehensive validation of sim-to-real transfer
        """
        validation_results = {}
        
        # Sim-to-sim validation (baseline)
        sim_performance = self.evaluate_policy(self.sim_env)
        validation_results['sim_baseline'] = sim_performance
        
        # Sim-to-real transfer without adaptation
        transfer_performance = self.evaluate_policy(
            self.real_env, adapted=False
        )
        validation_results['direct_transfer'] = transfer_performance
        
        # Sim-to-real with adaptation
        adapted_performance = self.evaluate_policy(
            self.real_env, adapted=True
        )
        validation_results['adapted_transfer'] = adapted_performance
        
        # Robustness to environmental changes
        for env_condition in ['lighting', 'friction', 'mass_variation']:
            conditioned_performance = self.evaluate_under_condition(
                env_condition
            )
            validation_results[env_condition] = conditioned_performance
        
        return validation_results
    
    def evaluate_policy(self, environment, adapted=False):
        """
        Evaluate policy in given environment
        """
        total_reward = 0
        success_count = 0
        episode_count = 10  # Evaluate over 10 episodes
        
        for episode in range(episode_count):
            state = environment.reset()
            episode_reward = 0
            done = False
            
            while not done:
                action = self.policy(state)
                state, reward, done, info = environment.step(action)
                episode_reward += reward
            
            total_reward += episode_reward
            if info.get('success', False):
                success_count += 1
        
        avg_reward = total_reward / episode_count
        success_rate = success_count / episode_count
        
        return {
            'avg_reward': avg_reward,
            'success_rate': success_rate
        }

def uncertainty_quantification_for_transfer(model, data_loader):
    """
    Quantify uncertainty to assess transfer suitability
    """
    predictions = []
    uncertainties = []
    
    for batch in data_loader:
        # Enable dropout for uncertainty estimation
        model.train()
        
        batch_predictions = []
        for _ in range(100):  # Monte Carlo samples
            pred = model(batch.x)
            batch_predictions.append(pred.detach().cpu().numpy())
        
        batch_predictions = np.array(batch_predictions)
        
        # Compute mean and uncertainty
        mean_pred = np.mean(batch_predictions, axis=0)
        uncertainty = np.std(batch_predictions, axis=0)
        
        predictions.extend(mean_pred)
        uncertainties.extend(uncertainty)
    
    return np.array(predictions), np.array(uncertainties)
