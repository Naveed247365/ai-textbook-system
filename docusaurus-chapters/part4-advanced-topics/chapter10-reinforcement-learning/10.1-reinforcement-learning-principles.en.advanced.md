# Reinforcement Learning Principles (English Advanced Version)

## Chapter Overview

Reinforcement Learning (RL) represents a mathematical framework grounded in optimal control theory, dynamic programming, and Markov decision processes for sequential decision-making under uncertainty. The theoretical foundations encompass Bellman's principle of optimality, convergence analysis of temporal difference learning, and the mathematical formulation of policy gradients in function approximation spaces. Advanced RL incorporates stochastic optimization, information theory, and game theory to develop principled algorithms for complex decision-making problems.

### Mathematical Foundations

The fundamental RL problem can be formulated as a Markov Decision Process (MDP):

M = (S, A, P, R, γ, μ)

Where:
- S: State space (possibly continuous and infinite)
- A: Action space (discrete or continuous)
- P: Transition probabilities P(s'|s,a) = Pr[S_{t+1} = s' | S_t = s, A_t = a]
- R: Reward function R(s,a,s')
- γ: Discount factor γ ∈ [0,1]
- μ: Initial state distribution

The objective is to find an optimal policy π* that maximizes expected discounted return:

J(π) = E[Σ_{t=0}^∞ γ^t R(s_t, a_t) | π]

### Formal Framework

The Bellman equation for the optimal value function:

V*(s) = max_a E[R(s,a,S') + γ V*(S') | S=s, A=a]

And the corresponding optimal action-value function:

Q*(s,a) = E[R(s,a,S') + γ max_{a'} Q*(S', a') | S=s, A=a]

## Advanced RL Algorithms

### Temporal Difference Learning

Temporal difference methods combine Monte Carlo and dynamic programming approaches:

**TD(0) Update Rule**:
V(S_t) ← V(S_t) + α[R_{t+1} + γV(S_{t+1}) - V(S_t)]

**TD(λ) with Eligibility Traces**:
E_t(s) = λγE_{t-1}(s) + ∇_θ V(s;θ) if S_t = s, else 0
θ ← θ + αδ_tE_t

### Sarsa and Q-Learning

**Sarsa (On-policy TD Control)**:
Q(S_t, A_t) ← Q(S_t, A_t) + α[R_{t+1} + γQ(S_{t+1}, A_{t+1}) - Q(S_t, A_t)]

**Q-Learning (Off-policy TD Control)**:
Q(S_t, A_t) ← Q(S_t, A_t) + α[R_{t+1} + γmax_a Q(S_{t+1}, a) - Q(S_t, A_t)]

### Policy Gradient Methods

Policy gradient methods optimize the policy directly by gradient ascent:

J(θ) = E_π_θ[G_0] = ∫_s d^{π_θ}(s) ∫_a π_θ(a|s) Q^{π_θ}(s,a) da ds

Where d^{π_θ}(s) is the stationary state distribution under policy π_θ.

**REINFORCE Algorithm**:
∇_θ J(θ) = E[Σ_{t=0}^T ∇_θ log π_θ(A_t|S_t) G_t]

**Actor-Critic Methods**:
∇_θ J(θ) ≈ E[∇_θ log π_θ(A|S) Q_w(S,A)]

### Actor-Critic Architectures

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class ActorCritic(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super(ActorCritic, self).__init__()
        
        # Shared feature extractor
        self.shared_layers = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Actor: outputs action probabilities (for discrete) or mean/std (for continuous)
        self.actor_mean = nn.Linear(hidden_dim, action_dim)
        self.actor_std = nn.Parameter(torch.ones(action_dim) * 0.1)
        
        # Critic: outputs state value
        self.critic = nn.Linear(hidden_dim, 1)
    
    def forward(self, state):
        features = self.shared_layers(state)
        
        # Actor: compute action distribution parameters
        action_mean = self.actor_mean(features)
        action_std = F.softplus(self.actor_std)  # Ensure positivity
        
        # Critic: compute state value
        state_value = self.critic(features)
        
        return action_mean, action_std, state_value

class AdvantageActorCritic(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super(AdvantageActorCritic, self).__init__()
        
        # Shared layers
        self.feature_extractor = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Actor network
        self.actor = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim),
            nn.Softmax(dim=-1)  # For discrete actions
        )
        
        # Critic network
        self.critic = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )
    
    def forward(self, state):
        features = self.feature_extractor(state)
        action_probs = self.actor(features)
        state_value = self.critic(features)
        return action_probs, state_value
```

```python
class DeepQNetwork(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):

class DoubleDQN(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super(DoubleDQN, self).__init__()
        
        # Two networks: online and target
        self.online_network = DeepQNetwork(state_dim, action_dim, hidden_dim)
        self.target_network = DeepQNetwork(state_dim, action_dim, hidden_dim)
        
        # Copy weights initially
        self.target_network.load_state_dict(self.online_network.state_dict())
    
    def forward(self, state, network='online'):
        if network == 'online':
            return self.online_network(state)
        elif network == 'target':
            return self.target_network(state)

class DuelingDQN(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super(DuelingDQN, self).__init__()
        
        # Shared feature layer
        self.feature_layer = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU()
        )
        
        # Value stream
        self.value_stream = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, 1)
        )
        
        # Advantage stream
        self.advantage_stream = nn.Sequential(
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim)
        )
    
    def forward(self, state):
        features = self.feature_layer(state)
        
        # Compute value and advantages
        value = self.value_stream(features)
        advantages = self.advantage_stream(features)
        
        # Combine using dueling architecture
        q_values = value + (advantages - advantages.mean(dim=1, keepdim=True))
        return q_values
```

## Advanced Exploration Strategies

### Upper Confidence Bound (UCB) and Thompson Sampling

```python
class UCBExploration:
    def __init__(self, n_actions, c=2):
        self.n_actions = n_actions
        self.c = c  # Exploration parameter
        self.action_counts = np.zeros(n_actions)
        self.action_values = np.zeros(n_actions)
        self.total_steps = 0
    
    def select_action(self, state):
        self.total_steps += 1
        
        # Choose action with highest UCB value
        ucb_values = np.zeros(self.n_actions)
        for a in range(self.n_actions):
            if self.action_counts[a] == 0:
                return a  # Try unexplored actions first
            
            ucb_values[a] = (self.action_values[a] + 
                           self.c * np.sqrt(np.log(self.total_steps) / self.action_counts[a]))
        
        return np.argmax(ucb_values)

class ThompsonSampling:
    def __init__(self, n_actions):
        self.n_actions = n_actions
        # Beta distribution parameters (alpha, beta) for each action
        self.alpha = np.ones(n_actions)
        self.beta = np.ones(n_actions)
    
    def select_action(self, state):
        # Sample from beta distribution for each action
        samples = [np.random.beta(self.alpha[a], self.beta[a]) for a in range(self.n_actions)]
        return np.argmax(samples)
    
    def update(self, action, reward):
        # Update beta distribution based on reward (0 or 1)
        self.alpha[action] += reward
        self.beta[action] += (1 - reward)
```

### Intrinsic Motivation and Curiosity-Driven Learning

```python
class IntrinsicMotivation:
    def __init__(self, state_dim, action_dim, hidden_dim=256, lr=1e-4):
        # Forward model: predicts next state given current state and action
        self.forward_model = nn.Sequential(
            nn.Linear(state_dim + action_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, state_dim)
        )
        
        # Inverse model: predicts action given state transitions
        self.inverse_model = nn.Sequential(
            nn.Linear(2 * state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim)
        )
        
        self.forward_optimizer = torch.optim.Adam(self.forward_model.parameters(), lr=lr)
        self.inverse_optimizer = torch.optim.Adam(self.inverse_model.parameters(), lr=lr)
        
        self.intrinsic_scale = 0.1
    
    def compute_intrinsic_reward(self, state, action, next_state):
        """Compute curiosity bonus based on prediction error"""
        # Predict next state using forward model
        state_action = torch.cat([state, action], dim=-1)
        predicted_next_state = self.forward_model(state_action)
        
        # Compute prediction error (curiosity)
        error = (predicted_next_state - next_state).pow(2).mean(dim=-1)
        
        return self.intrinsic_scale * error
    
    def update_models(self, states, actions, next_states):
        """Update forward and inverse models"""
        # Update forward model
        state_action = torch.cat([states, actions], dim=-1)
        predicted_next_states = self.forward_model(state_action)
        forward_loss = F.mse_loss(predicted_next_states, next_states)
        
        self.forward_optimizer.zero_grad()
        forward_loss.backward()
        self.forward_optimizer.step()
        
        # Update inverse model
        state_pairs = torch.cat([states, next_states], dim=-1)
        predicted_actions = self.inverse_model(state_pairs)
        inverse_loss = F.mse_loss(predicted_actions, actions)
        
        self.inverse_optimizer.zero_grad()
        inverse_loss.backward()
        self.inverse_optimizer.step()
```

### Dyna Architecture

The Dyna architecture combines real experience with model-based planning:

```python
class DynaAgent:
    def __init__(self, model, planner, real_env, n_simulated_updates=10):
        self.model = model  # Learned environment model
        self.planner = planner  # Planning algorithm (e.g., value iteration)
        self.real_env = real_env
        self.n_simulated_updates = n_simulated_updates
    
    def train_step(self, state, action, reward, next_state, done):
        # Update model with real interaction
        self.model.update(state, action, reward, next_state, done)
        
        # Update policy with real experience
        self.update_policy_real(state, action, reward, next_state, done)
        
        # Perform simulated updates using learned model
        for _ in range(self.n_simulated_updates):
            # Sample experience from model
            sim_state = self.model.sample_state()
            sim_action = self.select_action(sim_state)  # Follow current policy
            sim_reward, sim_next_state = self.model.predict(sim_state, sim_action)
            
            # Update policy with simulated experience
            self.update_policy_simulated(sim_state, sim_action, sim_reward, sim_next_state)

class WorldModel(nn.Module):
    def __init__(self, state_dim, action_dim):
        super(WorldModel, self).__init__()
        
        # State transition model
        self.transition_net = nn.Sequential(
            nn.Linear(state_dim + action_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, state_dim)
        )
        
        # Reward model
        self.reward_net = nn.Sequential(
            nn.Linear(state_dim + action_dim, 256),
            nn.ReLU(),
            nn.Linear(256, 256),
            nn.ReLU(),
            nn.Linear(256, 1)
        )
    
    def forward(self, state, action):
        state_action = torch.cat([state, action], dim=-1)
        next_state_delta = self.transition_net(state_action)
        next_state = state + next_state_delta  # Residual update
        reward = self.reward_net(state_action)
        return next_state, reward
    
    def predict(self, state, action):
        with torch.no_grad():
            next_state, reward = self.forward(state, action)
        return reward.item(), next_state
```

### Model Predictive Control (MPC) Integration

```python
class MPCPlanner:
    def __init__(self, model, horizon=10, n_candidates=1000):
        self.model = model
        self.horizon = horizon
        self.n_candidates = n_candidates
    
    def plan(self, initial_state, goal_state):
        best_action_sequence = None
        best_return = float('-inf')
        
        for _ in range(self.n_candidates):
            # Sample random action sequence
            action_sequence = torch.randn(self.horizon, initial_state.shape[-1])
            action_sequence = torch.tanh(action_sequence)  # Clamp to [-1, 1]
            
            # Simulate trajectory
            state = initial_state.clone()
            total_return = 0
            
            for t in range(self.horizon):
                # Predict next state using model
                next_state, reward = self.model(state.unsqueeze(0), 
                                               action_sequence[t].unsqueeze(0))
                
                # Compute reward (distance to goal)
                goal_reward = -torch.norm(next_state[:2] - goal_state[:2])
                total_return += (0.9 ** t) * (reward + goal_reward)
                
                state = next_state.squeeze(0)
            
            if total_return > best_return:
                best_return = total_return
                best_action_sequence = action_sequence.clone()
        
        # Return first action of best sequence
        return best_action_sequence[0] if best_action_sequence is not None else None
```

## Advanced Policy Optimization

### Trust Region Policy Optimization (TRPO)

TRPO constrains policy updates to prevent large policy changes:

```python
def trpo_compute_kl_divergence(pi_old, pi_new, states, actions):
    """Compute KL divergence between old and new policies"""
    with torch.no_grad():
        log_prob_old = pi_old.get_log_prob(states, actions)
    log_prob_new = pi_new.get_log_prob(states, actions)
    return (log_prob_old - log_prob_new).mean()

def trpo_line_search(f, x, fullstep, expected_improve_rate):
    """Perform line search for TRPO"""
    accept_ratio = 0.1
    max_backtracks = 10
    for (_n_backtracks, stepfrac) in enumerate(.5 ** np.arange(max_backtracks)):
        x_new = x - stepfrac * fullstep
        improve = f(x) - f(x_new)
        if improve >= 0 and stepfrac * expected_improve_rate >= improve * accept_ratio:
            return x_new
    return x
```

### Proximal Policy Optimization (PPO)

PPO approximates TRPO with simpler clipping mechanism:

```python
class PPO:
    def __init__(self, policy, value_net, clip_epsilon=0.2, lr=3e-4):
        self.policy = policy
        self.value_net = value_net
        self.clip_epsilon = clip_epsilon
        self.policy_optimizer = torch.optim.Adam(policy.parameters(), lr=lr)
        self.value_optimizer = torch.optim.Adam(value_net.parameters(), lr=lr)
    
    def compute_loss(self, states, actions, old_log_probs, returns, advantages):
        # Compute new action probabilities
        new_log_probs, entropy = self.policy.get_log_prob_and_entropy(states, actions)
        
        # Compute ratio
        ratio = torch.exp(new_log_probs - old_log_probs)
        
        # PPO surrogate loss
        surr1 = ratio * advantages
        surr2 = torch.clamp(ratio, 1.0 - self.clip_epsilon, 1.0 + self.clip_epsilon) * advantages
        policy_loss = -torch.min(surr1, surr2).mean() - 0.01 * entropy.mean()
        
        # Value loss
        values = self.value_net(states)
        value_loss = F.mse_loss(values, returns)
        
        return policy_loss, value_loss
    
    def update(self, states, actions, old_log_probs, returns, advantages):
        policy_loss, value_loss = self.compute_loss(states, actions, old_log_probs, returns, advantages)
        
        # Update policy
        self.policy_optimizer.zero_grad()
        policy_loss.backward()
        torch.nn.utils.clip_grad_norm_(self.policy.parameters(), 0.5)
        self.policy_optimizer.step()
        
        # Update value function
        self.value_optimizer.zero_grad()
        value_loss.backward()
        torch.nn.utils.clip_grad_norm_(self.value_net.parameters(), 0.5)
        self.value_optimizer.step()
```

### Soft Actor-Critic (SAC)

SAC is an off-policy maximum entropy algorithm:

```python
class SoftActorCritic:
    def __init__(self, state_dim, action_dim, hidden_dim=256, alpha=0.2):
        # Actor (policy network)
        self.actor = GaussianPolicy(state_dim, action_dim, hidden_dim)
        
        # Critic networks (Q-functions)
        self.critic1 = QNetwork(state_dim, action_dim, hidden_dim)
        self.critic2 = QNetwork(state_dim, action_dim, hidden_dim)
        
        # Target networks
        self.critic1_target = copy.deepcopy(self.critic1)
        self.critic2_target = copy.deepcopy(self.critic2)
        
        # Optimizers
        self.actor_optimizer = torch.optim.Adam(self.actor.parameters(), lr=3e-4)
        self.critic_optimizer = torch.optim.Adam(
            list(self.critic1.parameters()) + list(self.critic2.parameters()), 
            lr=3e-4
        )
        
        # Entropy temperature
        self.target_entropy = -torch.prod(torch.Tensor(action_dim)).item()
        self.log_alpha = torch.zeros(1, requires_grad=True)
        self.alpha_optimizer = torch.optim.Adam([self.log_alpha], lr=3e-4)
        self.alpha = alpha
    
    def update(self, replay_buffer, batch_size=256):
        state, action, reward, next_state, done = replay_buffer.sample(batch_size)
        
        # Compute target Q-values
        with torch.no_grad():
            next_action, next_log_prob, _ = self.actor.sample(next_state)
            next_q1 = self.critic1_target(next_state, next_action)
            next_q2 = self.critic2_target(next_state, next_action)
            next_q = torch.min(next_q1, next_q2) - self.alpha * next_log_prob
            target_q = reward + (1 - done) * 0.99 * next_q
        
        # Critic update
        current_q1 = self.critic1(state, action)
        current_q2 = self.critic2(state, action)
        critic_loss = F.mse_loss(current_q1, target_q) + F.mse_loss(current_q2, target_q)
        
        self.critic_optimizer.zero_grad()
        critic_loss.backward()
        self.critic_optimizer.step()
        
        # Actor update
        pi, log_prob, _ = self.actor.sample(state)
        q1_pi = self.critic1(state, pi)
        q2_pi = self.critic2(state, pi)
        min_q_pi = torch.min(q1_pi, q2_pi)
        
        actor_loss = (self.alpha * log_prob - min_q_pi).mean()
        
        self.actor_optimizer.zero_grad()
        actor_loss.backward()
        self.actor_optimizer.step()
        
        # Alpha update
        alpha_loss = -(self.log_alpha * (log_prob + self.target_entropy).detach()).mean()
        self.alpha_optimizer.zero_grad()
        alpha_loss.backward()
        self.alpha_optimizer.step()
        self.alpha = self.log_alpha.exp()
```

```python
class IndependentQLearning:
    def __init__(self, n_agents, state_dim, action_dim, hidden_dim=256):
        self.agents = [DQN(state_dim, action_dim, hidden_dim) 
                      for _ in range(n_agents)]
        self.n_agents = n_agents
    
    def get_actions(self, states):
```

### Centralized Training with Decentralized Execution (CTDE)

```python
class MADDPG:
    """Multi-Agent Deep Deterministic Policy Gradient"""
    def __init__(self, n_agents, state_dims, action_dims, hidden_dim=256):
        self.n_agents = n_agents
        self.actors = [DDPGActor(state_dims[i], action_dims[i], hidden_dim) 
                      for i in range(n_agents)]
        self.critics = [DDPGCritic(sum(state_dims), sum(action_dims), hidden_dim) 
                       for _ in range(n_agents)]
        
        # Target networks
        self.target_actors = [copy.deepcopy(actor) for actor in self.actors]
        self.target_critics = [copy.deepcopy(critic) for critic in self.critics]
    
    def get_actions(self, states, add_noise=True):
        """Get actions for all agents (decentralized execution)"""
        actions = []
        for i in range(self.n_agents):
            action = self.actors[i](states[i].unsqueeze(0))
            if add_noise:
                noise = torch.randn_like(action) * 0.1
                action += noise
            actions.append(action.clamp(-1, 1))
        return actions
    
    def centralized_critic_training(self, states, actions, rewards, next_states):
        """Use centralized information for training (CTDE)"""
        all_actions = torch.cat(actions, dim=1)
        all_states = torch.cat(states, dim=1)
        
        # Update critics using centralized information
        for i in range(self.n_agents):
            next_actions = []
            for j in range(self.n_agents):
                next_action = self.target_actors[j](next_states[j])
                next_actions.append(next_action)
            all_next_actions = torch.cat(next_actions, dim=1)
            all_next_states = torch.cat(next_states, dim=1)
            
            with torch.no_grad():
                target_q = rewards[i] + 0.99 * self.target_critics[i](
                    all_next_states, all_next_actions
                )
            
            current_q = self.critics[i](all_states, all_actions)
            critic_loss = F.mse_loss(current_q, target_q.detach())
            
            self.critics[i].optimizer.zero_grad()
            critic_loss.backward()
            self.critics[i].optimizer.step()
```

## Advanced Topics in RL

### Hierarchical RL

Hierarchical RL decomposes complex tasks into subtasks:

```python
class OptionCritic:
    """Option-Critic architecture for hierarchical RL"""
    def __init__(self, state_dim, action_dim, n_options, hidden_dim=256):
        # Termination condition network
        self.termination_net = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, n_options),
            nn.Sigmoid()
        )
        
        # Option policy network
        self.option_policy = nn.Sequential(
            nn.Linear(state_dim + n_options, hidden_dim),  # + option identifier
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim),
            nn.Softmax(dim=-1)
        )
        
        # Q-function for options
        self.q_option = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, n_options)
        )
    
    def forward(self, state, option):
        """Forward pass for specific option"""
        state_option = torch.cat([state, F.one_hot(option, num_classes=self.n_options)], dim=-1)
        action_probs = self.option_policy(state_option)
        termination_probs = self.termination_net(state)
        q_values = self.q_option(state)
        
        return action_probs, termination_probs, q_values
```

### Distributional RL

Distributional RL learns the full distribution of returns instead of just expectations:

```python
class CategoricalDQN(nn.Module):
    """Categorical DQN - learns distribution over returns"""
    def __init__(self, state_dim, action_dim, n_atoms=51, v_min=-10.0, v_max=10.0):
        super(CategoricalDQN, self).__init__()
        self.n_atoms = n_atoms
        self.v_min = v_min
        self.v_max = v_max
        self.action_dim = action_dim
        
        # Support for the categorical distribution
        self.register_buffer('support', torch.linspace(v_min, v_max, n_atoms))
        self.delta_z = (v_max - v_min) / (n_atoms - 1)
        
        # Network outputs probability distribution over atoms
        self.network = nn.Sequential(
            nn.Linear(state_dim, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, action_dim * n_atoms)
        )
    
    def forward(self, state):
        logits = self.network(state)
        logits = logits.view(-1, self.action_dim, self.n_atoms)
        probs = F.softmax(logits, dim=-1)
        return probs
    
    def compute_q_values(self, state):
        """Compute expected Q-values from the distribution"""
        probs = self.forward(state)
        q_values = torch.sum(probs * self.support, dim=2)
        return q_values
```

## Sample Efficiency and Generalization

### Experience Replay Techniques

```python
class PrioritizedExperienceReplay:
    def __init__(self, capacity, alpha=0.6, beta_start=0.4):
        self.capacity = capacity
        self.alpha = alpha
        self.beta = beta_start
        self.memory = []
        self.priorities = []
        self.position = 0
    
    def push(self, state, action, reward, next_state, done, priority=None):
        if len(self.memory) < self.capacity:
            self.memory.append(None)
            self.priorities.append(None)
        
        if priority is None:
            priority = 1.0  # Default priority
        
        self.memory[self.position] = (state, action, reward, next_state, done)
        self.priorities[self.position] = priority
        self.position = (self.position + 1) % self.capacity
    
    def sample(self, batch_size, beta=None):
        if beta is None:
            beta = self.beta
        
        # Compute probabilities
        total = len(self.memory)
        priorities = np.array(self.priorities)
        probabilities = priorities ** self.alpha
        probabilities /= probabilities.sum()
        indices = np.random.choice(total, batch_size, p=probabilities)
        
        # Compute importance sampling weights
        weights = (total * probabilities[indices]) ** (-beta)
        weights /= weights.max()
        
        experiences = [self.memory[idx] for idx in indices]
        return experiences, indices, weights
    
    def update_priorities(self, batch_indices, td_errors):
        """Update priorities based on TD errors"""
        for idx, td_error in zip(batch_indices, td_errors):
            priority = td_error + 1e-5  # Small epsilon to avoid zero priority
            self.priorities[idx] = priority ** self.alpha
```

### Off-Policy Evaluation

Techniques for evaluating policies using data from different policies:

```python
def importance_sampling_evaluation(behavior_policy_probs, target_policy_probs, 
                                  rewards, discounts):
    """Off-policy evaluation using importance sampling"""
    # Compute importance weights
    weights = target_policy_probs / behavior_policy_probs
    weights = torch.clamp(weights, 0, 10)  # Clamp to prevent extreme ratios
    
    # Compute weighted returns
    weighted_returns = []
    for i, (r, d) in enumerate(zip(rewards, discounts)):
        accumulated = 0
        for j in range(i, len(rewards)):
            accumulated = r + d * accumulated
            if j == i:
                break
        weighted_returns.append(weights[i] * accumulated)
    
    return torch.mean(torch.tensor(weighted_returns))

def doubly_robust_estimation(behavior_policy_probs, target_policy_probs, rewards, 
                            q_values, discounts):
    """Doubly robust off-policy evaluation"""
    # Importance sampling term
    rho = target_policy_probs / behavior_policy_probs
    rho = torch.clamp(rho, 0, 10)
    
    # Direct method term
    dm_term = target_policy_probs * q_values
    
    # Doubly robust estimator
    dr_estimate = rho * (rewards + discounts * q_values) + dm_term - rho * q_values
    return torch.mean(dr_estimate)
```
