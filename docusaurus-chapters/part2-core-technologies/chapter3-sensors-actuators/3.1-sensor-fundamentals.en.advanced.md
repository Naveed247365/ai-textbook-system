# Sensor Fundamentals (English Advanced)

## Mathematical Foundations of Sensor Systems

### Sensor Measurement Model

A sensor measurement can be formally modeled as a stochastic process:

```
z_k = h(x_k) + v_k
```

Where:
- z_k ∈ ℝ^m: Measurement vector at time k
- x_k ∈ ℝ^n: True state vector at time k
- h: Nonlinear measurement function h: ℝ^n → ℝ^m
- v_k ~ N(0, R_k): Measurement noise with covariance R_k

### Probability Distributions and Estimation

**Likelihood Function**:
```
p(z_k|x_k) = (2π)^(-m/2) |R_k|^(-1/2) exp[-½(z_k - h(x_k))^T R_k^(-1) (z_k - h(x_k))]
```

**Maximum Likelihood Estimation**:
```
x̂_ML = argmax_x p(z_k|x_k)
```

**Minimum Mean Square Error (MMSE)**:
```
x̂_MMSE = E[x_k|z_k] = ∫ x_k p(x_k|z_k) dx_k
```

## Advanced Sensor Technologies

### Inertial Measurement Units (IMUs)

**State Space Model**:
```
ṗ = v + w_p
v̇ = R(a_body - g) + w_v
θ̇ = ω + w_θ
```

Where p is position, v is velocity, θ is orientation, R is rotation matrix, and w terms are process noise.

**Error State Kalman Filter**:
```
δx = [δp, δv, δθ, δb_a, δb_ω]^T
```

### LIDAR Systems

**3D Point Cloud Representation**:
```
P = {p_i | p_i = [x_i, y_i, z_i]^T, i = 1, 2, ..., N}
```

**Ray Casting Model**:
```
r(λ) = p_sensor + λd_direction
```

Where λ is the range parameter and d_direction is the unit direction vector.

### Time-of-Flight Sensors

**Physical Model**:
```
d = (c * Δt) / 2
```

Where c is the speed of light and Δt is the round-trip time.

**Intensity-Based Refinement**:
```
d_refined = d + k_1*I + k_2*I²
```

Where I is the received intensity and k_1, k_2 are calibration parameters.

## Sensor Fusion Algorithms

### Extended Kalman Filter (EKF)

**Prediction Step**:
```
x̂_k|k-1 = f(x̂_k-1|k-1, u_k-1)
P_k|k-1 = F_k P_k-1|k-1 F_k^T + Q_k-1
```

Where F_k = ∂f/∂x|_{x̂_k-1|k-1}

**Update Step**:
```
K_k = P_k|k-1 H_k^T (H_k P_k|k-1 H_k^T + R_k)^(-1)
x̂_k|k = x̂_k|k-1 + K_k (z_k - h(x̂_k|k-1))
P_k|k = (I - K_k H_k) P_k|k-1
```

Where H_k = ∂h/∂x|_{x̂_k|k-1}

### Unscented Kalman Filter (UKF)

**Sigma Point Generation**:
```
χ_0 = x̂
χ_i = x̂ + √[(n+λ)P]_i for i = 1, ..., n
χ_i = x̂ - √[(n+λ)P]_{i-n} for i = n+1, ..., 2n
```

**Prediction and Update**:
```
x̂_k|k-1 = Σ_{i=0}^{2n} W_i^(m) χ_i^*
P_k|k-1 = Σ_{i=0}^{2n} W_i^(c) [χ_i^* - x̂_k|k-1][χ_i^* - x̂_k|k-1]^T + Q_k-1
```

### Particle Filter

**Importance Sampling**:
```
x_k^(i) ~ π(x_k|x_k-1^(i), z_k)
w_k^(i) ∝ p(z_k|x_k^(i))p(x_k^(i)|x_k-1^(i)) / π(x_k^(i)|x_k-1^(i), z_k)
```

**Resampling**:
```
N_eff = 1 / Σ_{i=1}^N (w_k^(i))²
```

## Sensor Calibration and Error Modeling

### Geometric Calibration

**Camera Calibration**:
```
[u]   [f_x   0   c_x] [R  t] [X]
[v] = [0   f_y   c_y] [0  1] [Y]
[1]   [0    0     1 ] [Z]
    = K [R  t] [X Y Z]^T
```

Where K is the intrinsic matrix, R is rotation, and t is translation.

### Multi-Sensor Calibration

**Extrinsic Calibration**:
```
T_target_sensor = T_target_world * T_world_sensor
```

**Temporal Synchronization**:
```
t_sensor_corrected = t_sensor_raw + δt_offset
```

### Error Propagation

**Covariance Propagation**:
```
P_output = J_input * P_input * J_input^T
```

Where J_input is the Jacobian of the transformation.

## Advanced Sensor Technologies

### Event-Based Vision Sensors

**Asynchronous Event Model**:
```
ε(x, y, t) = sign(I(x, y, t) - I(x, y, t_0) - C_threshold)
```

Where ε is the event, I is intensity, and C_threshold is the contrast threshold.

### Tactile Sensing Arrays

**Force Distribution Modeling**:
```
f_contact = K_contact * (x_contact - x_surface)
```

**Tactile Image Processing**:
```
I_tactile = Σ_{i=1}^N w_i * φ(||x - x_i||)
```

Where φ is a radial basis function and w_i are weights.

## Performance Metrics and Evaluation

### Sensor Performance Metrics

**Root Mean Square Error (RMSE)**:
```
RMSE = √[Σ_{i=1}^N (z_measured_i - z_true_i)² / N]
```

**Signal-to-Noise Ratio (SNR)**:
```
SNR = 10 * log10(P_signal / P_noise)
```

**Cramér-Rao Lower Bound (CRLB)**:
```
CRLB = E[(θ̂ - θ)(θ̂ - θ)^T] ≥ I(θ)^(-1)
```

Where I(θ) is the Fisher Information Matrix.

### Information-Theoretic Measures

**Mutual Information**:
```
I(X;Y) = ∫∫ p(x,y) log[p(x,y) / (p(x)p(y))] dx dy
```

**Entropy**:
```
H(X) = -∫ p(x) log p(x) dx
```

## Sensor Network Topologies

### Distributed Sensor Networks

**Consensus Algorithms**:
```
x_i(k+1) = x_i(k) + Σ_{j∈N_i} a_ij(k)[x_j(k) - x_i(k)]
```

Where N_i is the set of neighbors of node i and a_ij are weights.

### Multi-Modal Sensor Integration

**Information Matrix Fusion**:
```
Y_fused = Σ_{i=1}^N Y_i
î_fused = Σ_{i=1}^N î_i
```

Where Y is the information matrix and î is the information state.

## Advanced Applications

### SLAM (Simultaneous Localization and Mapping)

**State Estimation**:
```
x_k = [p_robot, θ_robot, m_1, m_2, ..., m_M]^T
```

Where p_robot is robot pose and m_i are landmark positions.

**EKF-SLAM Prediction**:
```
x̂_k|k-1 = f(x̂_k-1|k-1, u_k-1)
P_k|k-1 = G_k P_k-1|k-1 G_k^T + L_k Q_k-1 L_k^T
```

### Adaptive Sensor Management

**Information Gain Maximization**:
```
u* = argmax_u I(z_k+1; x_k+1 | z_1:k, u_1:k)
```

**Sensor Scheduling**:
```
J = Σ_{k=1}^K tr(P_k) + Σ_{i=1}^N c_i n_i
```

Where c_i is the cost of sensor i and n_i is the number of times it's used.

## Key Takeaways

- Sensor systems require rigorous mathematical modeling for optimal performance
- Advanced filtering techniques (EKF, UKF, particle filters) handle nonlinearities
- Calibration and error modeling are critical for accurate measurements
- Information-theoretic approaches optimize sensor fusion
- Distributed sensor networks enable scalable multi-robot systems
- SLAM and adaptive sensor management represent frontier applications
