# Actuator Systems (English Advanced)

## Mathematical Modeling of Actuator Dynamics

### DC Motor Mathematical Model

**Electrical Equation**:
```
V(t) = R*i(t) + L*di(t)/dt + K_e*ω(t)
```

**Mechanical Equation**:
```
J*dω(t)/dt = K_t*i(t) - B*ω(t) - T_L(t)
```

Where:
- V(t): Applied voltage
- R: Armature resistance
- L: Armature inductance
- i(t): Current
- K_e: Back EMF constant
- ω(t): Angular velocity
- J: Moment of inertia
- K_t: Torque constant
- B: Viscous damping coefficient
- T_L(t): Load torque

**Combined Transfer Function**:
```
G(s) = θ(s)/V(s) = K_t / [s*(L*s + R)*(J*s + B) + K_t*K_e]
```

### Stepper Motor Model

**Dynamic Equation**:
```
J*d²θ/dt² + B*dθ/dt + T_L = T_e - T_r*sin(N_r*θ)
```

Where T_r is reluctance torque and N_r is number of rotor teeth.

### Servo Motor Control Model

**PID Controller**:
```
u(t) = K_p*e(t) + K_i*∫e(t)dt + K_d*de(t)/dt
```

Where e(t) = θ_desired(t) - θ_actual(t)

**Laplace Domain**:
```
U(s) = (K_p + K_i/s + K_d*s) * E(s)
```

## Advanced Control Techniques

### Computed Torque Control

**Dynamic Model**:
```
M(q)q̈ + C(q, q̇)q̇ + g(q) = τ
```

Where M(q) is the inertia matrix, C(q, q̇) represents Coriolis and centrifugal forces, and g(q) represents gravitational forces.

**Control Law**:
```
τ = M(q)q̈_d + C(q, q̇)q̇ + g(q) + K_v*(q̇_d - q̇) + K_p*(q_d - q)
```

### Adaptive Control

**Parameter Estimation**:
```
τ = Y(θ, θ̇, θ̈)*θ̂ + K_v*s
```

Where Y is the regressor matrix, θ̂ is the parameter estimate, and s is the sliding surface.

**Update Law**:
```
θ̂̇ = -Γ*Yᵀ*s
```

Where Γ is a positive definite gain matrix.

### Sliding Mode Control

**Sliding Surface**:
```
s = λ*(q - q_d) + (q̇ - q̇_d)
```

**Control Law**:
```
τ = τ_eq + τ_switch
```

Where τ_eq is the equivalent control and τ_switch is the switching control.

## Hydraulic Actuator Systems

### Mathematical Model

**Pressure Dynamics**:
```
Ṗ_1 = (β/V_1) * (Q_1 - A_1*ẋ - C_leak*(P_1 - P_2))
Ṗ_2 = (β/V_2) * (Q_2 + A_2*ẋ + C_leak*(P_1 - P_2))
```

Where β is bulk modulus, V is volume, A is piston area, and C_leak is leakage coefficient.

**Force Generation**:
```
F = A_1*P_1 - A_2*P_2 - F_friction - F_load
```

### Servo Valve Control

**Flow Equation**:
```
Q = C_d*A_v*√(2*ΔP/ρ) * sign(ΔP)
```

Where C_d is discharge coefficient, A_v is valve area, and ρ is fluid density.

## Pneumatic Actuator Systems

### Mathematical Model

**Continuity Equation**:
```
ṁ = ρ*A*v = ρ*A*dx/dt
```

**Ideal Gas Law Application**:
```
P*V = n*R*T
```

**Pressure Dynamics**:
```
V*Ṗ/RT = ṁ_in - ṁ_out
```

## Nonlinear Control Techniques

### Feedback Linearization

**System Model**:
```
ẋ = f(x) + g(x)*u
y = h(x)
```

**Linearizing Control**:
```
v = L_f^r h(x) + L_g L_f^(r-1) h(x) * u
u = (v - L_f^r h(x)) / L_g L_f^(r-1) h(x)
```

Where L_f and L_g are Lie derivatives.

### Backstepping Control

For systems in strict feedback form:
```
ẋ₁ = f₁(x₁) + g₁(x₁)*x₂
ẋ₂ = f₂(x₁, x₂) + g₂(x₁, x₂)*x₃
⋮
ẋₙ = fₙ(x) + gₙ(x)*u
```

**Virtual Controls**:
```
α₁ = -k₁*x₁ - φ₁(x₁)
α₂ = -k₂*(x₂ - α₁) - φ₂(x₁, x₂) - ∂α₁/∂x₁*(f₁ + g₁*x₂)
```

### Model Predictive Control (MPC)

**Optimization Problem**:
```
min ∑_{k=0}^{N-1} l(x_k, u_k) + V_f(x_N)
subject to: x_{k+1} = f(x_k, u_k)
            u_min ≤ u_k ≤ u_max
            x_min ≤ x_k ≤ x_max
```

Where l is the stage cost and V_f is the terminal cost.

## Advanced Actuator Technologies

### Piezoelectric Actuators

**Constitutive Relations**:
```
D = ε^E*E + dᵀ*T
S = sᴱ*T + d*E
```

Where D is electric displacement, E is electric field, T is stress, S is strain, ε^E is permittivity, sᴱ is compliance, and d is piezoelectric coefficient.

### Shape Memory Alloy (SMA) Actuators

**Phase Transformation Model**:
```
ε = ε_0 + α*(T - T_0) + β*(σ - σ_0) + γ*ξ
```

Where ξ is the martensite fraction and β is the transformation coefficient.

**Thermal Model**:
```
ρ*c_p*dT/dt = Q_input - Q_loss + σ*dσ/dt
```

### Electroactive Polymer (EAP) Actuators

**Electrostatic Force**:
```
F = ε_0*ε_r*A*V² / (2*g²)
```

Where A is area, V is voltage, and g is gap distance.

## Control System Design Considerations

### Robust Control

**H-infinity Control**:
```
min ||T_{zw}||_∞
```

Where T_{zw} is the transfer function from disturbances w to controlled outputs z.

### Optimal Control

**Linear Quadratic Regulator (LQR)**:
```
J = ∫[xᵀQx + uᵀRu] dt
```

**Optimal Control Law**:
```
u = -R⁻¹BᵀPx
```

Where P is the solution to the Algebraic Riccati Equation.

### Observer Design

**Luenberger Observer**:
```
ẋ̂ = A*x̂ + B*u + L*(y - C*x̂)
```

**Kalman Filter (Optimal Observer)**:
```
K = P*Cᵀ*R⁻¹
Ṗ = A*P + P*Aᵀ - P*Cᵀ*R⁻¹*C*P + Q
```

## System Integration and Real-Time Control

### Real-Time Implementation

**Discretization**:
```
x[k+1] = x[k] + T_s*f(x[k], u[k])
```

Where T_s is the sampling time.

**Digital Control Implementation**:
```
u[k] = K_p*e[k] + K_i*T_s*∑e[i] + K_d*(e[k] - e[k-1])/T_s
```

### Networked Control Systems

**Communication Delays**:
```
u(t) = K*x(t - τ)
```

**Stability Condition**:
```
τ < π / (2*max(Im(λ(A))))
```

## Performance Metrics and Evaluation

### Control Performance Metrics

**Integral of Squared Error (ISE)**:
```
ISE = ∫e²(t) dt
```

**Integral of Absolute Error (IAE)**:
```
IAE = ∫|e(t)| dt
```

**Integral of Time-weighted Absolute Error (ITAE)**:
```
ITAE = ∫t*|e(t)| dt
```

### Frequency Domain Analysis

**Bode Plot Margins**:
```
GM = 1/|G(jω_180)|  (Gain Margin)
PM = 180° + ∠G(jω_gc)  (Phase Margin)
```

## Advanced Applications

### Impedance Control

**Desired Impedance Model**:
```
M_d*q̈_d + B_d*q̇_d + K_d*q_d = F_desired - F_contact
```

### Admittance Control

**Admittance Model**:
```
q̈_d = M_a⁻¹(F_measured - B_a*q̇_d - K_a*q_d)
```

### Force Control

**Force Control Law**:
```
τ = τ_ff + K_f*(F_desired - F_measured)
```
