# NVIDIA Isaac Sim (اردو ایڈوانسڈ ورژن)

## باب کا جائزہ

NVIDIA Isaac Sim روبوٹکس کے تحقیق اور ترقی کے لیے ایک جامع سیمیولیشن پلیٹ فارم ہے جو Omniverse پلیٹ فارم پر تعمیر کیا گیا ہے۔ یہ PhysX کا استعمال کرتے ہوئے اعلیٰ معیار کی فزکس سیمیولیشن، RTX ٹیکنالوجی کے ذریعے فوٹو ریلیسٹک رینڈرنگ، اور NVIDIA کے AI ماحول کے ساتھ لاتعداد انضمام کے ذریعے ڈومین رینڈمائزیشن، مصنوعی ڈیٹا جنریشن، اور پیچیدہ روبوٹکس سسٹم کے لیے مضبوط سیم ٹو ریل ٹرانسفر لرننگ کو فعال کرتا ہے۔

### معماری اور بنیادی اجزاء

Isaac Sim کی معماری کئی مربوط سسٹم پر مشتمل ہے:

**Omniverse USD فاؤنڈیشن**: منظر کو ظاہر کرنے کے لیے یونیورسل سین ڈسکرپشن (USD) فریم ورک
**NVIDIA PhysX انجن**: GPU تیزی کے ساتھ فزکس سیمیولیشن
**RTX رینڈرنگ پائپ لائن**: فوٹو ریلیسٹک سینسر سیمیولیشن کے لیے ریل ٹائم رے ٹریسنگ
**CUDA کمپیوٹ فریم ورک**: GPU-ایکسلریٹڈ AI اور فزکس کمپیوٹیشنز

**کارکردگی کی خصوصیات:**
- **فزکس فیڈلٹی**: اعلیٰ معیار کے کا نٹیکٹ ڈائنامکس کے لیے 1000Hz فزکس اپ ڈیٹ کی شرح تک
- **رینڈرنگ کوالٹی**: گلوبل ایلیویشن اور پیچیدہ مواد کے ساتھ فل RTX رے ٹریسنگ
- **AI انضمام**: TensorRT، cuDNN، اور Isaac ROS کے ساتھ براہ راست انضمام
- **اسکیل ایبلٹی**: ملٹی- GPU اور تقسیم شدہ سیمیولیشن کی حمایت

## جامع فزکس سیمیولیشن

### PhysX کنفیگریشن

Isaac Sim فزکس پیرامیٹرز پر گہرائی کنٹرول فراہم کرتا ہے:

```python
# مثال: جامع فزکس کنفیگریشن
from omni.isaac.core.utils import nucleus
from omni.isaac.core import World

# حسب ضرورت فزکس پیرامیٹر کے ساتھ دنیا کو شروع کریں
world = World(stage_units_in_meters=1.0)

# PhysX خصوصیات کنفیگر کریں
physics_ctx = world.get_physics_context()
physics_ctx.set_gravity(9.81)  # معیاری گریویٹی
physics_ctx.set_physics_dt(1.0/60.0)  # فزکس ٹائم سٹیپ
physics_ctx.set_subspace_count(1)  # متوازی سالور تھریڈز کی تعداد
physics_ctx.set_solver_type("TGS")  # TGS یا PGS سالور
```

### کالیژن ڈیٹیکشن اور ریسپانس

اعلیٰ درجے کی کالیژن ہینڈلنگ میں شامل ہیں:

**کا نٹیکٹ میٹریلز**: مسل اور ریسٹی ٹویشن کوائف کے ساتھ حسب ضرورت سطح کی خصوصیات
**ٹریگر والیومز**: ایونٹ ڈیٹیکشن کے لیے غیر جسمانی والیومز
**رے کاسٹنگ**: نیویگیشن الگورتھم کے لیے درست کالیژن کوائف
**سافٹ باڈی ڈائنامکس**: مطیل اشیاء کی سیمیولیشن (ایکسٹینشنز کے ساتھ)

### ملٹی-باڈی ڈائنامکس

پیچیدہ روبوٹکس سسٹم کو اعلیٰ معیار کی ملٹی-باڈی سیمیولیشن کی ضرورت ہوتی ہے:

```python
# مثال: جوائنٹ حدود اور ڈائنامکس کی کنفیگریشن
import omni.isaac.core as ogc
from omni.isaac.core.articulations import Articulation

# ایک پیچیدہ مینوپولیٹر لوڈ کریں
robot = world.scene.add(
    Articulation(
        prim_path="/World/Robot",
        name="my_robot",
        usd_path="/Isaac/Robots/MyRobot/robot.usd"
    )
)

# جوائنٹ ڈائنامکس کنفیگر کریں
for joint_name in robot.dof_names:
    # جوائنٹ حدود سیٹ کریں
    robot.set_joint_position_limits(
        joint_names=[joint_name],
        lower_positions=[-2.0],
        upper_positions=[2.0]
    )
    
    # جوائنٹ مسل اور ڈیمپنگ کنفیگر کریں
    robot.set_joint_friction_coefficients(
        joint_names=[joint_name],
        values=[0.1]
    )
    
    # جوائنٹ ڈیمپنگ سیٹ کریں
    robot.set_joint_drive_params(
        joint_names=[joint_name],
        stiffness_values=[100.0],
        damping_values=[10.0],
        drive_mode="POSITION"
    )
```

### ڈومین رینڈمائزیشن

سیم ٹو ریل ٹرانسفر کے لیے اعلیٰ معیار کی ڈومین رینڈمائزیشن تکنیکس:

```python
import omni.replicator.core as rep

# ڈومین رینڈمائزیشن کنفیگر کریں
with rep.new_layer():
    # لائٹنگ کو تبدیل کریں
    with rep.randomizer():
        def randomize_lighting():
            # ڈوم لائٹ کی شدت میں تبدیلی
            dome_light = rep.create.light(
                position=rep.distribution.uniform((-500, -500, 500), (500, 500, 1000)),
                intensity=rep.distribution.uniform(1000, 5000),
                color=rep.distribution.uniform((0.5, 0.5, 0.5), (1, 1, 1)),
                light_type="dome"
            )
            return dome_light.node
    
    # میٹریلز کو تبدیل کریں
    with rep.randomizer():
        def randomize_materials():
            # بے ترتیب اشیاء منتخب کریں
            objects = rep.get.prims(path_pattern="/World/.*")
            
            # جسمانی طور پر قابل قبول قدر کے ساتھ میٹریلز بے ترتیب کریں
            with objects:
                rep.randomizer.random_material_params(
                    static_friction=rep.distribution.uniform(0.1, 0.9),
                    dynamic_friction=rep.distribution.uniform(0.1, 0.8),
                    restitution=rep.distribution.uniform(0.0, 0.5)
                )
            return objects
    
    # ٹیکسچرز کو تبدیل کریں
    with rep.randomizer():
        def randomize_textures():
            # سطحوں پر بے ترتیب ٹیکسچرز لاگو کریں
            rep.randomizer.randomize_textures(
                texture_paths=["/Textures/Materials/Random.*"],
                probability=0.8
            )
```

```python
        self.lidar_pub.publish(lidar_data)
        self.imu_pub.publish(imu_data)

        self.apply_velocity_command(msg.linear.x, msg.angular.z)
```

## سیمیولیشن فیڈلٹی اور تصدیق

### کم مقداری تصدیق کے طریقے

حقیقی دنیا کے ڈیٹا کے مقابلے میں سیمیولیشن کی درستی کی توثیق:

**کنیمیٹک تصدیق**: جوائنٹ اینگلز اور اینڈ ایفیکٹر مقامات کا موازنہ
**ڈائی نامک تصدیق**: طاقت، ٹورک، اور حرکت کے نمونوں کا موازنہ
**سینسر تصدیق**: سیمیولیشن اور حقیقت کے درمیان سینسر آؤٹ پٹس کا موازنہ

```python
def validate_simulation_kinematics(real_data, sim_data):
    # جوائنٹ اینگل ٹریجکٹریز کا موازنہ کریں
    joint_error = np.mean(np.abs(real_data['joints'] - sim_data['joints']))
    
    # اینڈ ایفیکٹر مقامات کا موازنہ کریں
    ee_error = np.mean(np.linalg.norm(
        real_data['ee_pos'] - sim_data['ee_pos'], axis=1
    ))
    
    return {
        'joint_error': joint_error,
        'end_effector_error': ee_error
    }
```

```python
import omni.kit.test

class TestSimulationComponents(omni.kit.test.AsyncTestCase):
    async def test_robot_kinematics(self):
        # سیمیولیشن میں روبوٹ کنیمیٹکس کو ٹیسٹ کریں
        robot = self.load_robot()
        ee_pos = robot.get_end_effector_position()
        
        # متوقع کنیمیٹکس کے مقابلے میں توثیق کریں
        expected_pos = self.calculate_forward_kinematics(robot.get_joints())
        self.assertAlmostEqual(ee_pos, expected_pos, places=3)
```
