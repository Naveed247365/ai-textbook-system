# کمپیوٹر وژن کی بنیادیں (اردو ایڈوانسڈ ورژن)

## باب کا جائزہ

کمپیوٹر وژن مصنوعی ذہانت کا ایک ذیلی شعبہ ہے جو مشینوں کو حقیقی دنیا کی بصری معلومات کی تشریح، تجزیہ، اور سمجھ کو فعال کرتا ہے۔ اس کے بنیادی طور پر، کمپیوٹر وژن میں تصاویر اور ویڈیو سلسلے سے مطلب کے اخراج کو جامع ریاضیاتی ماڈلز، الگورتھم، اور سیکھنے والے نظام کے ذریعے انجام دیا جاتا ہے۔ یہ باب ماڈرن کمپیوٹر وژن سسٹم کی بنیادیں، جدید تکنیکس، اور نفاذ کے طریقے کو دریافت کرتا ہے۔

### سیکھنے کے اہداف
- کمپیوٹر وژن کی ریاضیاتی بنیادوں کو ماسٹر کرنا
- کیمرہ ماڈلز، کیلیبریشن، اور ملٹی ویو جیومیٹری کو سمجھنا
- جدید امیج پروسیسنگ اور فیچر ایکسٹریکشن الگورتھم کو نافذ کرنا
- بصری پہچان کے لیے ڈیپ لرننگ کی تکنیکس کو لاگو کرنا
- کمپیوٹر وژن سسٹم کی کارکردگی کا تجزیہ اور جائزہ لینا

## ریاضیاتی بنیادیں

### کمپیوٹر وژن میں لکیری الجبرا

کمپیوٹر وژن میں جیومیٹرک تبدیلیوں کو ظاہر کرنے اور مینیپولیٹ کرنے کے لیے لکیری الجبرا کا بہت زیادہ استعمال ہوتا ہے:

**ہومو جینس کوآرڈینیٹس**:
کمپیوٹر وژن میں، ہم اکثر 2D اور 3D سپیس میں پوائنٹس کی نمائندگی کے لیے ہومو جینس کوآرڈینیٹس استعمال کرتے ہیں۔ 2D پوائنٹ (x, y) کو ہومو جینس کوآرڈینیٹس میں (x, y, w) بنایا جاتا ہے، جہاں یوکلیڈین پوائنٹ (x/w, y/w) ہے۔

**ٹرانسفارمیشن میٹریسز**:
- **ٹرانسلیشن**: (tx, ty) ویکٹر کے ذریعے ایک پوائنٹ کو منتقل کرنا
  ```
  [x']   [1  0  tx] [x]
  [y'] = [0  1  ty] [y]
  [1 ]   [0  0  1 ] [1]
  ```

- **ریوٹیشن**: زاویہ θ کے ذریعے ایک پوائنٹ کو گھومنا
  ```
  [x']   [cos(θ)  -sin(θ)  0] [x]
  [y'] = [sin(θ)   cos(θ)  0] [y]
  [1 ]   [  0       0     1] [1]
  ```

- **اسکیلنگ**: (sx, sy) فیکٹرز کے ذریعے ایک پوائنٹ کو اسکیل کرنا
  ```
  [x']   [sx   0   0] [x]
  [y'] = [ 0  sy   0] [y]
  [1 ]   [ 0   0   1] [1]
  ```

### کمپیوٹر وژن میں امکان اور ایسٹیمیشن

بہت سے کمپیوٹر وژن کے مسائل میں عدم یقینی اور نوائسی ماپیں شامل ہوتی ہیں، جس کے لیے امکانی طریقے درکار ہوتے ہیں:

**بےزین ڈھانچہ**:
بصری ایسٹیمیشن کے مسائل میں، ہم اکثر مشاہدات کی روشنی میں سب سے زیادہ ممکنہ حالت تلاش کرنا چاہتے ہیں:

P(حالت|مشاہدہ) = P(مشاہدہ|حالت) × P(حالت) / P(مشاہدہ)

یہ ٹریکنگ، ریکنسٹرکشن، اور ریکوگنیشن الگورتھم کا بنیادی ڈھانچہ ہے۔

**زیادہ سے زیادہ امکان کی ایسٹیمیشن (MLE)**:
مشاہدات z اور پیرامیٹر θ کی روشنی میں، MLE مشاہدات کا امکان زیادہ سے زیادہ کرنے والے پیرامیٹر کو تلاش کرتا ہے:
θ_MLE = argmax_θ P(z|θ)

## کیمرہ ماڈلز اور کیلیبریشن

### پن ہول کیمرہ ماڈل

پن ہول کیمرہ ماڈل 3D پوائنٹس کو 2D امیج کوآرڈینیٹس میں کیسے میپ کرنا ہے اس کا بنیادی جیومیٹرک ماڈل ہے:

```
[x]     [fx  0  cx] [X]
[y] =   [0   fy cy] [Y] * (1/Z)
[1]     [0   0  1 ] [Z]
```

جہاں:
- (X, Y, Z) تین بعدی دنیا کے کوآرڈینیٹس ہیں
- (x, y) 2D امیج کوآرڈینیٹس ہیں
- (fx, fy) فوکل لمبائیاں پکسل میں ہیں
- (cx, cy) بنیادی پوائنٹ (آپٹیکل سینٹر) ہے
- fx = f * sx، fy = f * sy جہاں f فوکل لمبائی میٹر میں ہے، sx اور sy پکسل کے ابعاد ہیں

### کیمرہ کیلیبریشن

کیمرہ کیلیبریشن کیمرہ سسٹم کے داخلی اور بیرونی پیرامیٹر کا تعین کرتا ہے:

```python
import cv2
import numpy as np

def calibrate_camera_advanced(images, pattern_size=(9, 6)):
    """
    چیکر بورڈ پیٹرن کا استعمال کرتے ہوئے جدید کیمرہ کیلیبریشن
    
    دلائل::
        images: کیلیبریشن امیجز کی فہرست
        pattern_size: ہر قطار/کالم میں انر کونرز کی تعداد
        
    واپسی::
        camera_matrix: داخلی کیمرہ میٹرکس
        dist_coeffs: بگاڑ کے کوائف
        rvecs, tvecs: گھوماؤ اور منتقلی کے ویکٹر
        reprojection_error: کیلیبریشن کی درستی کا پیمانہ
    """
    # اشیاء کے پوائنٹس تیار کریں (3D پوائنٹس حقیقی دنیا کے ا_COORDINATES میں)
    objp = np.zeros((pattern_size[0] * pattern_size[1], 3), np.float32)
    objp[:, :2] = np.mgrid[0:pattern_size[0], 0:pattern_size[1]].T.reshape(-1, 2)
    
    # تمام امیجز کے لیے اشیاء کے پوائنٹس اور امیج کے پوائنٹس کو ذخیرہ کرنے والے ارے
    objpoints = []  # 3D پوائنٹس حقیقی دنیا کے اCOORDINATES میں
    imgpoints = []  # 2D پوائنٹس امیج کے پلین میں
    
    for img in images:
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        
        # چیس بورڈ کے کونے تلاش کریں
        ret, corners = cv2.findChessboardCorners(gray, pattern_size, 
                                                flags=cv2.CALIB_CB_ADAPTIVE_THRESH + 
                                                      cv2.CALIB_CB_FAST_CHECK + 
                                                      cv2.CALIB_CB_NORMALIZE_IMAGE)
        
        # اگر مل جائیں تو، اشیاء کے پوائنٹس اور امیج کے پوائنٹس شامل کریں
        if ret:
            objpoints.append(objp)
            # کونوں کی جگہوں کو بہتر بنائیں
            corners2 = cv2.cornerSubPix(gray, corners, (11, 11), (-1, -1))
            imgpoints.append(corners2)
    
    # کیلیبریشن کریں
    if len(objpoints) > 0 and len(imgpoints) > 0:
        ret, camera_matrix, dist_coeffs, rvecs, tvecs = cv2.calibrateCamera(
            objpoints, imgpoints, gray.shape[::-1], None, None
        )
        
        # reprojection error کا حساب لگائیں
        total_error = 0
        for i in range(len(objpoints)):
            imgpoints2, _ = cv2.projectPoints(objpoints[i], rvecs[i], tvecs[i], 
                                              camera_matrix, dist_coeffs)
            error = cv2.norm(imgpoints[i], imgpoints2, cv2.NORM_L2) / len(imgpoints2)
            total_error += error
        
        mean_error = total_error / len(objpoints)
        return camera_matrix, dist_coeffs, rvecs, tvecs, mean_error
    
    return None, None, None, None, float('inf')
```

### لینس بگاڑ ماڈلز

حقیقی کیمرے بگاڑ پیدا کرتے ہیں جن کو درست کرنا ضروری ہے:

**ریڈیل بگاڑ**:
سب سے عام بگاڑ تصویر کے مرکز سے ردیلی طور پر ہوتا ہے:
- x_corrected = x * (1 + k₁r² + k₂r⁴ + k₃r⁶)
- y_corrected = y * (1 + k₁r² + k₂r⁴ + k₃r⁶)

جہاں r² = x² + y² اور k₁، k₂، k₃ ردیل بگاڑ کے کوائف ہیں۔

**ٹینجنٹل بگاڑ**:
یہ لینس اور امیج پلین کی غلط مطابقت کی وجہ سے ہوتا ہے:
- x_corrected = x + [2p₁xy + p₂(r² + 2x²)]
- y_corrected = y + [p₁(r² + 2y²) + 2p₂xy]

جہاں p₁ اور p₂ ٹینجنٹل بگاڑ کے کوائف ہیں۔

## جدید امیج پروسیسنگ تکنیکس

### کنولوشن آپریشن

کنولوشن امیج پروسیسنگ میں ایک بنیادی عمل ہے جو دو فنکشنز کو ضم کرکے تیسرے فنکشن پیدا کرتا ہے:

ایک امیج I اور کرنل K کے لیے:
(I * K)(i, j) = Σ Σ I(m, n) × K(i-m, j-n)

**عام کرنلز**:
- **ایج ڈیٹیکشن**: سوبیل، پریوٹ، کینی آپریٹر
- **سموتھنگ**: گاؤسین، باکس، بائی لیٹرل فلٹر
- **شارپننگ**: لیپلاسیئن، انشارپ ماسکنگ

```python
def convolution_2d(image, kernel):
    """
    2D کنولوشن عمل کریں
    
    دلائل::
        image: 2D نامپائی ارے کے طور پر ان پٹ امیج
        kernel: 2D نامپائی ارے کے طور پر کنولوشن کرنل
        
    واپسی::
        کنولوڈ امیج
    """
    # ابعاد حاصل کریں
    img_h, img_w = image.shape
    ker_h, ker_w = kernel.shape
    
    # پیڈنگ کا حساب لگائیں
    pad_h = ker_h // 2
    pad_w = ker_w // 2
    
    # امیج کو پیڈ کریں
    padded_img = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='edge')
    
    # آؤٹ پٹ کو شروع کریں
    output = np.zeros_like(image)
    
    # کنولوشن انجام دیں
    for i in range(img_h):
        for j in range(img_w):
            # دلچسپی کا علاقہ نکالیں
            region = padded_img[i:i+ker_h, j:j+ker_w]
            # ڈاٹ پروڈکٹ کا حساب لگائیں
            output[i, j] = np.sum(region * kernel)
    
    return output

def sobel_edge_detector(image):
    """
    سوبیل آپریٹر کا استعمال کرتے ہوئے ایج ڈیٹیکٹ کریں
    """
    # سوبیل کرنلز کی وضاحت کریں
    sobel_x = np.array([[-1, 0, 1],
                        [-2, 0, 2],
                        [-1, 0, 1]])
    
    sobel_y = np.array([[-1, -2, -1],
                        [ 0,  0,  0],
                        [ 1,  2,  1]])
    
    # کنولوشن کا اطلاق کریں
    grad_x = convolution_2d(image, sobel_x)
    grad_y = convolution_2d(image, sobel_y)
    
    # گریڈینٹ کی میگنیٹوڈ کا حساب لگائیں
    magnitude = np.sqrt(grad_x**2 + grad_y**2)
    
    # گریڈینٹ کی سمت کا حساب لگائیں
    direction = np.arctan2(grad_y, grad_x)
    
    return magnitude, direction
```

### مورفولوجیکل آپریشن

مورفولوجیکل آپریشن امیج کو ان کی شکل کی بنیاد پر پروسیس کرتے ہیں۔ ان کو ایک سٹرکچرل ایلیمنٹ (کرنل) کی ضرورت ہوتی ہے اور ان کا استعمال بنری امیجز پر کیا جاتا ہے۔

**ایروشن**:
- روشن علاقوں کو سکڑاتا ہے
- چھوٹے چمکدار دھبے ہٹاتا ہے
- فارمولا: (A ⊖ B) = {z | B_z ⊆ A}

**ڈیلیشن**:
- روشن علاقوں کو بڑھاتا ہے
- چھوٹے تیز علاقوں کو بھرتا ہے
- فارمولا: (A ⊕ B) = {z | (B^)_z ∩ A ≠ ∅}

**اوننگ**:
- ایروشن کے بعد ڈیلیشن
- نوائز اور چھوٹی چیزوں کو ہٹاتا ہے

**کلوزنگ**:
- ڈیلیشن کے بعد ایروشن
- سوراخ بھرتا ہے اور قریبی چیزیں جوڑتا ہے

```python
def morphological_operations(image, kernel, operation='erosion'):
    """
    بنری امیج پر مورفولوجیکل آپریشن لاگو کریں
    """
    if operation == 'erosion':
        # ایروشن: ماحول میں کم سے کم لیں
        return cv2.erode(image, kernel, iterations=1)
    elif operation == 'dilation':
        # ڈیلیشن: ماحول میں زیادہ سے زیادہ لیں
        return cv2.dilate(image, kernel, iterations=1)
    elif operation == 'opening':
        # اوننگ: ایروشن کے بعد ڈیلیشن
        return cv2.morphologyEx(image, cv2.MORPH_OPEN, kernel)
    elif operation == 'closing':
        # کلوزنگ: ڈیلیشن کے بعد ایروشن
        return cv2.morphologyEx(image, cv2.MORPH_CLOSE, kernel)
```

## فیچر ڈیٹیکشن اور ڈیسکرپشن

### سکیل اینورینٹ فیچر ٹرانسفارم (SIFT)

SIFT ایک مضبوط فیچر ڈیٹیکشن اور ڈیسکرپشن الگورتھم ہے جو اسکیل، گھمائش، اور لائٹنگ کی تبدیلیوں کے خلاف مستحکم ہے:

```python
def implement_sift_conceptually():
    """
    SIFT الگورتھم کا تصوراتی نفاذ
    """
    # 1. اسکیل اسپیس ایکسٹریما ڈیٹیکشن
    # - گاؤسین پیرامڈ تیار کریں
    # - گاؤسین کے فرق (DoG) تلاش کریں
    # - اسکیل اور جگہ دونوں میں مقامی ایکسٹریما تلاش کریں
    
    # 2. کی پوائنٹ لوکلائزیشن
    # - کم کنٹراسٹ کی پوائنٹس ہٹائیں
    # - ایج ریسپانسز ختم کریں
    
    # 3. سمت تفویض
    # - گریڈینٹ کی میگنیٹوڈ اور سمت کا حساب لگائیں
    # - سمت کا ہسٹوگرام تیار کریں
    # - ہر کی پوائنٹ کو ایک یا زیادہ سمتیں تفویض کریں
    
    # 4. کی پوائنٹ ڈیسکرپٹر
    # - کی پوائنٹ کے گرد 16x16 پیچ بنائیں
    # - 4x4 ذیلی علاقوں میں تقسیم کریں
    # - ہر ذیلی علاقے کے لیے 8-بن سمت ہسٹوگرام بنائیں
    # - 128-ڈائریکشنل ڈیسکرپٹر بنانے کے لیے ہسٹوگرامس جوڑیں
    pass

def sift_features_opencv(image):
    """
    OpenCV کا استعمال کرتے ہوئے SIFT فیچرز نکالیں
    """
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    
    # SIFT ڈیٹیکٹر بنائیں
    sift = cv2.SIFT_create()
    
    # کی پوائنٹس ڈیٹیکٹ کریں اور ڈسکریپٹرز کا حساب لگائیں
    keypoints, descriptors = sift.detectAndCompute(gray, None)
    
    return keypoints, descriptors
```

### سپیڈ ایو روبسٹ فیچرز (SURF)

SURF SIFT کا ایک تیز تر متبادل ہے جو انٹیگرل امیجز اور ہار ویو لیٹس کا استعمال کرتا ہے:

```python
def surf_features_opencv(image):
    """
    OpenCV کا استعمال کرتے ہوئے SURF فیچرز نکالیں
    """
    gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY)
    
    # SURF ڈیٹیکٹر بنائیں (نئے ورژن میں، ORB یا SIFT استعمال کریں)
    # SURF پیٹنٹ ہے اور نئے OpenCV ورژن میں دستیاب نہیں ہے
    # یہ تصوراتی ہے
    if hasattr(cv2, 'xfeatures2d'):
        surf = cv2.xfeatures2d.SURF_create(400)
        keypoints, descriptors = surf.detectAndCompute(gray, None)
        return keypoints, descriptors
    else:
        # ORB یا SIFT کا جائزہ
        orb = cv2.ORB_create()
        keypoints, descriptors = orb.detectAndCompute(gray, None)
        return keypoints, descriptors
```

## ڈیپ لرننگ میں کمپیوٹر وژن

### کنولوشنل نیورل نیٹ ورکس (CNNs) آرکیٹیکچر

CNNs گرڈ جیسی چیزوں جیسے امیجز کو پروسیس کرنے کے لیے تیار کیے گئے نیورل نیٹ ورکس ہیں:

**بنیادی اجزاء**:
1. **کنولوشنل لیئرز**: کمیل فلٹر کا استعمال کرتے ہوئے مقامی فیچرز نکالیں
2. **ایکٹیویشن فنکشنز**: غیر لکیریت داخل کریں (ReLU, Leaky ReLU)
3. **پولنگ لیئرز**: فیچر میپس کو ڈاؤن سیمپل کریں (زیادہ سے زیادہ، اوسط پولنگ)
4. **مکمل طور پر جڑے ہوئے لیئرز**: حتمی طبقہ بندی کے لیے فیچرز کو ملانا

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class AdvancedCNN(nn.Module):
    def __init__(self, num_classes=1000, input_channels=3):
        super(AdvancedCNN, self).__init__()
        
        # کنولوشنل بلاک 1
        self.conv1 = nn.Conv2d(input_channels, 64, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(64)
        self.conv2 = nn.Conv2d(64, 64, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(64)
        self.pool1 = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # کنولوشنل بلاک 2
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        self.bn3 = nn.BatchNorm2d(128)
        self.conv4 = nn.Conv2d(128, 128, kernel_size=3, padding=1)
        self.bn4 = nn.BatchNorm2d(128)
        self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # کنولوشنل بلاک 3
        self.conv5 = nn.Conv2d(128, 256, kernel_size=3, padding=1)
        self.bn5 = nn.BatchNorm2d(256)
        self.pool3 = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # اڈاپٹو اوسط پولنگ طے شدہ سائز کو
        self.adaptive_pool = nn.AdaptiveAvgPool2d((7, 7))
        
        # مکمل طور پر جڑے ہوئے لیئرز
        self.fc1 = nn.Linear(256 * 7 * 7, 512)
        self.dropout = nn.Dropout(0.5)
        self.fc2 = nn.Linear(512, num_classes)
        
    def forward(self, x):
        # بلاک 1
        x = F.relu(self.bn1(self.conv1(x)))
        x = F.relu(self.bn2(self.conv2(x)))
        x = self.pool1(x)
        
        # بلاک 2
        x = F.relu(self.bn3(self.conv3(x)))
        x = F.relu(self.bn4(self.conv4(x)))
        x = self.pool2(x)
        
        # بلاک 3
        x = F.relu(self.bn5(self.conv5(x)))
        x = self.pool3(x)
        
        # اڈاپٹو پولنگ
        x = self.adaptive_pool(x)
        
        # فلیٹن
        x = x.view(x.size(0), -1)
        
        # مکمل طور پر جڑے ہوئے لیئرز
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        
        return x
```

### فیچر پریمڈ نیٹ ورکس (FPN)

FPN متعدد سکیل آبجیکٹ ڈیٹیکشن کو متوازن کرتا ہے جو فیچر پریمڈز کو تعمیر کرکے:

```python
class FeaturePyramidNetwork(nn.Module):
    def __init__(self, in_channels_list, out_channels=256):
        super(FeaturePyramidNetwork, self).__init__()
        self.lateral_convs = nn.ModuleList()
        self.fpn_convs = nn.ModuleList()
        
        # لیٹرل 1x1 کنولوشنز فیچرز کو اسی چینل کے بعد میں پروجیکٹ کرنے کے لیے
        for in_channels in in_channels_list:
            if in_channels == 0:
                continue
            lateral_conv = nn.Conv2d(in_channels, out_channels, kernel_size=1)
            fpn_conv = nn.Conv2d(out_channels, out_channels, kernel_size=3, padding=1)
            
            self.lateral_convs.append(lateral_conv)
            self.fpn_convs.append(fpn_conv)
        
        self.initialize_weights()
    
    def forward(self, features):
        """
        دلائل::
            features: بیک بون کے مختلف درجات سے فیچرز کی فہرست
        """
        # فیچر پریمڈ بنائیں
        laterals = []
        for i, feature in enumerate(features):
            laterals.append(self.lateral_convs[i](feature))
        
        # اوپر سے شروع کریں، معلومات نیچے کی طرف منتقل کر رہے ہیں
        used_backbone_levels = len(laterals)
        for i in range(used_backbone_levels - 1, 0, -1):
            prev_shape = laterals[i - 1].shape[2:]
            laterals[i - 1] += F.interpolate(
                laterals[i], size=prev_shape, mode='nearest'
            )
        
        # 3x3 کنولوشنز لگائیں حتمی فیچرز حاصل کرنے کے لیے
        outs = []
        for i in range(used_backbone_levels):
            outs.append(self.fpn_convs[i](laterals[i]))
        
        return tuple(outs)
    
    def initialize_weights(self):
        for m in self.modules():
            if isinstance(m, nn.Conv2d):
                nn.init.kaiming_normal_(m.weight, mode='fan_out', nonlinearity='relu')
                if m.bias is not None:
                    nn.init.constant_(m.bias, 0)
```

## ملٹی ویو جیومیٹری اور سٹیریو وژن

### ایپی پولر جیومیٹری

ایپی پولر جیومیٹری ایک ہی منظر کے متعدد ویو کے درمیان جیومیٹرک رشتہ کی وضاحت کرتا ہے:

** fundamental matrix F**:
- سٹیریو امیجز کے درمیان مطابقت رکھنے والے پوائنٹس کو ربط دیتا ہے
- بائیں امیج میں ایک پوائنٹ x اور دائیں امیج میں x' کے لیے: x'^T * F * x = 0
- 7 ڈگری فریڈم ہے (Scaler تک)

**essential matrix E**:
- کیلیبریٹڈ کیمرز کے لیے
- fundamental matrix سے متعلق: E = K'^T * F * K
- کیمرز کے درمیان گھومنا اور منتقلی کو ظاہر کرتا ہے

```python
def fundamental_matrix_from_points(points1, points2):
    """
    مطابق پوائنٹس سے fundamental matrix کا حساب لگائیں
    """
    # عددی استحکام کے لیے پوائنٹس کو نارملائز کریں
    points1_norm, T1 = normalize_points(points1)
    points2_norm, T2 = normalize_points(points2)
    
    # A کے کن سٹرینٹ میٹرکس بنائیں جہاں ہر قطار ہے: [x'x, x'y, x', y'x, y'y, y', x, y, 1]
    A = []
    for i in range(len(points1_norm)):
        x, y = points1_norm[i]
        x_prime, y_prime = points2_norm[i]
        
        row = [x_prime * x, x_prime * y, x_prime,
               y_prime * x, y_prime * y, y_prime,
               x, y, 1]
        A.append(row)
    
    A = np.array(A)
    
    # A*f = 0 SVD کا استعمال کرتے ہوئے حل کریں
    U, S, Vt = np.linalg.svd(A)
    F = Vt[-1].reshape(3, 3)
    
    # رینک-2 کن سٹرینٹ نافذ کریں
    U, S, Vt = np.linalg.svd(F)
    S[2] = 0  # سب سے چھوٹی سینگولر قیمت کو 0 کریں
    F = U @ np.diag(S) @ Vt
    
    # نارملائز کریں
    F = T2.T @ F @ T1
    
    # F[2,2] = 1 کرنے کے لیے نارملائز کریں
    F = F / F[2, 2]
    
    return F

def normalize_points(points):
    """
    عددی استحکام کے لیے نارملائز پوائنٹس
    """
    # سینٹروڈ کا حساب لگائیں
    centroid = np.mean(points, axis=0)
    
    # سینٹروڈ سے اوسط فاصلے کا حساب لگائیں
    dists = np.sqrt(np.sum((points - centroid) ** 2, axis=1))
    mean_dist = np.mean(dists)
    
    # نارملائزیشن میٹرکس بنائیں
    s = np.sqrt(2) / mean_dist
    T = np.array([[s, 0, -s * centroid[0]],
                  [0, s, -s * centroid[1]],
                  [0, 0, 1]])
    
    # نارملائزیشن لاگو کریں
    points_h = np.hstack([points, np.ones((len(points), 1))])
    points_norm_h = (T @ points_h.T).T
    points_norm = points_norm_h[:, :2]
    
    return points_norm, T
```

### سٹیریو ڈیپتھ ایسٹیمیشن

سٹیریو وژن بائیں اور دائیں امیجز میں مطابقت رکھنے والے پوائنٹس تلاش کرکے ڈیپتھ کا حساب لگاتا ہے:

**ٹرائی اینگولیشن**:
سٹیریو امیجز میں مطابق پوائنٹس اور کیمرہ پیرامیٹر کی بنیاد پر، ہم 3D کوآرڈینیٹس کا حساب لگا سکتے ہیں۔

**ڈسپریٹی میپ**:
بائیں اور دائیں امیجز میں مطابق پوائنٹس کی پکسل پوزیشنز کا فرق.
ڈیپتھ = (بیس لائن × فوکل لمبائی) / ڈسپریٹی

## کارکردگی کے جائزے کے معیار

### آبجیکٹ ڈیٹیکشن کے معیار

**انٹرسیکشن اوور یونین (IoU)**:
IoU = اوور لیپ کا علاقہ / یونین کا علاقہ
یہ یہ پیمائش کرنے کے لیے استعمال ہوتا ہے کہ کتنا پریڈکٹیڈ باؤنڈنگ باکس گراؤنڈ ٹرو سے میچ کرتا ہے۔

**پریسیژن اور ریکال**:
- پریسیژن = سچے پازیٹیوز / (سچے پازیٹیوز + جھوٹے پازیٹیوز)
- ریکال = سچے پازیٹیوز / (سچے پازیٹیوز + جھوٹے نیگیٹیوز)

**مین ایوریج پریسیژن (mAP)**:
تمام کلاسز اور IoU کے احاطے میں کارکردگی کا اوسط۔

```python
def calculate_iou(box1, box2):
    """
    دو باؤنڈنگ باکسز کے درمیان انٹرسیکشن اوور یونین کا حساب لگائیں
    ہر باکس [x1, y1, x2, y2] ہے
    """
    # تعامل کا علاقہ کا حساب لگائیں
    x1_inter = max(box1[0], box2[0])
    y1_inter = max(box1[1], box2[1])
    x2_inter = min(box1[2], box2[2])
    y2_inter = min(box1[3], box2[3])
    
    if x2_inter <= x1_inter or y2_inter <= y1_inter:
        return 0.0
    
    area_inter = (x2_inter - x1_inter) * (y2_inter - y1_inter)
    
    # انفرادی علاقوں کا حساب لگائیں
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    
    # یونین علاقہ کا حساب لگائیں
    area_union = area1 + area2 - area_inter
    
    # IoU کا حساب لگائیں
    iou = area_inter / area_union
    return iou

def calculate_map(predictions, ground_truths, iou_threshold=0.5):
    """
    مین ایوریج پریسیژن کا حساب لگائیں
    """
    # کلاسز کے حساب سے پریڈکشنز گروپ کریں
    # ہر کلاس کے لیے، AP کا حساب لگائیں
    # تمام کلاسز میں اوسط
    
    classes = set([pred['class'] for pred in predictions])
    aps = []
    
    for class_id in classes:
        class_preds = [p for p in predictions if p['class'] == class_id]
        class_gts = [gt for gt in ground_truths if gt['class'] == class_id]
        
        # پریڈکشنز کو اعتماد کے حساب سے ترتیب دیں
        class_preds.sort(key=lambda x: x['confidence'], reverse=True)
        
        # پریڈکشنز کو گراؤنڈ ٹرو سے میچ کریں
        matched_gts = set()
        tp = [0] * len(class_preds)  # سچے پازیٹیوز
        fp = [0] * len(class_preds)  # جھوٹے پازیٹیوز
        
        for i, pred in enumerate(class_preds):
            best_iou = 0
            best_gt_idx = -1
            
            for j, gt in enumerate(class_gts):
                if j in matched_gts:
                    continue
                
                iou = calculate_iou(pred['bbox'], gt['bbox'])
                if iou > best_iou:
                    best_iou = iou
                    best_gt_idx = j
            
            if best_iou >= iou_threshold and best_gt_idx != -1:
                tp[i] = 1
                matched_gts.add(best_gt_idx)
            else:
                fp[i] = 1
        
        # ہر پوائنٹ پر پریسیژن اور ریکال کا حساب لگائیں
        tp_cumsum = np.cumsum(tp)
        fp_cumsum = np.cumsum(fp)
        
        recalls = tp_cumsum / len(class_gts) if len(class_gts) > 0 else [0]
        precisions = tp_cumsum / (tp_cumsum + fp_cumsum + 1e-8)
        
        # 11-پوائنٹ انٹرپولیشن کا استعمال کرتے ہوئے AP کا حساب لگائیں
        ap = 0
        for t in np.linspace(0, 1, 11):
            if len(recalls) > 0:
                mask = recalls >= t
                precision_at_t = np.max(precisions[mask]) if np.any(mask) else 0
                ap += precision_at_t / 11
        
        aps.append(ap)
    
    return np.mean(aps) if aps else 0
```

### وژن ٹرانسفارمر (ViTs)

وژن ٹرانسفارمر ٹرانسفارمر آرکیٹیکچر کو کمپیوٹر وژن پر لاگو کرتے ہیں:

```python
class VisionTransformer(nn.Module):
    def __init__(self, image_size, patch_size, num_classes, dim, depth, heads, mlp_dim):
        super().__init__()
        assert image_size % patch_size == 0, 'Image dimensions must be divisible by the patch size.'
        
        num_patches = (image_size // patch_size) ** 2
        patch_dim = 3 * patch_size ** 2
        
        self.patch_size = patch_size
        
        # امیج کو پیچوں میں تبدیل کریں اور ایمبیڈنگ طول تک پروجیکٹ کریں
        self.to_patch_embedding = nn.Sequential(
            Rearrange('b c (h p1) (w p2) -> b (h w) (p1 p2 c)', p1=patch_size, p2=patch_size),
            nn.Linear(patch_dim, dim),
        )
        
        # سیکھنے والا کلاس ٹوکن
        self.cls_token = nn.Parameter(torch.randn(1, 1, dim))
        
        # مقامی ایمبیڈنگ
        self.pos_embedding = nn.Parameter(torch.randn(1, num_patches + 1, dim))
        
        # ٹرانسفارمر لیئرز
        self.transformer = Transformer(dim, depth, heads, dim // heads, mlp_dim)
        
        # کلاسیفکیشن ہیڈ
        self.mlp_head = nn.Sequential(
            nn.LayerNorm(dim),
            nn.Linear(dim, num_classes)
        )
    
    def forward(self, img):
        # پیچوں میں تبدیل کریں
        x = self.to_patch_embedding(img)
        b, n, _ = x.shape
        
        # کلاس ٹوکن اور مقامی ایمبیڈنگ شامل کریں
        cls_tokens = self.cls_token.repeat(b, 1, 1)
        x = torch.cat((cls_tokens, x), dim=1)
        x += self.pos_embedding[:, :(n + 1)]
        
        # ٹرانسفارمر لگائیں
        x = self.transformer(x)
        
        # کلاس ٹوکن نکالیں اور کلاسیفکیشن ہیڈ لگائیں
        x = x[:, 0]
        return self.mlp_head(x)

class Transformer(nn.Module):
    def __init__(self, dim, depth, heads, dim_head, mlp_dim):
        super().__init__()
        self.layers = nn.ModuleList([])
        for _ in range(depth):
            self.layers.append(nn.ModuleList([
                PreNorm(dim, Attention(dim, heads=heads, dim_head=dim_head)),
                PreNorm(dim, FeedForward(dim, mlp_dim))
            ]))
    
    def forward(self, x):
        for attn, ff in self.layers:
            x = attn(x) + x
            x = ff(x) + x
        return x
```
