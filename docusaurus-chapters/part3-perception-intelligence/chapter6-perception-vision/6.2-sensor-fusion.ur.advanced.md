# روبوٹکس میں سینسر فیوژن (اردو ایڈوانسڈ ورژن)

## باب کا جائزہ

روبوٹکس میں اعلیٰ معیار کی سینسر فیوژن متعدد ہیٹروجنیس سینسرز سے معلومات کو ملانے کے لیے م sophisticated ریاضیاتی تکنیکس کا مطالعہ کرتی ہے تاکہ بہترین حالت کا تخمینہ اور ماحولیاتی سمجھ حاصل کی جا سکے۔ یہ باب سینسر فیوژن کی نظریاتی بنیادوں، جدید الگورتھم، اور کمپلکس روبوٹک سسٹم میں نفاذ کی میتھڈولوجیز کا جائزہ لیتا ہے، بشمول امکاناتی ڈھانچے، آپٹیمائزیشن تکنیکس، اور حقیقی وقت کا نفاذ کے خیالات۔

### سیکھنے کے اہداف
- سینسر فیوژن کی اعلیٰ معیار کی ریاضیاتی بنیادوں پر قابو پانا
- نفاذ کے چیلنجز اور حل سمجھنا
- آپٹیمائزیشن-مبنی فیوژن تکنیکس کو لاگو کرنا
- فیوژن الگورتھم کی کارکردگی کا تجزیہ کرنا
- مضبوط سینسر فیوژن تعمیرات ڈیزائن کرنا

## ریاضیاتی بنیادیں

### سینسر فیوژن کے لیے بےزین ڈھانچہ

بےزین نقطہ نظر متعدد سینسر پیمائشیں ملانے کے لیے ایک جامع ریاضیاتی بنیاد فراہم کرتا ہے:

P(x|z₁, z₂, ..., zₙ) = η P(z₁, z₂, ..., zₙ|x) P(x)

جہاں x حالت ویکٹر ہے، zᵢ i-th سینسر کی پیمائش کی نمائندگی کرتا ہے، اور η نارملائزیشن کن سٹنٹ ہے۔

**سیکوئنچل بےزین اپ ڈیٹنگ**::
P(x|z₁, ..., zₖ) ∝ P(zₖ|x) P(x|z₁, ..., zₖ₋₁)

### فیوژن میں امکاناتی ڈینسٹی فنکشنز

**گاؤسین ڈسٹری بیوشنز**::
لکیری نظام اور گاؤسین نوائز کے لیے، بہترین فیوژن کلمن فلٹر فریم ورک کے ذریعے حاصل کی جاتی ہے جہاں مختلف سینسرز سے معلومات ان کی عدم یقینی کے مطابق ملائی جاتی ہے۔

**غیر گاؤسین ڈسٹری بیوشنز**::
ملٹی موڈل یا غیر گاؤسین عدم یقینیوں کے لیے، پارٹیکل فلٹر یا دیگر غیر پیرامیٹرک طریقے استعمال کیے جاتے ہیں۔ مشترکہ امکاناتی تقسیم کو وزن شدہ نمونوں کے ذریعے تقریب کیا جاتا ہے:

P(x) ≈ Σᵢ wᵢ δ(x - xᵢ)

جہاں wᵢ وزن ہیں اور δ ڈیرک ڈیلٹا فنکشن ہے۔

### انفارمیشن سپیس کی فارمولیشن

کوواریئنس میٹرکس کے ساتھ کام کرنے کے بجائے، انفارمیشن سپیس فارمولیشن استعمال کرتا ہے::
- انفارمیشن میٹرکس: Y = P⁻¹
- انفارمیشن سٹیٹ: y = P⁻¹x

یہ فارمولیشن سینسر فیوژن کے لیے خاص طور پر مفید ہے کیونکہ یہ آزاد معلومات کے ذرائع کے اضافے کو قدرتی طور پر نمایاں کرتا ہے:

Y_fused = Σᵢ Yᵢ
y_fused = Σᵢ yᵢ

## اعلیٰ معیار کی فیوژن الگورتھم

### کلمن فلٹر کے ویریئنٹس

**ایکسٹینڈیڈ کلمن فلٹر (EKF)**::
غیر لکیری نظام کے لیے، EKF موجودہ حالت کے تخمینے کے ارد گرد نظام کو لکیریائز کرتا ہے::

xₖ|ₖ₋₁ = f(xₖ₋₁|ₖ₋₁, uₖ₋₁)
Pₖ|ₖ₋₁ = FₖPₖ₋₁|ₖ₋₁Fₖᵀ + Qₖ

جہاں Fₖ = ∂f/∂x کو xₖ₋₁|ₖ₋₁ پر جاری کیا جاتا ہے۔

**ان سینٹیڈ کلمن فلٹر (UKF)**::
UKF غیر لکیری فعالیت کے ذریعے ڈسٹری بیوشن کے اعدادوشمار کو زیادہ درست انداز میں قبضہ کرنے کے لیے deterministic sampling استعمال کرتا ہے::

1. موجودہ حالت اور کوواریئنس کی بنیاد پر سگما پوائنٹس تیار کریں
2. غیر لکیری فعالیت کے ذریعے سگما پوائنٹس کو منتقل کریں
3. تبدیل شدہ سگما پوائنٹس کا اوسط اور کوواریئنس کا حساب کریں

```python
class UnscentedKalmanFilter:
    def __init__(self, state_dim, obs_dim, alpha=1e-3, beta=2, kappa=0):
        self.state_dim = state_dim
        self.obs_dim = obs_dim
        self.alpha = alpha
        self.beta = beta
        self.kappa = kappa
        
        # سکیلنگ پیرامیٹر کا حساب لگائیں
        lambda_ = alpha**2 * (state_dim + kappa) - state_dim
        self.cov_scale = state_dim + lambda_
        
        # اوسط اور کوواریئنس کے لیے وزن
        self.Wm = [lambda_ / self.cov_scale]  # اوسط کا وزن
        self.Wc = [lambda_ / self.cov_scale + (1 - alpha**2 + beta)]  # کوواریئنس کا وزن
        for i in range(1, 2 * state_dim + 1):
            self.Wm.append(1 / (2 * self.cov_scale))
            self.Wc.append(1 / (2 * self.cov_scale))
        
        # حالت اور کوواریئنس
        self.x = np.zeros(state_dim)
        self.P = np.eye(state_dim)
    
    def generate_sigma_points(self):
        """موجودہ حالت اور کوواریئنس کی بنیاد پر سگما پوائنٹس تیار کریں"""
        # سکیلڈ کوواریئنس کا مربع جڑ کا حساب لگائیں
        U = np.linalg.cholesky(self.cov_scale * self.P).T
        
        sigma_points = np.zeros((2 * self.state_dim + 1, self.state_dim))
        
        # پہلا سگما پوائنٹ اوسط ہے
        sigma_points[0, :] = self.x
        
        # باقی سگما پوائنٹس تیار کریں
        for i in range(self.state_dim):
            sigma_points[i + 1, :] = self.x + U[i, :]
            sigma_points[self.state_dim + 1 + i, :] = self.x - U[i, :]
        
        return sigma_points
    
    def predict(self, process_noise, control_input=None):
        """UKF کے لیے پریڈکشن اسٹیپ"""
        sigma_points = self.generate_sigma_points()
        
        # موشن ماڈل کے ذریعے سگما پوائنٹس کو منتقل کریں
        if control_input is not None:
            propagated_points = np.array([self.motion_model(point, control_input) 
                                         for point in sigma_points])
        else:
            propagated_points = np.array([self.motion_model(point) 
                                         for point in sigma_points])
        
        # پریڈکٹڈ حالت کا حساب لگائیں
        self.x = np.sum([self.Wm[i] * propagated_points[i] 
                        for i in range(len(propagated_points))], axis=0)
        
        # پریڈکٹڈ کوواریئنس کا حساب لگائیں
        P_pred = np.zeros((self.state_dim, self.state_dim))
        for i in range(len(propagated_points)):
            diff = propagated_points[i] - self.x
            P_pred += self.Wc[i] * np.outer(diff, diff)
        
        self.P = P_pred + process_noise
    
    def update(self, measurement, measurement_noise):
        """UKF کے لیے اپ ڈیٹ اسٹیپ"""
        sigma_points = self.generate_sigma_points()
        
        # پیمائش ماڈل کے ذریعے سگما پوائنٹس کو تبدیل کریں
        measurement_points = np.array([self.measurement_model(point) 
                                      for point in sigma_points])
        
        # پریڈکٹڈ پیمائش کا حساب لگائیں
        z_pred = np.sum([self.Wm[i] * measurement_points[i] 
                        for i in range(len(measurement_points))], axis=0)
        
        # پیمائش کوواریئنس کا حساب لگائیں
        P_zz = np.zeros((self.obs_dim, self.obs_dim))
        for i in range(len(measurement_points)):
            diff = measurement_points[i] - z_pred
            P_zz += self.Wc[i] * np.outer(diff, diff)
        P_zz += measurement_noise
        
        # کراس-کوواریئنس کا حساب لگائیں
        P_xz = np.zeros((self.state_dim, self.obs_dim))
        for i in range(len(sigma_points)):
            state_diff = sigma_points[i] - self.x
            meas_diff = measurement_points[i] - z_pred
            P_xz += self.Wc[i] * np.outer(state_diff, meas_diff)
        
        # کلمن گین کا حساب لگائیں
        K = P_xz @ np.linalg.inv(P_zz)
        
        # حالت اور کوواریئنس کو اپ ڈیٹ کریں
        self.x = self.x + K @ (measurement - z_pred)
        self.P = self.P - K @ P_zz @ K.T
```

### پارٹیکل فلٹر

**سیکوئنچل امپورٹنس ری سیمپلنگ (SIR)**::
پارٹیکل فلٹر امکاناتی تقسیم کو وزن شدہ نمونوں کے طور پر ظاہر کرتا ہے::

```python
class ParticleFilter:
    def __init__(self, state_dim, num_particles=1000):
        self.state_dim = state_dim
        self.num_particles = num_particles
        self.particles = np.random.normal(0, 1, (num_particles, state_dim))
        self.weights = np.ones(num_particles) / num_particles
        self.state_limits = np.array([[-5, 5]] * state_dim)  # مثال کی حدیں
    
    def predict(self, control_input, process_noise_std=0.1):
        """سیسٹم ماڈل کا استعمال کرتے ہوئے موشن اپ ڈیٹ کریں"""
        for i in range(self.num_particles):
            # موشن ماڈل لاگو کریں (مثال: سادہ رینڈم واک کنٹرول کے ساتھ)
            self.particles[i] += control_input + np.random.normal(0, process_noise_std, self.state_dim)
            
            # ضرورت کے مطابق حالت کی حدیں لاگو کریں
            for j in range(self.state_dim):
                self.particles[i, j] = np.clip(self.particles[i, j], 
                                             self.state_limits[j, 0], 
                                             self.state_limits[j, 1])
    
    def update(self, measurement, measurement_std=0.1):
        """پیمائش کی م likelihood کی بنیاد پر اپ ڈیٹ کریں"""
        for i in range(self.num_particles):
            # اس پارٹیکل کے لیے پیمائش کا تخمینہ لگائیں
            predicted_measurement = self.measurement_model(self.particles[i])
            
            # حقیقی پیمائش کی likelihood کا حساب لگائیں
            innovation = measurement - predicted_measurement
            likelihood = self.gaussian_pdf(innovation, np.zeros_like(innovation), 
                                         measurement_std * np.eye(len(measurement)))
            
            # وزن کو اپ ڈیٹ کریں
            self.weights[i] *= likelihood
        
        # ویٹس کو نارملائز کریں
        self.weights = self.weights / np.sum(self.weights)
    
    def resample(self):
        """ان کے وزن کی بنیاد پر پارٹیکلز کو دوبارہ نمونہ لیں"""
        # سسٹمیٹک ری سیمپلنگ
        indices = self.systematic_resample()
        self.particles = self.particles[indices]
        self.weights = np.ones(self.num_particles) / self.num_particles
    
    def systematic_resample(self):
        """سسٹمیٹک ری سیمپلنگ الگورتھم"""
        cumulative_sum = np.cumsum(self.weights)
        indices = np.zeros(self.num_particles, dtype=int)
        
        # یکساں طور پر پھیلے ہوئے نمونے تیار کریں
        interval = 1 / self.num_particles
        r = np.random.uniform(0, interval)
        
        i, j = 0, 0
        while i < self.num_particles:
            while cumulative_sum[j] < r:
                j += 1
            indices[i] = j
            r += interval
            i += 1
        
        return indices
    
    def gaussian_pdf(self, x, mean, cov):
        """ملٹی ویریئٹ گاؤسین امکاناتی ڈینسٹی فنکشن"""
        dim = len(x)
        diff = x - mean
        cov_inv = np.linalg.inv(cov)
        cov_det = np.linalg.det(cov)
        
        normalization = 1 / np.sqrt((2 * np.pi)**dim * cov_det)
        exponent = -0.5 * diff.T @ cov_inv @ diff
        
        return normalization * np.exp(exponent)
    
    def estimate(self):
        """پارٹیکلز سے حالت کا تخمینہ لگائیں"""
        return np.average(self.particles, axis=0, weights=self.weights)
```

## آپٹیمائزیشن-مبنی فیوژن

### زیادہ سے زیادہ امکاناتی ایسٹیمیشن (MLE)

سینسر فیوژن کے لیے، MLE نقطہ نظر پیمائش کی likelihood کو حالت کے لحاظ سے زیادہ سے زیادہ کرتا ہے::

θ̂_ML = argmax_θ P(z₁, z₂, ..., zₙ|θ)

یہ وزن شدہ کم اسکویئر کے مسئلے میں منتج ہوتا ہے::

minₓ Σᵢ (zᵢ - hᵢ(x))ᵀ Rᵢ⁻¹ (zᵢ - hᵢ(x))

جہاں Rᵢ سینسر i کے لیے پیمائش نوائز کوواریئنس ہے۔

def covariance_intersection(P1, P2, x1, x2):
    """
    نامعلوم کراس-کاریلیشن والے تخمینے کو ملائیں
    """
    # انفارمیشن میٹرکسز
    Y1 = np.linalg.inv(P1)
    Y2 = np.linalg.inv(P2)
    
    # تکراری طور پر بہترین وزن حل کریں
    # 2-تخمینہ کی صورت میں، اسے سادہ کیا جا سکتا ہے
    # لیکن ہم نمایش کے لیے گریڈیئنٹ ڈیسینٹ استعمال کریں گے
    w = 0.5  # شروعاتی طور پر برابر وزن
    
    # فیوژن کوواریئنس اور حالت کا حساب لگائیں
    P_fused_inv = w * Y1 + (1 - w) * Y2
    P_fused = np.linalg.inv(P_fused_inv)
    
    # فیوژن حالت کا حساب لگائیں
    x_fused = P_fused @ (w * Y1 @ x1 + (1 - w) * Y2 @ x2)
    
    return x_fused, P_fused

### کنسس مبنی فیوژن

تقسیم شدہ ملٹی-روبوٹ سسٹم کے لیے::

Xᵢ(k+1) = Xᵢ(k) + Σⱼ∈Nᵢ αᵢⱼ(k)(Xⱼ(k) - Xᵢ(k))

جہاں Xᵢ روبوٹ i کا حالت کا تخمینہ ہے، Nᵢ پڑوسی روبوٹس کی نمائندگی کرتا ہے، اور αᵢⱼ کنسس وزن ہیں۔

## ملٹی-سینسر انضمام تعمیرات

### مرکزی فیوژن

تمام سینسر ڈیٹا ایک مرکزی پروسیسنگ یونٹ پر بھیج دیا جاتا ہے::

**فوائد**::
- بہترین معلومات کا استعمال
- عالمی آپٹیمائزیشن ممکن
- پیچیدہ الگورتھم کا نفاذ آسان

**نقصانات**::
- کمیونیکیشن بٹل نیکس
- ناکامی کا واحد نقطہ
- مرکز میں کمپیوٹیشنل بوجھ

### غیر مرکزی فیوژن

ہر سینسر نوڈ اپنا ڈیٹا پروسیس کرتا ہے اور پڑوسیوں کے ساتھ بات چیت کرتا ہے::

**فوائد**::
- کمیونیکیشن ناکامیوں کے خلاف مضبوط
- تقسیم شدہ کمپیوٹیشنل بوجھ
- اسکیل ایبل تعمیر

**نقصانات**::
- مرکزی حوصلے کے مقابلے ذیل میں
- پیچیدہ مطابقت پذیری پروٹوکول
- غیر مسلسل تخمینے کا امکان

### سلسلہ وار فیوژن

پروسیسنگ اور فیوژن کے متعدد درجات::

**لیول 2**: درمیانی فیوژن (جیسے، متعدد مقامی تخمینے)

## کارکردگی کا تجزیہ اور معیار

### مطابقت معیار

**نارملائزڈ ایسٹیمیشن ایرر اسکویئر (NEES)**::
γₖ = (xₖ - x̂ₖ)ᵀ Pₖ⁻¹ (xₖ - x̂ₖ)

ایک مطابقت رکھنے والے فلٹر کے لیے n حالت کے طول کے ساتھ: E[γₖ] = n

**غیر-کریڈیبلٹی انڈیکس (NCI)**::
پیمائش کی کوفی ویئرینس کے ساتھ حقیقی ایرر ویئرینس کی میل کو پیمائش کرتا ہے۔

### درستگی معیار

**روٹ مین اسکویئر ایرر (RMSE)**::
RMSE = √(1/N Σᵢ₌₁ᴺ (x_true - x_est)²)

**اوسط انحراف**::
AD = 1/N Σᵢ₌₁ᴺ |x_true - x_est|

### کمپیوٹیشنل معیار

**حقیقی وقت فیکٹر**::
ایک وقت کے قدم کو پروسیس کرنے میں لگا وقت / حقیقی وقت کا وقفہ

**میموری کا استعمال**::
فیوژن الگورتھم کے لیے درکار میموری vs دستیاب میموری

### آؤٹ لائر رد کرنا

آؤٹ لائرز کی موجودگی میں مضبوط فیوژن::

**RANSAC (رینڈم سیمپل کنسنسس)**::
```python
def ransac_fusion(measurements, measurement_models, threshold, max_iterations=100):
    """
    آؤٹ لائرز سے نمٹنے کے لیے RANSAC-مبنی فیوژن
    """
    best_consensus_set = []
    best_model = None
    
    for _ in range(max_iterations):
        # کم از کم سبسیٹ کو بے ترتیب طور پر منتخب کریں
        sample_size = 2  # سادہ لکیری فٹنگ کے لیے؛ مخصوص ماڈل کے لیے ایڈجسٹ کریں
        random_indices = np.random.choice(len(measurements), sample_size, replace=False)
        
        # کم از کم نمونے پر ماڈل فٹ کریں
        model = fit_model(measurements[random_indices], 
                         [measurement_models[i] for i in random_indices])
        
        # کنسسوس سیٹ گنتی کریں
        consensus_set = []
        for i, (meas, meas_model) in enumerate(zip(measurements, measurement_models)):
            predicted = predict_measurement(model, meas_model)
            error = np.linalg.norm(meas - predicted)
            if error < threshold:
                consensus_set.append(i)
        
        # اگر یہ سب سے بڑا کنسسوس سیٹ ہے تو بہترین ماڈل کو اپ ڈیٹ کریں
        if len(consensus_set) > len(best_consensus_set):
            best_consensus_set = consensus_set
            best_model = model
    
    return best_model, best_consensus_set
```

### اڈاپٹو فیوژن

ماحولیاتی شرائط کی بنیاد پر فیوژن پیرامیٹر جو مطابقت رکھتے ہیں::

**اڈاپٹو کلمن فلٹر**::
تبدیلی کی اطلاع کے اعداد و شمار کی بنیاد پر عمل اور پیمائش کے نوائز پیرامیٹر کو آن لائن ایڈجسٹ کرتا ہے۔

**سوئچنگ ماڈلز**::
 متعدد موشن ماڈلز کا استعمال کرتا ہے اور پیمائش کے بہترین فٹ کی بنیاد پر ان کے درمیان مطیع کرتا ہے۔

```python
class AdaptiveKalmanFilter:
    def __init__(self, state_dim):
        self.state_dim = state_dim
        self.x = np.zeros(state_dim)
        self.P = np.eye(state_dim)
        self.Q = np.eye(state_dim) * 0.1  # عمل نوائز
        self.R = np.eye(state_dim) * 1.0  # پیمائش نوائز
        self.mahalanobis_threshold = 3.0  # آؤٹ لائر ڈیٹیکشن کے لیے تھریشولڈ
        
    def update_adaptive(self, z, H):
        """اڈاپٹو اپ ڈیٹ جو نوائز پیرامیٹر ایڈجسٹ کرتا ہے"""
        # اطلاع کا حساب لگائیں
        innovation = z - H @ self.x
        
        # اطلاع کوواریئنس کا حساب لگائیں
        S = H @ self.P @ H.T + self.R
        
        # مہالانوبس فاصلہ کا حساب لگائیں
        maha_dist = innovation.T @ np.linalg.inv(S) @ innovation
        
        # اطلاع پر مبنی اڈاپٹو منطق
        if maha_dist > self.mahalanobis_threshold**2:
            # غیر متوقع موشن کی وجہ سے عمل نوائز بڑھائیں
            self.Q *= 1.1
            # اس پیمائش کے ساتھ اپ ڈیٹ نہ کریں (ممکنہ آؤٹ لائر)
            return
        elif maha_dist < 0.1:  # بہت چھوٹی اطلاع
            # موشن قابل پیش ہونے کی وجہ سے عمل نوائز کم کریں
            self.Q *= 0.9
        
        # ریگولر کلمن اپ ڈیٹ
        K = self.P @ H.T @ np.linalg.inv(S)
        self.x = self.x + K @ innovation
        self.P = (np.eye(self.state_dim) - K @ H) @ self.P
```

### انفارمیشن-تھیوریٹک فیوژن

آپٹیمل سینسر سلیکشن کے لیے باہمی معلومات اور انتروپی کا استعمال::

**انتروپی-مبنی فیوژن**::
H(X) = -Σ p(x) log p(x)

فیوژن کا تخمینہ کم کرنے والے سینسرز کو منتخب کریں۔

**باہمی معلومات**::
I(X;Y) = Σ Σ p(x,y) log(p(x,y) / (p(x)p(y)))

سینسر پیمائش کے درمیان مشترکہ معلومات کو پیمائش کرتا ہے۔
