## Mathematical Foundations

### Linear Algebra in Computer Vision

Computer vision relies heavily on linear algebra for representing and manipulating geometric transformations:

**Homogeneous Coordinates**:
In computer vision, we often use homogeneous coordinates to represent points in 2D and 3D space. A 2D point (x, y) in homogeneous coordinates becomes (x, y, w), where the Euclidean point is (x/w, y/w).

**Transformation Matrices**:
- **Translation**: Moving a point by a vector (tx, ty)
  ```
  [x']   [1  0  tx] [x]
  [y'] = [0  1  ty] [y]
  [1 ]   [0  0  1 ] [1]
  ```

- **Rotation**: Rotating a point by angle θ
  ```
  [x']   [cos(θ)  -sin(θ)  0] [x]
  [y'] = [sin(θ)   cos(θ)  0] [y]
  [1 ]   [  0       0     1] [1]
  ```

- **Scaling**: Scaling a point by factors (sx, sy)
  ```
  [x']   [sx   0   0] [x]
  [y'] = [ 0  sy   0] [y]
  [1 ]   [ 0   0   1] [1]
  ```

### Probability and Estimation in Computer Vision

Many computer vision problems involve uncertainty and noisy measurements, requiring probabilistic approaches:

**Bayesian Framework**:
In visual estimation problems, we often want to find the most likely state given observations:

P(state|observation) = P(observation|state) × P(state) / P(observation)

This forms the basis for tracking, reconstruction, and recognition algorithms.

**Maximum Likelihood Estimation (MLE)**:
Given observations z and parameter θ, MLE finds the parameter that maximizes the probability of the observations:
θ_MLE = argmax_θ P(z|θ)

## Camera Models and Calibration

### Pinhole Camera Model

The pinhole camera model is the fundamental geometric model describing how 3D points map to 2D image coordinates:

```
[x]     [fx  0  cx] [X]
[y] =   [0   fy cy] [Y] * (1/Z)
[1]     [0   0  1 ] [Z]
```

Where:
- (X, Y, Z) are 3D world coordinates
- (x, y) are 2D image coordinates
- (fx, fy) are focal lengths in pixels
- (cx, cy) is the principal point (optical center)
- fx = f * sx, fy = f * sy where f is focal length in meters, sx and sy are pixel dimensions

### Camera Calibration

Camera calibration determines the intrinsic and extrinsic parameters of a camera system:

```python
import cv2
import numpy as np

def calibrate_camera_advanced(images, pattern_size=(9, 6)):
    """
    Advanced camera calibration using checkerboard pattern
    
    Args:
        images: List of calibration images
        pattern_size: Number of inner corners per row/column
        
    Returns:
        camera_matrix: Intrinsic camera matrix
        dist_coeffs: Distortion coefficients
        rvecs, tvecs: Rotation and translation vectors
        reprojection_error: Calibration accuracy metric
    """
    # Prepare object points (3D points in real world coordinates)
    objp = np.zeros((pattern_size[0] * pattern_size[1], 3), np.float32)
    objp[:, :2] = np.mgrid[0:pattern_size[0], 0:pattern_size[1]].T.reshape(-1, 2)
    
    # Arrays to store object points and image points from all images
    objpoints = []  # 3D points in real world space
    imgpoints = []  # 2D points in image plane
    
    for img in images:
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        
        # Find the chess board corners
        ret, corners = cv2.findChessboardCorners(gray, pattern_size, 
                                                flags=cv2.CALIB_CB_ADAPTIVE_THRESH + 
                                                      cv2.CALIB_CB_FAST_CHECK + 
                                                      cv2.CALIB_CB_NORMALIZE_IMAGE)
        
        # If found, add object points and image points
        if ret:
            objpoints.append(objp)
            # Refine corner locations
            corners2 = cv2.cornerSubPix(gray, corners, (11, 11), (-1, -1))
            imgpoints.append(corners2)
    
    # Perform calibration
    if len(objpoints) > 0 and len(imgpoints) > 0:
        ret, camera_matrix, dist_coeffs, rvecs, tvecs = cv2.calibrateCamera(
            objpoints, imgpoints, gray.shape[::-1], None, None
        )
        
        # Calculate reprojection error
        total_error = 0
        for i in range(len(objpoints)):
            imgpoints2, _ = cv2.projectPoints(objpoints[i], rvecs[i], tvecs[i], 
                                              camera_matrix, dist_coeffs)
            error = cv2.norm(imgpoints[i], imgpoints2, cv2.NORM_L2) / len(imgpoints2)
            total_error += error
        
        mean_error = total_error / len(objpoints)
        return camera_matrix, dist_coeffs, rvecs, tvecs, mean_error
    
    return None, None, None, None, float('inf')
```

### Lens Distortion Models

Real cameras introduce distortions that need to be corrected:

**Radial Distortion**:
The most common distortion occurs radially from the center of the image:
- x_corrected = x * (1 + k₁r² + k₂r⁴ + k₃r⁶)
- y_corrected = y * (1 + k₁r² + k₂r⁴ + k₃r⁶)

Where r² = x² + y² and k₁, k₂, k₃ are radial distortion coefficients.

**Tangential Distortion**:
This occurs due to lens and image plane misalignment:
- x_corrected = x + [2p₁xy + p₂(r² + 2x²)]
- y_corrected = y + [p₁(r² + 2y²) + 2p₂xy]

Where p₁ and p₂ are tangential distortion coefficients.

## Advanced Image Processing Techniques

### Convolution Operations

Convolution is a fundamental operation in image processing that combines two functions to produce a third function:

For an image I and kernel K:
(I * K)(i, j) = Σ Σ I(m, n) × K(i-m, j-n)

**Common Kernels**:
- **Edge Detection**: Sobel, Prewitt, Canny operators
- **Smoothing**: Gaussian, Box, Bilateral filters
- **Sharpening**: Laplacian, Unsharp masking

```python
def convolution_2d(image, kernel):
    """
    Perform 2D convolution operation
    
    Args:
        image: Input image as 2D numpy array
        kernel: Convolution kernel as 2D numpy array
        
    Returns:
        Convolved image
    """
    # Get dimensions
    img_h, img_w = image.shape
    ker_h, ker_w = kernel.shape
    
    # Calculate padding
    pad_h = ker_h // 2
    pad_w = ker_w // 2
    
    # Pad the image
    padded_img = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='edge')
    
    # Initialize output
    output = np.zeros_like(image)
    
    # Perform convolution
    for i in range(img_h):
        for j in range(img_w):
            # Extract region of interest
            region = padded_img[i:i+ker_h, j:j+ker_w]
            # Compute dot product
            output[i, j] = np.sum(region * kernel)
    
    return output

def sobel_edge_detector(image):
    """
    Detect edges using Sobel operator
    """
    # Define Sobel kernels
    sobel_x = np.array([[-1, 0, 1],
                        [-2, 0, 2],
                        [-1, 0, 1]])
    
    sobel_y = np.array([[-1, -2, -1],
                        [ 0,  0,  0],
                        [ 1,  2,  1]])
    
    # Apply convolution
    grad_x = convolution_2d(image, sobel_x)
    grad_y = convolution_2d(image, sobel_y)
    
    # Calculate gradient magnitude
    magnitude = np.sqrt(grad_x**2 + grad_y**2)
    
    # Calculate gradient direction
    direction = np.arctan2(grad_y, grad_x)
    
    return magnitude, direction
```

### Morphological Operations

Morphological operations process images based on their shape. They require a structuring element (kernel) and are primarily used on binary images.

**Erosion**:
- Shrinks bright regions
- Removes small bright spots
- Formula: (A ⊖ B) = {z | B_z ⊆ A}

**Dilation**:
- Expands bright regions
- Fills small dark holes
- Formula: (A ⊕ B) = {z | (B^)_z ∩ A ≠ ∅}

**Opening**:
- Erosion followed by dilation
- Removes noise and small objects

**Closing**:
- Dilation followed by erosion
- Fills holes and connects nearby objects

```python
def morphological_operations(image, kernel, operation='erosion'):
    """
    Apply morphological operations to binary image
    """
    if operation == 'erosion':
        # Erosion: take minimum in neighborhood
        return cv2.erode(image, kernel, iterations=1)
    elif operation == 'dilation':
        # Dilation: take maximum in neighborhood
        return cv2.dilate(image, kernel, iterations=1)
    elif operation == 'opening':
        # Opening: erosion followed by dilation
        return cv2.morphologyEx(image, cv2.MORPH_OPEN, kernel)
    elif operation == 'closing':
        # Closing: dilation followed by erosion
        return cv2.morphologyEx(image, cv2.MORPH_CLOSE, kernel)
```

## Deep Learning in Computer Vision

### Convolutional Neural Networks (CNNs) Architecture

CNNs are specialized neural networks designed for processing grid-like data such as images:

**Core Components**:
1. **Convolutional Layers**: Extract local features using learnable filters
2. **Activation Functions**: Introduce non-linearity (ReLU, Leaky ReLU)
3. **Pooling Layers**: Downsample feature maps (Max pooling, Average pooling)
4. **Fully Connected Layers**: Combine features for final classification

```python
import torch
import torch.nn as nn
import torch.nn.functional as F

class AdvancedCNN(nn.Module):
    def __init__(self, num_classes=1000, input_channels=3):
        super(AdvancedCNN, self).__init__()
        
        # Convolutional block 1
        self.conv1 = nn.Conv2d(input_channels, 64, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(64)
        self.conv2 = nn.Conv2d(64, 64, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(64)
        self.pool1 = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # Convolutional block 2
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        self.bn3 = nn.BatchNorm2d(128)
        self.conv4 = nn.Conv2d(128, 128, kernel_size=3, padding=1)
        self.bn4 = nn.BatchNorm2d(128)
        self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # Convolutional block 3
        self.conv5 = nn.Conv2d(128, 256, kernel_size=3, padding=1)
        self.bn5 = nn.BatchNorm2d(256)
        self.pool3 = nn.MaxPool2d(kernel_size=2, stride=2)
        
        # Adaptive average pooling to fixed size
        self.adaptive_pool = nn.AdaptiveAvgPool2d((7, 7))
        
        # Fully connected layers
        self.fc1 = nn.Linear(256 * 7 * 7, 512)
        self.dropout = nn.Dropout(0.5)
        self.fc2 = nn.Linear(512, num_classes)
        
    def forward(self, x):
        # Block 1
        x = F.relu(self.bn1(self.conv1(x)))
        x = F.relu(self.bn2(self.conv2(x)))
        x = self.pool1(x)
        
        # Block 2
        x = F.relu(self.bn3(self.conv3(x)))
        x = F.relu(self.bn4(self.conv4(x)))
        x = self.pool2(x)
        
        # Block 3
        x = F.relu(self.bn5(self.conv5(x)))
        x = self.pool3(x)
        
        # Adaptive pooling
        x = self.adaptive_pool(x)
        
        # Flatten
        x = x.view(x.size(0), -1)
        
        # Fully connected layers
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)
        
        return x
```

### Feature Pyramid Networks (FPN)

FPN addresses multi-scale object detection by building feature pyramids:

```python
class FeaturePyramidNetwork(nn.Module):
    def __init__(self, in_channels_list, out_channels=256):
        super(FeaturePyramidNetwork, self).__init__()
        self.lateral_convs = nn.ModuleList()
        self.fpn_convs = nn.ModuleList()
        
        # Lateral 1x1 convolutions to project features to same channel dimension
        for in_channels in in_channels_list:
            if in_channels == 0:
                continue
            lateral_conv = nn.Conv2d(in_channels, out_channels, kernel_size=1)
            fpn_conv = nn.Conv2d(out_channels, out_channels, kernel_size=3, padding=1)
            
            self.lateral_convs.append(lateral_conv)
            self.fpn_convs.append(fpn_conv)
        
        self.initialize_weights()
    
    def forward(self, features):
        """
        Args:
            features: List of features from different levels of backbone
        """
        # Build the feature pyramid
        laterals = []
        for i, feature in enumerate(features):
            laterals.append(self.lateral_convs[i](feature))
        
        # Start from the top, propagating information down
        used_backbone_levels = len(laterals)
        for i in range(used_backbone_levels - 1, 0, -1):
            prev_shape = laterals[i - 1].shape[2:]
            laterals[i - 1] += F.interpolate(
                laterals[i], size=prev_shape, mode='nearest'
            )
        
        # Apply 3x3 convs to get final features
        outs = []
        for i in range(used_backbone_levels):
            outs.append(self.fpn_convs[i](lateral[i]))
        
        return tuple(outs)
    
    def initialize_weights(self):
        for m in self.modules():
            if isinstance(m, nn.Conv2d):
                nn.init.kaiming_normal_(m.weight, mode='fan_out', nonlinearity='relu')
                if m.bias is not None:
                    nn.init.constant_(m.bias, 0)
```

## Multi-View Geometry and Stereo Vision

### Epipolar Geometry

Epipolar geometry describes the geometric relationship between multiple views of the same scene:

**Fundamental Matrix F**:
- Relates corresponding points between stereo images
- For a point x in left image and x' in right image: x'^T * F * x = 0
- Has 7 degrees of freedom (up to scale)

**Essential Matrix E**:
- For calibrated cameras
- Related to fundamental matrix: E = K'^T * F * K
- Encodes rotation and translation between cameras

```python
def fundamental_matrix_from_points(points1, points2):
    """
    Compute fundamental matrix from corresponding points
    """
    # Normalize points for numerical stability
    points1_norm, T1 = normalize_points(points1)
    points2_norm, T2 = normalize_points(points2)
    
    # Construct constraint matrix A where each row is: [x'x, x'y, x', y'x, y'y, y', x, y, 1]
    A = []
    for i in range(len(points1_norm)):
        x, y = points1_norm[i]
        x_prime, y_prime = points2_norm[i]
        
        row = [x_prime * x, x_prime * y, x_prime,
               y_prime * x, y_prime * y, y_prime,
               x, y, 1]
        A.append(row)
    
    A = np.array(A)
    
    # Solve A*f = 0 using SVD
    U, S, Vt = np.linalg.svd(A)
    F = Vt[-1].reshape(3, 3)
    
    # Enforce rank-2 constraint
    U, S, Vt = np.linalg.svd(F)
    S[2] = 0  # Set smallest singular value to 0
    F = U @ np.diag(S) @ Vt
    
    # Denormalize
    F = T2.T @ F @ T1
    
    # Normalize to make F[2,2] = 1
    F = F / F[2, 2]
    
    return F

def normalize_points(points):
    """
    Normalize points for numerical stability
    """
    # Calculate centroid
    centroid = np.mean(points, axis=0)
    
    # Calculate average distance from centroid
    dists = np.sqrt(np.sum((points - centroid) ** 2, axis=1))
    mean_dist = np.mean(dists)
    
    # Create normalization matrix
    s = np.sqrt(2) / mean_dist
    T = np.array([[s, 0, -s * centroid[0]],
                  [0, s, -s * centroid[1]],
                  [0, 0, 1]])
    
    # Apply normalization
    points_h = np.hstack([points, np.ones((len(points), 1))])
    points_norm_h = (T @ points_h.T).T
    points_norm = points_norm_h[:, :2]
    
    return points_norm, T
```

### Stereo Depth Estimation

Stereo vision estimates depth by finding corresponding points in left and right images:

**Triangulation**:
Given corresponding points in stereo images and camera parameters, we can compute 3D coordinates.

**Disparity Map**:
The difference in pixel positions of corresponding points in left and right images.
Depth = (Baseline × Focal Length) / Disparity

## Performance Evaluation Metrics

### Object Detection Metrics

**Intersection over Union (IoU)**:
IoU = Area of Overlap / Area of Union
Used to measure how well a predicted bounding box matches the ground truth.

**Precision and Recall**:
- Precision = True Positives / (True Positives + False Positives)
- Recall = True Positives / (True Positives + False Negatives)

**Mean Average Precision (mAP)**:
Average precision across all classes and IoU thresholds.

```python
def calculate_iou(box1, box2):
    """
    Calculate Intersection over Union between two bounding boxes
    Each box is [x1, y1, x2, y2]
    """
    # Calculate intersection area
    x1_inter = max(box1[0], box2[0])
    y1_inter = max(box1[1], box2[1])
    x2_inter = min(box1[2], box2[2])
    y2_inter = min(box1[3], box2[3])
    
    if x2_inter <= x1_inter or y2_inter <= y1_inter:
        return 0.0
    
    area_inter = (x2_inter - x1_inter) * (y2_inter - y1_inter)
    
    # Calculate individual areas
    area1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    area2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    
    # Calculate union area
    area_union = area1 + area2 - area_inter
    
    # Calculate IoU
    iou = area_inter / area_union
    return iou

def calculate_map(predictions, ground_truths, iou_threshold=0.5):
    """
    Calculate mean average precision
    """
    # Group predictions by class
    # For each class, calculate AP
    # Average across all classes
    
    classes = set([pred['class'] for pred in predictions])
    aps = []
    
    for class_id in classes:
        class_preds = [p for p in predictions if p['class'] == class_id]
        class_gts = [gt for gt in ground_truths if gt['class'] == class_id]
        
        # Sort predictions by confidence
        class_preds.sort(key=lambda x: x['confidence'], reverse=True)
        
        # Match predictions to ground truths
        matched_gts = set()
        tp = [0] * len(class_preds)  # True positives
        fp = [0] * len(class_preds)  # False positives
        
        for i, pred in enumerate(class_preds):
            best_iou = 0
            best_gt_idx = -1
            
            for j, gt in enumerate(class_gts):
                if j in matched_gts:
                    continue
                
                iou = calculate_iou(pred['bbox'], gt['bbox'])
                if iou > best_iou:
                    best_iou = iou
                    best_gt_idx = j
            
            if best_iou >= iou_threshold and best_gt_idx != -1:
                tp[i] = 1
                matched_gts.add(best_gt_idx)
            else:
                fp[i] = 1
        
        # Calculate precision and recall at each point
        tp_cumsum = np.cumsum(tp)
        fp_cumsum = np.cumsum(fp)
        
        recalls = tp_cumsum / len(class_gts) if len(class_gts) > 0 else [0]
        precisions = tp_cumsum / (tp_cumsum + fp_cumsum + 1e-8)
        
        # Calculate AP using 11-point interpolation
        ap = 0
        for t in np.linspace(0, 1, 11):
            if len(recalls) > 0:
                mask = recalls >= t
                precision_at_t = np.max(precisions[mask]) if np.any(mask) else 0
                ap += precision_at_t / 11
        
        aps.append(ap)
    
    return np.mean(aps) if aps else 0
```

## Research Frontiers and Emerging Techniques

### Vision Transformers (ViTs)

Vision Transformers apply the transformer architecture to computer vision:

```python
class VisionTransformer(nn.Module):
    def __init__(self, image_size, patch_size, num_classes, dim, depth, heads, mlp_dim):
        super().__init__()
        assert image_size % patch_size == 0, 'Image dimensions must be divisible by the patch size.'
        
        num_patches = (image_size // patch_size) ** 2
        patch_dim = 3 * patch_size ** 2
        
        self.patch_size = patch_size
        
        # Convert image to patches and project to embedding dimension
        self.to_patch_embedding = nn.Sequential(
            Rearrange('b c (h p1) (w p2) -> b (h w) (p1 p2 c)', p1=patch_size, p2=patch_size),
            nn.Linear(patch_dim, dim),
        )
        
        # Learnable class token
        self.cls_token = nn.Parameter(torch.randn(1, 1, dim))
        
        # Positional embeddings
        self.pos_embedding = nn.Parameter(torch.randn(1, num_patches + 1, dim))
        
        # Transformer layers
        self.transformer = Transformer(dim, depth, heads, dim // heads, mlp_dim)
        
        # Classification head
        self.mlp_head = nn.Sequential(
            nn.LayerNorm(dim),
            nn.Linear(dim, num_classes)
        )
    
    def forward(self, img):
        # Convert to patches
        x = self.to_patch_embedding(img)
        b, n, _ = x.shape
        
        # Add class token and positional embeddings
        cls_tokens = self.cls_token.repeat(b, 1, 1)
        x = torch.cat((cls_tokens, x), dim=1)
        x += self.pos_embedding[:, :(n + 1)]
        
        # Apply transformer
        x = self.transformer(x)
        
        # Extract class token and apply classification head
        x = x[:, 0]
        return self.mlp_head(x)

class Transformer(nn.Module):
    def __init__(self, dim, depth, heads, dim_head, mlp_dim):
        super().__init__()
        self.layers = nn.ModuleList([])
        for _ in range(depth):
            self.layers.append(nn.ModuleList([
                PreNorm(dim, Attention(dim, heads=heads, dim_head=dim_head)),
                PreNorm(dim, FeedForward(dim, mlp_dim))
            ]))
    
    def forward(self, x):
        for attn, ff in self.layers:
            x = attn(x) + x
            x = ff(x) + x
        return x
```
