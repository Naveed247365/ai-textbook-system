## Mathematical Foundations

### Bayesian Framework for Sensor Fusion

The Bayesian approach provides a rigorous mathematical foundation for combining multiple sensor measurements:

P(x|z₁, z₂, ..., zₙ) = η P(z₁, z₂, ..., zₙ|x) P(x)

Where x is the state vector, zᵢ represents measurements from the i-th sensor, and η is the normalization constant.

**Sequential Bayesian Updating**:
P(x|z₁, ..., zₖ) ∝ P(zₖ|x) P(x|z₁, ..., zₖ₋₁)

### Probability Density Functions in Fusion

**Gaussian Distributions**:
For linear systems with Gaussian noise, the optimal fusion is achieved through the Kalman filter framework where information from different sensors is combined according to their uncertainty.

**Non-Gaussian Distributions**:
For multimodal or non-Gaussian uncertainties, particle filters or other non-parametric methods are used. The joint probability distribution is approximated by weighted samples:

P(x) ≈ Σᵢ wᵢ δ(x - xᵢ)

Where wᵢ are weights and δ is the Dirac delta function.

### Information Space Formulation

Instead of working with covariance matrices, the information space formulation uses:
- Information matrix: Y = P⁻¹
- Information state: y = P⁻¹x

This formulation is particularly useful for sensor fusion as it naturally handles the addition of independent information sources:

Y_fused = Σᵢ Yᵢ
y_fused = Σᵢ yᵢ

## Advanced Fusion Algorithms

### Kalman Filter Variants

**Extended Kalman Filter (EKF)**:
For nonlinear systems, the EKF linearizes the system around the current state estimate:

xₖ|ₖ₋₁ = f(xₖ₋₁|ₖ₋₁, uₖ₋₁)
Pₖ|ₖ₋₁ = FₖPₖ₋₁|ₖ₋₁Fₖᵀ + Qₖ

Where Fₖ = ∂f/∂x evaluated at xₖ₋₁|ₖ₋₁.

**Unscented Kalman Filter (UKF)**:
The UKF uses deterministic sampling to capture distribution statistics more accurately:

1. Generate sigma points based on current state and covariance
2. Propagate sigma points through nonlinear function
3. Compute mean and covariance of transformed sigma points

```python
class UnscentedKalmanFilter:
    def __init__(self, state_dim, obs_dim, alpha=1e-3, beta=2, kappa=0):
        self.state_dim = state_dim
        self.obs_dim = obs_dim
        self.alpha = alpha
        self.beta = beta
        self.kappa = kappa
        
        # Calculate scaling parameters
        lambda_ = alpha**2 * (state_dim + kappa) - state_dim
        self.cov_scale = state_dim + lambda_
        
        # Weights for mean and covariance
        self.Wm = [lambda_ / self.cov_scale]  # Weight for mean
        self.Wc = [lambda_ / self.cov_scale + (1 - alpha**2 + beta)]  # Weight for covariance
        for i in range(1, 2 * state_dim + 1):
            self.Wm.append(1 / (2 * self.cov_scale))
            self.Wc.append(1 / (2 * self.cov_scale))
        
        # State and covariance
        self.x = np.zeros(state_dim)
        self.P = np.eye(state_dim)
    
    def generate_sigma_points(self):
        """Generate sigma points using current state and covariance"""
        # Calculate square root of scaled covariance
        U = np.linalg.cholesky(self.cov_scale * self.P).T
        
        sigma_points = np.zeros((2 * self.state_dim + 1, self.state_dim))
        
        # First sigma point is the mean
        sigma_points[0, :] = self.x
        
        # Generate remaining sigma points
        for i in range(self.state_dim):
            sigma_points[i + 1, :] = self.x + U[i, :]
            sigma_points[self.state_dim + 1 + i, :] = self.x - U[i, :]
        
        return sigma_points
    
    def predict(self, process_noise, control_input=None):
        """Prediction step for UKF"""
        sigma_points = self.generate_sigma_points()
        
        # Propagate sigma points through motion model
        if control_input is not None:
            propagated_points = np.array([self.motion_model(point, control_input) 
                                         for point in sigma_points])
        else:
            propagated_points = np.array([self.motion_model(point) 
                                         for point in sigma_points])
        
        # Calculate predicted state
        self.x = np.sum([self.Wm[i] * propagated_points[i] 
                        for i in range(len(propagated_points))], axis=0)
        
        # Calculate predicted covariance
        P_pred = np.zeros((self.state_dim, self.state_dim))
        for i in range(len(propagated_points)):
            diff = propagated_points[i] - self.x
            P_pred += self.Wc[i] * np.outer(diff, diff)
        
        self.P = P_pred + process_noise
    
    def update(self, measurement, measurement_noise):
        """Update step for UKF"""
        sigma_points = self.generate_sigma_points()
        
        # Transform sigma points through measurement model
        measurement_points = np.array([self.measurement_model(point) 
                                      for point in sigma_points])
        
        # Calculate predicted measurement
        z_pred = np.sum([self.Wm[i] * measurement_points[i] 
                        for i in range(len(measurement_points))], axis=0)
        
        # Calculate measurement covariance
        P_zz = np.zeros((self.obs_dim, self.obs_dim))
        for i in range(len(measurement_points)):
            diff = measurement_points[i] - z_pred
            P_zz += self.Wc[i] * np.outer(diff, diff)
        P_zz += measurement_noise
        
        # Calculate cross-covariance
        P_xz = np.zeros((self.state_dim, self.obs_dim))
        for i in range(len(sigma_points)):
            state_diff = sigma_points[i] - self.x
            meas_diff = measurement_points[i] - z_pred
            P_xz += self.Wc[i] * np.outer(state_diff, meas_diff)
        
        # Calculate Kalman gain
        K = P_xz @ np.linalg.inv(P_zz)
        
        # Update state and covariance
        self.x = self.x + K @ (measurement - z_pred)
        self.P = self.P - K @ P_zz @ K.T
```

### Particle Filters

**Sequential Importance Resampling (SIR)**:
Particle filters represent probability distributions as weighted samples:

```python
class ParticleFilter:
    def __init__(self, state_dim, num_particles=1000):
        self.state_dim = state_dim
        self.num_particles = num_particles
        self.particles = np.random.normal(0, 1, (num_particles, state_dim))
        self.weights = np.ones(num_particles) / num_particles
        self.state_limits = np.array([[-5, 5]] * state_dim)  # Example limits
    
    def predict(self, control_input, process_noise_std=0.1):
        """Motion update using system model with noise"""
        for i in range(self.num_particles):
            # Apply motion model (example: simple random walk with control)
            self.particles[i] += control_input + np.random.normal(0, process_noise_std, self.state_dim)
            
            # Apply state limits if needed
            for j in range(self.state_dim):
                self.particles[i, j] = np.clip(self.particles[i, j], 
                                             self.state_limits[j, 0], 
                                             self.state_limits[j, 1])
    
    def update(self, measurement, measurement_std=0.1):
        """Measurement update based on likelihood of measurement"""
        for i in range(self.num_particles):
            # Calculate predicted measurement for this particle
            predicted_measurement = self.measurement_model(self.particles[i])
            
            # Calculate likelihood of actual measurement given particle's prediction
            innovation = measurement - predicted_measurement
            likelihood = self.gaussian_pdf(innovation, np.zeros_like(innovation), 
                                         measurement_std * np.eye(len(measurement)))
            
            # Update weight
            self.weights[i] *= likelihood
        
        # Normalize weights
        self.weights = self.weights / np.sum(self.weights)
    
    def resample(self):
        """Resample particles based on their weights"""
        # Systematic resampling
        indices = self.systematic_resample()
        self.particles = self.particles[indices]
        self.weights = np.ones(self.num_particles) / self.num_particles
    
    def systematic_resample(self):
        """Systematic resampling algorithm"""
        cumulative_sum = np.cumsum(self.weights)
        indices = np.zeros(self.num_particles, dtype=int)
        
        # Generate uniformly spaced samples
        interval = 1 / self.num_particles
        r = np.random.uniform(0, interval)
        
        i, j = 0, 0
        while i < self.num_particles:
            while cumulative_sum[j] < r:
                j += 1
            indices[i] = j
            r += interval
            i += 1
        
        return indices
    
    def gaussian_pdf(self, x, mean, cov):
        """Multivariate Gaussian probability density function"""
        dim = len(x)
        diff = x - mean
        cov_inv = np.linalg.inv(cov)
        cov_det = np.linalg.det(cov)
        
        normalization = 1 / np.sqrt((2 * np.pi)**dim * cov_det)
        exponent = -0.5 * diff.T @ cov_inv @ diff
        
        return normalization * np.exp(exponent)
    
    def estimate(self):
        """Calculate state estimate from particles"""
        return np.average(self.particles, axis=0, weights=self.weights)
```

## Optimization-Based Fusion

### Maximum Likelihood Estimation (MLE)

For sensor fusion, the MLE approach maximizes the likelihood of the measurements given the state:

θ̂_ML = argmax_θ P(z₁, z₂, ..., zₙ|θ)

This leads to the weighted least squares problem:

minₓ Σᵢ (zᵢ - hᵢ(x))ᵀ Rᵢ⁻¹ (zᵢ - hᵢ(x))

Where Rᵢ is the measurement noise covariance for sensor i.

### Covariance Intersection

For combining estimates with unknown correlations:

```python
def covariance_intersection(P1, P2, x1, x2):
    """
    Fuse two estimates with unknown cross-correlations
    """
    # Information matrices
    Y1 = np.linalg.inv(P1)
    Y2 = np.linalg.inv(P2)
    
    # Iteratively solve for optimal weight
    # For the 2-estimate case, this can be simplified
    # but we'll use gradient descent for demonstration
    w = 0.5  # Start with equal weights
    
    # Calculate fused covariance and state
    P_fused_inv = w * Y1 + (1 - w) * Y2
    P_fused = np.linalg.inv(P_fused_inv)
    
    # Calculate fused state
    x_fused = P_fused @ (w * Y1 @ x1 + (1 - w) * Y2 @ x2)
    
    return x_fused, P_fused
```

### Consensus-Based Fusion

For distributed multi-robot systems:

Xᵢ(k+1) = Xᵢ(k) + Σⱼ∈Nᵢ αᵢⱼ(k)(Xⱼ(k) - Xᵢ(k))

Where Xᵢ is the state estimate of robot i, Nᵢ represents neighboring robots, and αᵢⱼ are consensus weights.

## Multi-Sensor Integration Architectures

### Centralized Fusion

All sensor data is sent to a central processing unit:

**Advantages**:
- Optimal information utilization
- Global optimization possible
- Easier implementation of complex algorithms

**Disadvantages**:
- Communication bottlenecks
- Single point of failure
- High computational load at center

### Decentralized Fusion

Each sensor node processes its own data and communicates with neighbors:

**Advantages**:
- Robust to communication failures
- Distributed computational load
- Scalable architecture

**Disadvantages**:
- Suboptimal compared to centralized
- Complex coordination protocols
- Potential for inconsistent estimates

### Hierarchical Fusion

Multiple levels of processing and fusion:

**Level 1**: Local sensor fusion (e.g., IMU + GPS)
**Level 2**: Intermediate fusion (e.g., multiple local estimates)
**Level 3**: Global fusion (system-level estimate)

## Performance Analysis and Metrics

### Consistency Metrics

**Normalized Estimation Error Squared (NEES)**:
γₖ = (xₖ - x̂ₖ)ᵀ Pₖ⁻¹ (xₖ - x̂ₖ)

For a consistent filter with n state dimensions: E[γₖ] = n

**Non-Credibility Index (NCI)**:
Measures how well the estimated covariance matches the actual error variance.

### Accuracy Metrics

**Root Mean Square Error (RMSE)**:
RMSE = √(1/N Σᵢ₌₁ᴺ (x_true - x_est)²)

**Average Deviation**:
AD = 1/N Σᵢ₌₁ᴺ |x_true - x_est|

### Computational Metrics

**Real-time Factor**:
Time taken to process one time step / actual time interval

**Memory Utilization**:
Memory required for fusion algorithm vs. available memory

### Outlier Rejection

Robust fusion in the presence of outliers:

**RANSAC (Random Sample Consensus)**:
```python
def ransac_fusion(measurements, measurement_models, threshold, max_iterations=100):
    """
    RANSAC-based fusion to handle outliers
    """
    best_consensus_set = []
    best_model = None
    
    for _ in range(max_iterations):
        # Randomly select minimal subset
        sample_size = 2  # For simple line fitting; adjust for specific model
        random_indices = np.random.choice(len(measurements), sample_size, replace=False)
        
        # Fit model to minimal sample
        model = fit_model(measurements[random_indices], 
                         [measurement_models[i] for i in random_indices])
        
        # Count consensus set
        consensus_set = []
        for i, (meas, meas_model) in enumerate(zip(measurements, measurement_models)):
            predicted = predict_measurement(model, meas_model)
            error = np.linalg.norm(meas - predicted)
            if error < threshold:
                consensus_set.append(i)
        
        # Update best model if this is the largest consensus set
        if len(consensus_set) > len(best_consensus_set):
            best_consensus_set = consensus_set
            best_model = model
    
    return best_model, best_consensus_set
```

### Adaptive Fusion

Fusion parameters that adapt based on environmental conditions:

**Adaptive Kalman Filter**:
Adjusts process and measurement noise parameters online based on innovation statistics.

**Switching Models**:
Uses multiple motion models and dynamically switches between them based on the best fit to measurements.

```python
class AdaptiveKalmanFilter:
    def __init__(self, state_dim):
        self.state_dim = state_dim
        self.x = np.zeros(state_dim)
        self.P = np.eye(state_dim)
        self.Q = np.eye(state_dim) * 0.1  # Process noise
        self.R = np.eye(state_dim) * 1.0  # Measurement noise
        self.mahalanobis_threshold = 3.0  # Threshold for outlier detection
        
    def update_adaptive(self, z, H):
        """Adaptive update that adjusts noise parameters"""
        # Calculate innovation
        innovation = z - H @ self.x
        
        # Calculate innovation covariance
        S = H @ self.P @ H.T + self.R
        
        # Calculate Mahalanobis distance
        maha_dist = innovation.T @ np.linalg.inv(S) @ innovation
        
        # Adaptive logic based on innovation
        if maha_dist > self.mahalanobis_threshold**2:
            # Increase process noise due to unexpected motion
            self.Q *= 1.1
            # Don't update with this measurement (potential outlier)
            return
        elif maha_dist < 0.1:  # Very small innovation
            # Decrease process noise as motion is predictable
            self.Q *= 0.9
        
        # Regular Kalman update
        K = self.P @ H.T @ np.linalg.inv(S)
        self.x = self.x + K @ innovation
        self.P = (np.eye(self.state_dim) - K @ H) @ self.P
```

### Information-Theoretic Fusion

Using mutual information and entropy for optimal sensor selection:

**Entropy-based Fusion**:
H(X) = -Σ p(x) log p(x)

Select sensors that minimize the entropy of the fused estimate.

**Mutual Information**:
I(X;Y) = Σ Σ p(x,y) log(p(x,y) / (p(x)p(y)))

Measures the information shared between sensor measurements.
