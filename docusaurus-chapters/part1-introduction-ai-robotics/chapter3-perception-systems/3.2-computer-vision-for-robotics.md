## Introduction to Computer Vision in Robotics

Computer vision in robotics differs significantly from general computer vision due to the real-time constraints, resource limitations, and action-oriented requirements of robotic systems. While general computer vision might focus on image understanding, robotic computer vision must bridge the gap between visual perception and physical action.

### Key Differences from General Computer Vision

1. **Real-time Processing**: Robots often require immediate responses to visual input
2. **Resource Constraints**: Limited computational power and memory
3. **Action-Oriented**: Visual processing must support decision-making and control
4. **Dynamic Environments**: Robots operate in changing, unstructured environments
5. **Embodied Perception**: Vision is integrated with other sensors and actuators

## Image Formation and Camera Models

Understanding how images are formed is crucial for robotic vision applications.

### Pinhole Camera Model

The pinhole camera model describes the mathematical relationship between a 3D point in the world and its 2D projection on the image plane:

```
[u]   [fx  0  cx] [X/Z]
[v] = [0  fy  cy] [Y/Z]
[1]   [0   0  1] [ 1 ]
```

Where:
- (u, v) are image coordinates
- (X, Y, Z) are world coordinates
- fx, fy are focal lengths in pixels
- cx, cy are principal point coordinates

```python
class CameraModel:
    def __init__(self, focal_length_x, focal_length_y, principal_point_x, principal_point_y):
        self.fx = focal_length_x
        self.fy = focal_length_y
        self.cx = principal_point_x
        self.cy = principal_point_y

        # Intrinsic matrix
        self.K = np.array([
            [self.fx, 0, self.cx],
            [0, self.fy, self.cy],
            [0, 0, 1]
        ])

    def project_3d_to_2d(self, points_3d):
        """
        Project 3D points to 2D image coordinates
        points_3d: array of shape (N, 3) with [X, Y, Z] coordinates
        """
        points_3d = np.atleast_2d(points_3d)

        # Convert to homogeneous coordinates
        points_3d_h = np.hstack([points_3d, np.ones((points_3d.shape[0], 1))])

        # Apply projection
        points_2d_h = (self.K @ points_3d_h.T).T

        # Convert back to Cartesian coordinates
        points_2d = points_2d_h[:, :2] / points_2d_h[:, 2:3]

        return points_2d

    def project_2d_to_3d(self, points_2d, depths):
        """
        Project 2D points to 3D given depths
        points_2d: array of shape (N, 2) with [u, v] coordinates
        depths: array of shape (N,) with Z values
        """
        points_2d = np.atleast_2d(points_2d)
        depths = np.atleast_1d(depths)

        # Convert to camera coordinates
        points_cam = np.column_stack([
            (points_2d[:, 0] - self.cx) * depths / self.fx,
            (points_2d[:, 1] - self.cy) * depths / self.fy,
            depths
        ])

        return points_cam
```

### Camera Calibration

Camera calibration determines the intrinsic and extrinsic parameters of a camera.

```python
class CameraCalibrator:
    def __init__(self, pattern_size=(9, 6)):
        self.pattern_size = pattern_size
        self.object_points = []  # 3D points in real world space
        self.image_points = []   # 2D points in image plane

    def find_chessboard_corners(self, image):
        """Find chessboard corners in image"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image

        # Find chessboard corners
        ret, corners = cv2.findChessboardCorners(gray, self.pattern_size, None)

        if ret:
            # Improve corner accuracy
            criteria = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)
            corners = cv2.cornerSubPix(
                gray, corners, (11, 11), (-1, -1), criteria
            )
            return corners.reshape(-1, 2)
        return None

    def add_calibration_image(self, image):
        """Add image to calibration dataset"""
        corners = self.find_chessboard_corners(image)
        if corners is not None:
            # Create 3D points (assuming chessboard is at z=0)
            objp = np.zeros((self.pattern_size[0] * self.pattern_size[1], 3), np.float32)
            objp[:, :2] = np.mgrid[0:self.pattern_size[0], 0:self.pattern_size[1]].T.reshape(-1, 2)

            self.object_points.append(objp)
            self.image_points.append(corners)
            return True
        return False

    def calibrate_camera(self):
        """Perform camera calibration"""
        if len(self.object_points) < 10:
            raise ValueError("Need at least 10 calibration images")

        # Calibrate camera
        ret, mtx, dist, rvecs, tvecs = cv2.calibrateCamera(
            self.object_points, self.image_points,
            (640, 480), None, None  # Assuming 640x480 image size
        )

        return {
            'camera_matrix': mtx,
            'distortion_coefficients': dist,
            'rotation_vectors': rvecs,
            'translation_vectors': tvecs,
            'reprojection_error': ret
        }

    def undistort_image(self, image, camera_matrix, dist_coeffs):
        """Remove lens distortion from image"""
        h, w = image.shape[:2]
        new_camera_mtx, roi = cv2.getOptimalNewCameraMatrix(
            camera_matrix, dist_coeffs, (w, h), 1, (w, h)
        )

        undistorted = cv2.undistort(image, camera_matrix, dist_coeffs, None, new_camera_mtx)

        # Crop the image based on ROI
        x, y, w, h = roi
        undistorted = undistorted[y:y+h, x:x+w]

        return undistorted
```

### Corner Detection

```python
class CornerDetector:
    def __init__(self, method='shi_tomasi', quality_level=0.01, min_distance=10):
        self.method = method
        self.quality_level = quality_level
        self.min_distance = min_distance

    def shi_tomasi_corners(self, image, max_corners=100):
        """Detect corners using Shi-Tomasi method"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image

        corners = cv2.goodFeaturesToTrack(
            gray,
            max_corners,
            self.quality_level,
            self.min_distance
        )

        if corners is not None:
            corners = np.int0(corners)
            return corners.reshape(-1, 2)
        return np.array([])

    def harris_corners(self, image, block_size=2, ksize=3, k=0.04):
        """Detect corners using Harris corner detector"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image

        # Normalize image
        gray = np.float32(gray)

        # Apply Harris corner detection
        dst = cv2.cornerHarris(gray, block_size, ksize, k)

        # Dilate to mark the corners
        dst = cv2.dilate(dst, None)

        # Threshold for an optimal value
        corners = np.where(dst > 0.01 * dst.max())
        corner_points = np.column_stack([corners[1], corners[0]])  # (x, y) format

        return corner_points
```

### Edge Detection

```python
class EdgeDetector:
    def __init__(self, method='canny', low_threshold=50, high_threshold=150):
        self.method = method
        self.low_threshold = low_threshold
        self.high_threshold = high_threshold

    def canny_edges(self, image):
        """Detect edges using Canny edge detector"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image

        # Apply Gaussian blur to reduce noise
        blurred = cv2.GaussianBlur(gray, (5, 5), 0)

        # Apply Canny edge detection
        edges = cv2.Canny(blurred, self.low_threshold, self.high_threshold)

        return edges

    def sobel_edges(self, image):
        """Detect edges using Sobel operator"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image

        # Calculate gradients in x and y directions
        grad_x = cv2.Sobel(gray, cv2.CV_64F, 1, 0, ksize=3)
        grad_y = cv2.Sobel(gray, cv2.CV_64F, 0, 1, ksize=3)

        # Calculate magnitude and direction of gradients
        magnitude = np.sqrt(grad_x**2 + grad_y**2)
        direction = np.arctan2(grad_y, grad_x)

        # Normalize magnitude to 0-255 range
        magnitude = np.uint8(255 * magnitude / np.max(magnitude))

        return magnitude, direction

    def laplacian_edges(self, image):
        """Detect edges using Laplacian operator"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image

        # Apply Laplacian
        laplacian = cv2.Laplacian(gray, cv2.CV_64F)

        # Take absolute value and convert to uint8
        laplacian = np.uint8(np.absolute(laplacian))

        return laplacian
```

### Feature Descriptors

```python
class FeatureDescriptor:
    def __init__(self, method='orb'):
        self.method = method
        if method == 'sift':
            self.detector = cv2.SIFT_create()
        elif method == 'surf':
            self.detector = cv2.xfeatures2d.SURF_create()
        elif method == 'orb':
            self.detector = cv2.ORB_create()
        else:
            raise ValueError(f"Unsupported feature descriptor: {method}")

    def extract_features(self, image):
        """Extract features using the selected method"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image

        # Detect keypoints and compute descriptors
        keypoints, descriptors = self.detector.detectAndCompute(gray, None)

        if descriptors is None:
            descriptors = np.array([])

        return keypoints, descriptors

    def match_features(self, descriptors1, descriptors2, method='bf'):
        """Match features between two sets of descriptors"""
        if method == 'bf':
            # Brute force matcher
            bf = cv2.BFMatcher()
            matches = bf.knnMatch(descriptors1, descriptors2, k=2)
        elif method == 'flann':
            # FLANN matcher
            FLANN_INDEX_KDTREE = 1
            index_params = dict(algorithm=FLANN_INDEX_KDTREE, trees=5)
            search_params = dict(checks=50)
            flann = cv2.FlannBasedMatcher(index_params, search_params)
            matches = flann.knnMatch(descriptors1, descriptors2, k=2)
        else:
            raise ValueError(f"Unsupported matching method: {method}")

        # Apply Lowe's ratio test to filter good matches
        good_matches = []
        for match_pair in matches:
            if len(match_pair) == 2:
                m, n = match_pair
                if m.distance < 0.7 * n.distance:
                    good_matches.append(m)

        return good_matches
```

### Template Matching

```python
class TemplateMatcher:
    def __init__(self, method=cv2.TM_CCOEFF_NORMED):
        self.method = method

    def match_template(self, image, template):
        """Match template in image"""
        gray = cv2.cvtColor(image, cv2.COLOR_BGR2GRAY) if len(image.shape) == 3 else image
        template_gray = cv2.cvtColor(template, cv2.COLOR_BGR2GRAY) if len(template.shape) == 3 else template

        # Perform template matching
        result = cv2.matchTemplate(gray, template_gray, self.method)

        # Find locations where matching exceeds threshold
        threshold = 0.8
        locations = np.where(result >= threshold)

        # Get matching rectangles
        matches = []
        for pt in zip(*locations[::-1]):
            matches.append({
                'location': pt,
                'confidence': result[pt[1], pt[0]],
                'bbox': [pt[0], pt[1], pt[0] + template_gray.shape[1], pt[1] + template_gray.shape[0]]
            })

        return matches

    def multi_scale_template_match(self, image, template, scales=range(50, 151, 25)):
        """Match template at multiple scales"""
        best_match = None
        best_confidence = 0

        for scale in scales:
            # Resize template
            new_width = int(template.shape[1] * scale / 100)
            new_height = int(template.shape[0] * scale / 100)
            resized_template = cv2.resize(template, (new_width, new_height))

            # Match at this scale
            matches = self.match_template(image, resized_template)

            # Find best match at this scale
            for match in matches:
                if match['confidence'] > best_confidence:
                    best_confidence = match['confidence']
                    best_match = {
                        'location': match['location'],
                        'confidence': match['confidence'],
                        'scale': scale,
                        'bbox': match['bbox']
                    }

        return best_match
```

### Color-Based Object Detection

```python
class ColorDetector:
    def __init__(self, color_space='hsv'):
        self.color_space = color_space

    def bgr_to_hsv(self, bgr_image):
        """Convert BGR image to HSV"""
        return cv2.cvtColor(bgr_image, cv2.COLOR_BGR2HSV)

    def create_color_mask(self, image, color_range):
        """Create a mask for a specific color range"""
        if self.color_space == 'hsv':
            hsv = image if len(image.shape) == 3 else self.bgr_to_hsv(image)

            if color_range == 'red':
                # Red color range in HSV (red wraps around 0 degrees)
                lower_red1 = np.array([0, 50, 50])
                upper_red1 = np.array([10, 255, 255])
                lower_red2 = np.array([170, 50, 50])
                upper_red2 = np.array([180, 255, 255])

                mask1 = cv2.inRange(hsv, lower_red1, upper_red1)
                mask2 = cv2.inRange(hsv, lower_red2, upper_red2)
                mask = mask1 + mask2
            elif color_range == 'blue':
                lower = np.array([100, 50, 50])
                upper = np.array([130, 255, 255])
                mask = cv2.inRange(hsv, lower, upper)
            elif color_range == 'green':
                lower = np.array([40, 50, 50])
                upper = np.array([80, 255, 255])
                mask = cv2.inRange(hsv, lower, upper)
            elif color_range == 'yellow':
                lower = np.array([20, 50, 50])
                upper = np.array([30, 255, 255])
                mask = cv2.inRange(hsv, lower, upper)
            else:
                raise ValueError(f"Unsupported color: {color_range}")

        return mask

    def detect_color_objects(self, image, color, min_area=100):
        """Detect objects of a specific color"""
        mask = self.create_color_mask(image, color)

        # Find contours in the mask
        contours, _ = cv2.findContours(mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

        objects = []
        for contour in contours:
            area = cv2.contourArea(contour)
            if area > min_area:
                # Get bounding box
                x, y, w, h = cv2.boundingRect(contour)

                # Calculate center
                center_x = x + w // 2
                center_y = y + h // 2

                objects.append({
                    'color': color,
                    'bbox': [x, y, x+w, y+h],
                    'center': (center_x, center_y),
                    'area': area,
                    'contour': contour
                })

        return objects
```

### Background Subtraction

```python
class BackgroundSubtractor:
    def __init__(self, method='mog2'):
        if method == 'mog2':
            self.subtractor = cv2.createBackgroundSubtractorMOG2()
        elif method == 'knn':
            self.subtractor = cv2.createBackgroundSubtractorKNN()
        else:
            raise ValueError(f"Unsupported background subtraction method: {method}")

    def apply_background_subtraction(self, frame):
        """Apply background subtraction to detect foreground objects"""
        fg_mask = self.subtractor.apply(frame)

        # Apply morphological operations to clean up the mask
        kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
        fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_OPEN, kernel)
        fg_mask = cv2.morphologyEx(fg_mask, cv2.MORPH_CLOSE, kernel)

        return fg_mask

    def detect_moving_objects(self, frame, min_area=100):
        """Detect moving objects using background subtraction"""
        fg_mask = self.apply_background_subtraction(frame)

        # Find contours of moving objects
        contours, _ = cv2.findContours(fg_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)

        moving_objects = []
        for contour in contours:
            area = cv2.contourArea(contour)
            if area > min_area:
                x, y, w, h = cv2.boundingRect(contour)
                center_x = x + w // 2
                center_y = y + h // 2

                moving_objects.append({
                    'bbox': [x, y, x+w, y+h],
                    'center': (center_x, center_y),
                    'area': area,
                    'contour': contour
                })

        return moving_objects, fg_mask
```

```python
class ObjectTracker:
    def __init__(self, tracker_type='kcf'):
        self.tracker_type = tracker_type
        self.trackers = {}
        self.next_id = 0

    def create_tracker(self):
        """Create a tracker based on the selected type"""
        if self.tracker_type == 'kcf':
            return cv2.TrackerKCF_create()
        elif self.tracker_type == 'csrt':
            return cv2.TrackerCSRT_create()
        elif self.tracker_type == 'mosse':
            return cv2.TrackerMOSSE_create()
        elif self.tracker_type == 'medianflow':
            return cv2.TrackerMedianFlow_create()
        else:
            raise ValueError(f"Unsupported tracker type: {self.tracker_type}")

    def initialize_tracker(self, frame, bbox):
        """Initialize tracker with bounding box"""
        tracker = self.create_tracker()
        success = tracker.init(frame, tuple(bbox))

        if success:
            tracker_id = self.next_id
            self.next_id += 1
            self.trackers[tracker_id] = {
                'tracker': tracker,
                'bbox': bbox,
                'active': True,
                'frames_tracked': 0
            }
            return tracker_id
        else:
            return None

    def update_trackers(self, frame):
        """Update all active trackers"""
        for tracker_id, tracker_info in self.trackers.items():
            if tracker_info['active']:
                success, bbox = tracker_info['tracker'].update(frame)

                if success:
                    tracker_info['bbox'] = bbox
                    tracker_info['frames_tracked'] += 1
                else:
                    # Tracker failed, mark as inactive
                    tracker_info['active'] = False

    def get_tracked_objects(self):
        """Get all currently tracked objects"""
        objects = []
        for tracker_id, tracker_info in self.trackers.items():
            if tracker_info['active']:
                x, y, w, h = tracker_info['bbox']
                objects.append({
                    'id': tracker_id,
                    'bbox': [int(x), int(y), int(x+w), int(y+h)],
                    'center': (int(x + w/2), int(y + h/2)),
                    'active': True
                })
        return objects
```

## 3D Vision and Depth Estimation

3D vision is crucial for robotic manipulation and navigation.

### Stereo Vision

```python
class StereoVision:
    def __init__(self, camera_params):
        self.left_camera = camera_params['left']
        self.right_camera = camera_params['right']
        self.baseline = camera_params['baseline']  # Distance between cameras
        self.focal_length = self.left_camera['focal_length']

        # Stereo matcher
        self.stereo = cv2.StereoSGBM_create(
            minDisparity=0,
            numDisparities=64,  # Must be divisible by 16
            blockSize=9,
            P1=8 * 3 * 9**2,
            P2=32 * 3 * 9**2,
            disp12MaxDiff=1,
            uniquenessRatio=15,
            speckleWindowSize=0,
            speckleRange=2,
            preFilterCap=63,
            mode=cv2.STEREO_SGBM_MODE_SGBM_3WAY
        )

    def compute_disparity(self, left_image, right_image):
        """Compute disparity map from stereo pair"""
        # Convert to grayscale if needed
        if len(left_image.shape) == 3:
            left_gray = cv2.cvtColor(left_image, cv2.COLOR_BGR2GRAY)
        else:
            left_gray = left_image

        if len(right_image.shape) == 3:
            right_gray = cv2.cvtColor(right_image, cv2.COLOR_BGR2GRAY)
        else:
            right_gray = right_image

        # Compute disparity
        disparity = self.stereo.compute(left_gray, right_gray).astype(np.float32) / 16.0

        return disparity

    def depth_from_disparity(self, disparity):
        """Convert disparity to depth"""
        # Depth = (focal_length * baseline) / disparity
        # Avoid division by zero
        depth = np.zeros_like(disparity)
        valid_disparity = disparity > 0
        depth[valid_disparity] = (self.focal_length * self.baseline) / disparity[valid_disparity]

        return depth

    def point_cloud_from_stereo(self, left_image, right_image):
        """Generate 3D point cloud from stereo images"""
        disparity = self.compute_disparity(left_image, right_image)
        depth = self.depth_from_disparity(disparity)

        # Generate 3D coordinates
        height, width = depth.shape
        u, v = np.meshgrid(np.arange(width), np.arange(height))

        # Convert pixel coordinates to 3D world coordinates
        x = (u - self.left_camera['cx']) * depth / self.focal_length
        y = (v - self.left_camera['cy']) * depth / self.focal_length
        z = depth

        # Stack into point cloud
        points = np.stack([x, y, z], axis=-1).reshape(-1, 3)

        # Get colors from the left image
        colors = left_image.reshape(-1, 3) if len(left_image.shape) == 3 else np.repeat(left_image.reshape(-1, 1), 3, axis=1)

        return points, colors
```

### Structure from Motion (SfM)

```python
class StructureFromMotion:
    def __init__(self):
        self.feature_detector = cv2.SIFT_create()
        self.matcher = cv2.BFMatcher()
        self.camera_matrix = None

    def find_feature_matches(self, img1, img2):
        """Find feature matches between two images"""
        # Detect features
        kp1, des1 = self.feature_detector.detectAndCompute(img1, None)
        kp2, des2 = self.feature_detector.detectAndCompute(img2, None)

        if des1 is None or des2 is None:
            return [], [], []

        # Match features
        matches = self.matcher.knnMatch(des1, des2, k=2)

        # Apply Lowe's ratio test
        good_matches = []
        for match_pair in matches:
            if len(match_pair) == 2:
                m, n = match_pair
                if m.distance < 0.7 * n.distance:
                    good_matches.append(m)

        # Extract corresponding points
        pts1 = np.float32([kp1[m.queryIdx].pt for m in good_matches]).reshape(-1, 1, 2)
        pts2 = np.float32([kp2[m.trainIdx].pt for m in good_matches]).reshape(-1, 1, 2)

        return pts1, pts2, good_matches

    def estimate_fundamental_matrix(self, pts1, pts2):
        """Estimate fundamental matrix from point correspondences"""
        F, mask = cv2.findFundamentalMat(pts1, pts2, cv2.RANSAC, 4, 0.999)
        F = F/F[2,2]  # Normalize
        return F, mask

    def estimate_essential_matrix(self, pts1, pts2, camera_matrix):
        """Estimate essential matrix from point correspondences"""
        E, mask = cv2.findEssentialMat(pts1, pts2, camera_matrix, cv2.RANSAC, 0.999, 1.0)
        return E, mask

    def recover_pose(self, E, pts1, pts2, camera_matrix):
        """Recover relative pose from essential matrix"""
        points, R, t, mask = cv2.recoverPose(E, pts1, pts2, camera_matrix)
        return R, t, points, mask
```

```python
class VisionCNN(nn.Module):
    def __init__(self, num_classes=10, input_channels=3):
        super(VisionCNN, self).__init__()

        # Feature extraction layers
        self.conv1 = nn.Conv2d(input_channels, 32, kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(32)
        self.conv2 = nn.Conv2d(32, 64, kernel_size=3, padding=1)
        self.bn2 = nn.BatchNorm2d(64)
        self.conv3 = nn.Conv2d(64, 128, kernel_size=3, padding=1)
        self.bn3 = nn.BatchNorm2d(128)

        # Pooling layers
        self.pool = nn.MaxPool2d(2, 2)

        # Adaptive pooling to handle variable input sizes
        self.adaptive_pool = nn.AdaptiveAvgPool2d((4, 4))

        # Classification head
        self.fc1 = nn.Linear(128 * 4 * 4, 256)
        self.dropout = nn.Dropout(0.5)
        self.fc2 = nn.Linear(256, num_classes)

    def forward(self, x):
        # Feature extraction
        x = F.relu(self.bn1(self.conv1(x)))
        x = self.pool(x)

        x = F.relu(self.bn2(self.conv2(x)))
        x = self.pool(x)

        x = F.relu(self.bn3(self.conv3(x)))
        x = self.adaptive_pool(x)

        # Classification
        x = x.view(x.size(0), -1)  # Flatten
        x = F.relu(self.fc1(x))
        x = self.dropout(x)
        x = self.fc2(x)

        return x
```

```python
    def preprocess_image(self, image, target_size=(416, 416)):
        """Preprocess image for YOLO"""
        # Resize image while maintaining aspect ratio
        h, w = image.shape[:2]
        target_w, target_h = target_size

        # Calculate scaling factor
        scale = min(target_w/w, target_h/h)
        new_w, new_h = int(w * scale), int(h * scale)

        # Resize image
        resized = cv2.resize(image, (new_w, new_h))

        # Pad image to target size
        padded = np.zeros((target_h, target_w, 3), dtype=np.uint8)
        start_x = (target_w - new_w) // 2
        start_y = (target_h - new_h) // 2
        padded[start_y:start_y+new_h, start_x:start_x+new_w] = resized

        # Normalize to [0, 1]
        normalized = padded.astype(np.float32) / 255.0

        # Convert to tensor format (CHW)
        tensor = np.transpose(normalized, (2, 0, 1))

        return tensor, (scale, start_x, start_y)

    def postprocess_output(self, output, image_shape, conf_threshold=0.5, nms_threshold=0.4):
        """Postprocess YOLO output to get final detections"""
        # This is a simplified version of YOLO postprocessing
        # In practice, this would involve reshaping the output, applying sigmoid,
        # filtering by confidence, and applying non-maximum suppression

        # Convert output to detections
        detections = []

        # For demonstration, create mock detections
        for i in range(5):  # Simulate 5 detections
            x = np.random.randint(0, image_shape[1])
            y = np.random.randint(0, image_shape[0])
            w = np.random.randint(50, 200)
            h = np.random.randint(50, 200)

            confidence = np.random.uniform(0.5, 1.0)
            class_id = np.random.randint(0, self.num_classes)

            if confidence > conf_threshold:
                detections.append({
                    'bbox': [x, y, x+w, y+h],
                    'confidence': confidence,
                    'class_id': class_id
                })

        return self.non_max_suppression(detections, nms_threshold)

    def non_max_suppression(self, detections, threshold):
        """Apply non-maximum suppression to remove duplicate detections"""
        if not detections:
            return []

        # Sort detections by confidence
        detections = sorted(detections, key=lambda x: x['confidence'], reverse=True)

        final_detections = []
        while detections:
            best = detections.pop(0)
            final_detections.append(best)

            # Remove overlapping detections
            detections = [det for det in detections
                         if self.calculate_iou(best['bbox'], det['bbox']) < threshold]

        return final_detections

    def calculate_iou(self, bbox1, bbox2):
        """Calculate Intersection over Union"""
        x1, y1, x2, y2 = bbox1
        x3, y3, x4, y4 = bbox2

        # Calculate intersection
        xi1, yi1 = max(x1, x3), max(y1, y3)
        xi2, yi2 = min(x2, x4), min(y2, y4)

        if xi2 <= xi1 or yi2 <= yi1:
            return 0

        intersection = (xi2 - xi1) * (yi2 - yi1)

        # Calculate union
        area1 = (x2 - x1) * (y2 - y1)
        area2 = (x4 - x3) * (y4 - y3)
        union = area1 + area2 - intersection

        return intersection / union if union > 0 else 0
```

```python
import threading
import queue

class RealTimeVisionProcessor:
    def __init__(self, processing_frequency=30):
        self.processing_freq = processing_frequency
        self.dt = 1.0 / processing_frequency
        self.input_queue = queue.Queue(maxsize=2)
        self.output_queue = queue.Queue(maxsize=2)
        self.processing_thread = None
        self.running = False

    def start_processing(self):
        """Start real-time processing"""
        self.running = True
        self.processing_thread = threading.Thread(target=self._processing_loop)
        self.processing_thread.start()

    def stop_processing(self):
        """Stop real-time processing"""
        self.running = False
        if self.processing_thread:
            self.processing_thread.join()

    def _processing_loop(self):
        """Main processing loop"""
        next_time = time.time()

        while self.running:
            start_time = time.time()

            try:
                # Get input frame
                frame = self.input_queue.get_nowait()

                # Process frame
                result = self.process_frame(frame)

                # Put result in output queue
                try:
                    self.output_queue.put_nowait(result)
                except queue.Full:
                    pass  # Drop result if output queue is full

            except queue.Empty:
                pass  # No input available

            # Maintain timing
            next_time += self.dt
            sleep_time = next_time - time.time()
            if sleep_time > 0:
                time.sleep(sleep_time)
            else:
                # Processing took too long, adjust timing
                next_time = time.time()
```

```python
class VisionSystemEvaluator:
    def __init__(self):
        self.metrics = {
            'accuracy': [],
            'precision': [],
            'recall': [],
            'f1_score': [],
            'processing_time': [],
            'frame_rate': []
        }

    def evaluate_detection(self, ground_truth, predictions, iou_threshold=0.5):
        """Evaluate object detection performance"""
        # Calculate True Positives, False Positives, False Negatives
        true_positives = 0
        false_positives = 0
        false_negatives = 0

        # Mark ground truth objects that have been matched
        gt_matched = [False] * len(ground_truth)

        for pred in predictions:
            best_iou = 0
            best_gt_idx = -1

            # Find best matching ground truth
            for gt_idx, gt in enumerate(ground_truth):
                if gt_matched[gt_idx]:
                    continue

                iou = self.calculate_iou(pred['bbox'], gt['bbox'])
                if iou > best_iou and iou >= iou_threshold:
                    best_iou = iou
                    best_gt_idx = gt_idx

            if best_gt_idx != -1:
                # True positive
                true_positives += 1
                gt_matched[best_gt_idx] = True
            else:
                # False positive
                false_positives += 1

        # False negatives are unmatched ground truth objects
        false_negatives = len(ground_truth) - sum(gt_matched)

        # Calculate metrics
        precision = true_positives / (true_positives + false_positives) if (true_positives + false_positives) > 0 else 0
        recall = true_positives / (true_positives + false_negatives) if (true_positives + false_negatives) > 0 else 0
        f1_score = 2 * precision * recall / (precision + recall) if (precision + recall) > 0 else 0

        return {
            'precision': precision,
            'recall': recall,
            'f1_score': f1_score,
            'true_positives': true_positives,
            'false_positives': false_positives,
            'false_negatives': false_negatives
        }

    def calculate_iou(self, bbox1, bbox2):
        """Calculate Intersection over Union"""
        x1, y1, x2, y2 = bbox1
        x3, y3, x4, y4 = bbox2

        # Calculate intersection area
        xi1, yi1 = max(x1, x3), max(y1, y3)
        xi2, yi2 = min(x2, x4), min(y2, y4)

        if xi2 <= xi1 or yi2 <= yi1:
            return 0

        intersection = (xi2 - xi1) * (yi2 - yi1)

        # Calculate union area
        area1 = (x2 - x1) * (y2 - y1)
        area2 = (x4 - x3) * (y4 - y3)
        union = area1 + area2 - intersection

        return intersection / union if union > 0 else 0

    def evaluate_tracking(self, ground_truth_trajectories, predicted_trajectories):
        """Evaluate object tracking performance"""
        # Calculate tracking metrics like MOTA (Multiple Object Tracking Accuracy)
        # This is a simplified version
        total_frames = len(ground_truth_trajectories)

        correct_detections = 0
        total_detections = 0

        for gt_frame, pred_frame in zip(ground_truth_trajectories, predicted_trajectories):
            for gt_obj in gt_frame:
                for pred_obj in pred_frame:
                    if self.calculate_iou(gt_obj['bbox'], pred_obj['bbox']) > 0.5:
                        correct_detections += 1
                        break
            total_detections += len(pred_frame)

        accuracy = correct_detections / total_detections if total_detections > 0 else 0

        return {
            'tracking_accuracy': accuracy,
            'correct_detections': correct_detections,
            'total_detections': total_detections
        }
```
