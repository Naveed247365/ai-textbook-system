# Actuators and Sensors

Actuators and sensors form the essential interface between a robot's control system and the physical world. Actuators provide the force and motion that enable robots to interact with their environment, while sensors provide the information needed for the robot to understand its state and surroundings. Together, they enable robots to perceive, act, and adapt to their environment.

1. Understand the fundamental principles of robot actuators and sensors
2. Compare different types of actuators and their applications
3. Analyze sensor characteristics and selection criteria
4. Design sensor-actuator integration systems
5. Evaluate the performance of actuator-sensor systems

## Introduction to Actuators

Actuators are the "muscles" of robotic systems, converting energy (typically electrical, hydraulic, or pneumatic) into mechanical motion. They are responsible for generating the forces and torques that enable robots to move, grasp objects, and manipulate their environment.

### Classification of Actuators

Actuators can be classified based on their power source:

1. **Electric actuators**: Use electrical energy, most common in robotics
2. **Hydraulic actuators**: Use pressurized fluid, high power density
3. **Pneumatic actuators**: Use compressed air, clean and simple
4. **Piezoelectric actuators**: Use electric fields, precise micro-motion

### Electric Motors

Electric motors are the most prevalent actuators in robotics due to their precision, controllability, and clean operation.

#### DC Motors

DC motors are simple and widely used for basic robotic applications. The fundamental relationship is:

**τ = K_t × I**
**ω = (V - I×R) / (K_e × Φ)**

Where τ is torque, K_t is torque constant, I is current, ω is angular velocity, V is applied voltage, R is resistance, K_e is back-EMF constant, and Φ is magnetic flux.

```python
class DCMotor:
    def __init__(self, torque_constant=0.1, resistance=2.0, inductance=0.01,
                 moment_of_inertia=0.01, damping=0.1):
        self.Kt = torque_constant   # Torque constant (Nm/A)
        self.R = resistance         # Armature resistance (Ohms)
        self.L = inductance         # Armature inductance (H)
        self.J = moment_of_inertia  # Rotor inertia (kg.m^2)
        self.B = damping           # Viscous damping (N.m.s/rad)

    def electrical_model(self, voltage, current, angular_velocity):
        """
        Electrical model of DC motor: V = R*i + L*di/dt + Ke*omega
        """
        back_emf = self.Kt * angular_velocity  # Assuming Ke = Kt in SI units
        di_dt = (voltage - self.R * current - back_emf) / self.L
        return di_dt

    def mechanical_model(self, current, angular_velocity, load_torque=0):
        """
        Mechanical model: J*domega/dt = Kt*i - B*omega - load_torque
        """
        developed_torque = self.Kt * current
        domega_dt = (developed_torque - self.B * angular_velocity - load_torque) / self.J
        return domega_dt

    def update_state(self, voltage, load_torque, dt):
        """
        Update motor state using simple Euler integration
        """
        # Current state
        i = 0  # Simplified - would track current state
        omega = 0  # Simplified - would track velocity state

        # Update electrical state
        di_dt = self.electrical_model(voltage, i, omega)
        new_current = i + di_dt * dt

        # Update mechanical state
        domega_dt = self.mechanical_model(new_current, omega, load_torque)
        new_angular_velocity = omega + domega_dt * dt

        return new_current, new_angular_velocity
```

#### Servo Motors

Servo motors combine a motor with position feedback and control electronics, providing precise position, velocity, and acceleration control.

```python
class ServoMotor:
    def __init__(self, motor, position_controller, gear_ratio=1.0):
        self.motor = motor
        self.position_controller = position_controller
        self.gear_ratio = gear_ratio
        self.current_position = 0.0
        self.current_velocity = 0.0

    def command_position(self, target_pos, dt):
        """
        Command servo motor to move to target position
        """
        # Calculate position error
        position_error = target_pos - self.current_position

        # Use position controller to calculate required torque
        required_torque = self.position_controller.update(target_pos, self.current_position, dt)

        # Apply torque to motor
        load_torque = required_torque / self.gear_ratio  # Account for gearing
        new_current, new_velocity = self.motor.update_state(0, load_torque, dt)

        # Update position based on velocity
        self.current_position += new_velocity * dt
        self.current_velocity = new_velocity

        return self.current_position, new_current, new_velocity
```

#### Stepper Motors

Stepper motors move in discrete steps, providing precise open-loop position control without feedback.

```python
class StepperMotor:
    def __init__(self, steps_per_revolution=200, holding_torque=0.5):
        self.steps_per_rev = steps_per_revolution
        self.holding_torque = holding_torque
        self.current_step = 0
        self.position = 0.0  # In radians

    def step(self, direction=1):
        """
        Move one step in specified direction
        """
        self.current_step += direction
        self.position = (self.current_step / self.steps_per_rev) * 2 * np.pi
        return self.position

    def move_to_step(self, target_step):
        """
        Move to specific step position
        """
        steps_to_move = target_step - self.current_step
        self.current_step = target_step
        self.position = (self.current_step / self.steps_per_rev) * 2 * np.pi
        return self.position

    def move_angle(self, angle_radians):
        """
        Move by specified angle
        """
        target_steps = int(angle_radians / (2 * np.pi) * self.steps_per_rev)
        return self.move_to_step(self.current_step + target_steps)
```

### Hydraulic and Pneumatic Actuators

Hydraulic and pneumatic actuators provide high force-to-weight ratios and are used in applications requiring significant power.

```python
class HydraulicActuator:
    def __init__(self, piston_area=0.001, max_pressure=20e6):  # 20 MPa
        self.piston_area = piston_area  # m^2
        self.max_pressure = max_pressure  # Pa
        self.current_pressure = 0.0
        self.position = 0.0

    def apply_pressure(self, pressure):
        """
        Apply pressure to actuator
        """
        self.current_pressure = min(pressure, self.max_pressure)
        force = self.current_pressure * self.piston_area
        return force

    def move(self, pressure, load_force, dt):
        """
        Move actuator under applied pressure and load
        """
        applied_force = self.apply_pressure(pressure)
        net_force = applied_force - load_force

        # Simplified motion model (assuming mass m)
        acceleration = net_force / 10.0  # 10kg mass for example
        new_velocity = 0  # Would track velocity
        self.position += new_velocity * dt + 0.5 * acceleration * dt**2

        return self.position
```

## Introduction to Sensors

Sensors are the "senses" of robotic systems, providing information about the robot's internal state and external environment. They enable robots to perceive their world and make informed decisions.

### Classification of Sensors

Sensors can be classified as:

1. **Proprioceptive sensors**: Measure internal robot state (position, velocity, force)
2. **Exteroceptive sensors**: Measure external environment (vision, touch, sound)
3. **Interoceptive sensors**: Measure internal system parameters (temperature, voltage)

### Position Sensors

Position sensors measure the location or orientation of robot components.

#### Encoders

Encoders provide precise position feedback and are essential for closed-loop control.

```python
class Encoder:
    def __init__(self, counts_per_revolution=4096, type='incremental'):
        self.cpr = counts_per_revolution
        self.type = type  # 'incremental' or 'absolute'
        self.counts = 0
        self.angle = 0.0
        self.last_angle = 0.0

    def update(self, new_counts):
        """Update encoder reading"""
        if self.type == 'incremental':
            # For incremental encoders, we track changes
            delta_counts = new_counts - self.counts
            self.counts = new_counts
            self.angle += delta_counts * (2 * np.pi / self.cpr)
        else:  # absolute
            self.counts = new_counts
            self.angle = (self.counts % self.cpr) * (2 * np.pi / self.cpr)

        return self.angle

    def get_velocity(self, dt):
        """Calculate angular velocity from position changes"""
        d_angle = self.angle - self.last_angle
        velocity = d_angle / dt
        self.last_angle = self.angle
        return velocity

    def get_position(self):
        """Get current position"""
        return self.angle
```

#### Potentiometers

Simple position sensors that measure position by varying electrical resistance.

```python
class Potentiometer:
    def __init__(self, min_angle=0, max_angle=2*np.pi, supply_voltage=5.0):
        self.min_angle = min_angle
        self.max_angle = max_angle
        self.supply_voltage = supply_voltage
        self.current_angle = 0.0

    def read_voltage(self):
        """
        Simulate voltage reading based on position
        """
        position_ratio = (self.current_angle - self.min_angle) / (self.max_angle - self.min_angle)
        voltage = self.supply_voltage * position_ratio
        return voltage

    def get_angle(self):
        """
        Get angle from voltage reading
        """
        voltage = self.read_voltage()
        position_ratio = voltage / self.supply_voltage
        angle = self.min_angle + position_ratio * (self.max_angle - self.min_angle)
        return angle
```

### Force and Torque Sensors

Force and torque sensors measure the interaction forces between the robot and its environment.

```python
class ForceTorqueSensor:
    def __init__(self, max_force=1000.0, max_torque=100.0):
        self.max_force = max_force
        self.max_torque = max_torque
        self.force = np.zeros(3)  # x, y, z forces
        self.torque = np.zeros(3)  # x, y, z torques

    def measure(self, applied_force, applied_torque):
        """
        Measure applied forces and torques
        """
        # Apply limits
        self.force = np.clip(applied_force, -self.max_force, self.max_force)
        self.torque = np.clip(applied_torque, -self.max_torque, self.max_torque)

        return {
            'force': self.force.copy(),
            'torque': self.torque.copy()
        }

    def get_magnitude(self):
        """
        Get magnitude of force and torque
        """
        force_mag = np.linalg.norm(self.force)
        torque_mag = np.linalg.norm(self.torque)
        return force_mag, torque_mag
```

### Inertial Measurement Units (IMUs)

IMUs measure acceleration, angular velocity, and sometimes magnetic field to determine orientation and motion.

```python
class IMU:
    def __init__(self):
        self.acceleration = np.zeros(3)  # x, y, z
        self.angular_velocity = np.zeros(3)  # roll, pitch, yaw rates
        self.magnetic_field = np.zeros(3)  # x, y, z magnetic field
        self.orientation = np.array([0, 0, 0, 1])  # quaternion [x, y, z, w]

    def read_sensors(self):
        """Simulated sensor reading"""
        # In a real system, this would interface with hardware
        return {
            'acceleration': self.acceleration.copy(),
            'angular_velocity': self.angular_velocity.copy(),
            'magnetic_field': self.magnetic_field.copy(),
            'orientation': self.orientation.copy()
        }

    def complementary_filter(self, acc_data, gyro_data, dt, alpha=0.98):
        """
        Simple complementary filter to combine accelerometer and gyroscope data
        """
        # Get orientation from accelerometer (pitch and roll only)
        if np.linalg.norm(acc_data) > 0.1:  # Avoid division by zero
            acc_pitch = np.arctan2(acc_data[0], np.sqrt(acc_data[1]**2 + acc_data[2]**2))
            acc_roll = np.arctan2(-acc_data[1], acc_data[2])

            # Integrate gyroscope data for all angles
            gyro_roll = self.orientation[0] + gyro_data[0] * dt
            gyro_pitch = self.orientation[1] + gyro_data[1] * dt
            gyro_yaw = self.orientation[2] + gyro_data[2] * dt

            # Apply complementary filter
            filtered_roll = alpha * gyro_roll + (1 - alpha) * acc_roll
            filtered_pitch = alpha * gyro_pitch + (1 - alpha) * acc_pitch

            # Update orientation (simplified - full quaternion math needed for complete implementation)
            self.orientation[0] = filtered_roll
            self.orientation[1] = filtered_pitch
            self.orientation[2] = gyro_yaw  # Yaw from gyroscope only (accelerometer can't measure yaw)

        return self.orientation

    def integrate_gyro(self, gyro_data, dt):
        """
        Simple gyroscope integration for orientation
        """
        # Convert angular velocity to quaternion derivative
        omega = np.concatenate([[0], gyro_data])  # [0, wx, wy, wz]
        q_dot = 0.5 * quat_multiply(omega, self.orientation)
        self.orientation += q_dot * dt
        self.orientation = self.orientation / np.linalg.norm(self.orientation)  # Normalize

        return self.orientation

def quat_multiply(q1, q2):
    """
    Multiply two quaternions
    """
    w1, x1, y1, z1 = q1
    w2, x2, y2, z2 = q2

    w = w1*w2 - x1*x2 - y1*y2 - z1*z2
    x = w1*x2 + x1*w2 + y1*z2 - z1*y2
    y = w1*y2 - x1*z2 + y1*w2 + z1*x2
    z = w1*z2 + x1*y2 - y1*x2 + z1*w2

    return np.array([w, x, y, z])
```

## Sensor-Actuator Integration

The integration of sensors and actuators is crucial for closed-loop control systems.

```python
class SensorActuatorSystem:
    def __init__(self, actuator, sensor, controller):
        self.actuator = actuator
        self.sensor = sensor
        self.controller = controller
        self.feedback = None
        self.command = None

    def control_cycle(self, desired_value, dt):
        """
        Complete control cycle: sense, decide, act
        """
        # 1. Sense current state
        self.feedback = self.sensor.get_position() if hasattr(self.sensor, 'get_position') else 0

        # 2. Compute control command
        self.command = self.controller.update(desired_value, self.feedback, dt)

        # 3. Apply to actuator
        result = self.actuator.command_position(self.command, dt) if hasattr(self.actuator, 'command_position') else None

        return {
            'feedback': self.feedback,
            'command': self.command,
            'result': result
        }

    def run_trajectory(self, trajectory, dt=0.01):
        """
        Execute a trajectory using sensor-actuator system
        """
        results = []
        for desired_pos in trajectory:
            result = self.control_cycle(desired_pos, dt)
            results.append(result)
        return results
```

## Advanced Sensor Systems

### Tactile Sensors

Tactile sensors provide information about contact, pressure, and texture.

```python
class TactileSensor:
    def __init__(self, sensor_array_size=(8, 8)):
        self.array_size = sensor_array_size
        self.pressure_map = np.zeros(sensor_array_size)
        self.contact_detected = False

    def sense_contact(self, force_distribution):
        """
        Sense contact and pressure distribution
        """
        self.pressure_map = np.reshape(force_distribution, self.array_size)
        self.contact_detected = np.any(self.pressure_map > 0.1)  # Threshold for contact
        return {
            'pressure_map': self.pressure_map.copy(),
            'contact': self.contact_detected,
            'total_force': np.sum(self.pressure_map),
            'contact_center': self._find_contact_center()
        }

    def _find_contact_center(self):
        """
        Find center of pressure
        """
        if not self.contact_detected:
            return None

        y_indices, x_indices = np.mgrid[0:self.array_size[0], 0:self.array_size[1]]
        total_force = np.sum(self.pressure_map)

        if total_force > 0:
            center_x = np.sum(x_indices * self.pressure_map) / total_force
            center_y = np.sum(y_indices * self.pressure_map) / total_force
            return (center_x, center_y)
        else:
            return (0, 0)
```

### Multi-Sensor Fusion

Combining information from multiple sensors to improve accuracy and robustness.

```python
class MultiSensorFusion:
    def __init__(self):
        self.estimates = {}
        self.confidences = {}

    def add_sensor_data(self, sensor_name, measurement, confidence=1.0):
        """
        Add data from a sensor with associated confidence
        """
        self.estimates[sensor_name] = measurement
        self.confidences[sensor_name] = confidence

    def weighted_average_fusion(self):
        """
        Fuse sensor data using weighted average based on confidence
        """
        if not self.estimates:
            return None

        # For scalar values
        weighted_sum = 0
        total_weight = 0

        for sensor, value in self.estimates.items():
            weight = self.confidences[sensor]
            weighted_sum += weight * value
            total_weight += weight

            fused_estimate = weighted_sum / total_weight

            return list(self.estimates.values())[0]  # Fallback
```

## Performance Considerations

### Sensor Accuracy and Precision

Sensors have various error characteristics that affect system performance:

- **Accuracy**: How close the measurement is to the true value
- **Precision**: How consistent repeated measurements are
- **Resolution**: Smallest detectable change
- **Linearity**: Deviation from ideal linear response
- **Hysteresis**: Difference in readings during increasing vs. decreasing input

### Actuator Performance Metrics

Actuator performance is characterized by:

- **Response time**: Time to reach commanded position
- **Precision**: Accuracy of position control
- **Backlash**: Lost motion due to mechanical play
- **Efficiency**: Power conversion effectiveness
- **Torque/Force density**: Output force per unit size/weight

### Bandwidth and Sampling Considerations

The control system bandwidth must match the sensor-actuator capabilities:

```python
class ControlSystemDesign:
    def __init__(self, sensor_bandwidth, actuator_bandwidth, desired_bandwidth):
        self.sensor_bw = sensor_bandwidth  # Hz
        self.actuator_bw = actuator_bandwidth  # Hz
        self.desired_bw = desired_bandwidth  # Hz
        self.sampling_rate = min(sensor_bandwidth, actuator_bandwidth) * 2  # Nyquist

    def check_stability_margins(self):
        """
        Check if system components support desired bandwidth
        """
        if self.desired_bw > 0.1 * self.sensor_bw:
            print("Warning: Desired bandwidth may be too high for sensor")
        if self.desired_bw > 0.1 * self.actuator_bw:
            print("Warning: Desired bandwidth may be too high for actuator")

        return {
            'sensor_limit': 0.1 * self.sensor_bw,
            'actuator_limit': 0.1 * self.actuator_bw,
            'recommended_max': min(0.1 * self.sensor_bw, 0.1 * self.actuator_bw)
        }
```

## Safety and Reliability

### Sensor Failure Detection

```python
class SensorHealthMonitor:
    def __init__(self, sensor, expected_range, timeout_threshold=1.0):
        self.sensor = sensor
        self.expected_range = expected_range
        self.timeout_threshold = timeout_threshold
        self.last_reading_time = time.time()
        self.reading_history = []

    def check_health(self):
        """
        Check sensor health based on range and timing
        """
        try:
            reading = self.sensor.get_position() if hasattr(self.sensor, 'get_position') else 0
            current_time = time.time()

            # Check if reading is in expected range
            in_range = self.expected_range[0] <= reading <= self.expected_range[1]

            # Check if reading is timely
            timely = (current_time - self.last_reading_time) < self.timeout_threshold

            # Update history
            self.reading_history.append((current_time, reading))
            if len(self.reading_history) > 100:  # Keep last 100 readings
                self.reading_history.pop(0)

            health_status = {
                'healthy': in_range and timely,
                'in_range': in_range,
                'timely': timely,
                'reading': reading
            }

            self.last_reading_time = current_time
            return health_status

        except Exception as e:
            return {
                'healthy': False,
                'error': str(e),
                'reading': None
            }
```

Proper selection, integration, and utilization of these components are crucial for achieving desired robot performance. Understanding the characteristics, limitations, and integration challenges of actuators and sensors is essential for effective robotic system design.
