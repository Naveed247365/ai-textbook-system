# روبوٹ کنٹرول سسٹم - اعلیٰ

روبوٹ کنٹرول سسٹم روبوٹکس کے سب سے جامع اور ریاضیاتی لحاظ سے سخت پہلو میں سے ایک ہے، جس میں نظریاتی بنیادیں، اعلیٰ میتھڈولوژیز، اور عملی نفاذ کو شامل کیا گیا ہے جو ہائی پرفارمنس روبوٹک آپریشن کے لیے ضروری ہے۔ یہ سسٹم امیر ترین ٹاسک کی وضاحتیں اور درست جسمانی انجام دہی کے درمیان پل کو جوڑتے ہیں، جس کے لیے سسٹم ڈائنامکس، آپٹیمائزیشن تھیوری، اور ریل ٹائم کمپیوٹنگ کی گہری سمجھ کی ضرورت ہوتی ہے۔

## ریاضیاتی بنیادیں اور سسٹم تھیوری

روبوٹ کنٹرول سسٹم کی نظریاتی بنیاد ماڈرن کنٹرول تھیوری میں جڑی ہوئی ہے، جو سسٹم کے رویے کو ماڈل کرنے کے لیے اسٹیٹ اسپیس کی نمائندگی اور ڈیفرینشل ایکویشن کا استعمال کرتی ہے۔ روبوٹک سسٹم کے لیے، اسٹیٹ اسپیس کی نمائندگی اس شکل میں ہے:

**ẋ = f(x, u, t)**
**y = h(x, t)**

جہاں x اسٹیٹ ویکٹر کی نمائندگی کرتا ہے، u کنٹرول ان پٹ ویکٹر، y آؤٹ پٹ ویکٹر، اور f اور h غیر لکیری فنکشن ہیں جو سسٹم ڈائنامکس کی وضاحت کرتے ہیں۔

خصوصی طور پر روبوٹک مینیپولیٹر کے لیے، اسٹیٹ اسپیس ماڈل بنیادی ڈائنا مک مساوات کو شامل کرتا ہے:

**M(q)q̈ + C(q, q̇)q̇ + G(q) + F(q, q̇) = τ**

جہاں کنٹرول ان پٹ τ سسٹم میں لگائے گئے جوڑ ٹورکس کی نمائندگی کرتا ہے۔

### لیاپونوو سٹیبیلٹی تھیوری

لیاپونوو سٹیبیلٹی تجزیہ کنٹرولر کی سٹیبیلٹی کو ثابت کرنے کے لیے ریاضیاتی ڈھانچہ فراہم کرتا ہے۔ ایک لیاپونوو فنکشن V(x) کو درج ذیل کو پورا کرنا چاہیے:

1. **V(0) = 0** اور **V(x) > 0** for all **x ≠ 0** (مثبت واضح)
2. **V̇(x) ≤ 0** for all **x** (منفی نیم-ویسی)

ایسٹمپٹوک سٹیبیلٹی کے لیے، **V̇(x) < 0** for all **x ≠ 0**.

```python
import numpy as np
from scipy.integrate import solve_ivp

class LyapunovStabilityAnalyzer:
    def __init__(self, system_model):
        self.system = system_model

    def construct_lyapunov_function(self, state):
        """
        سسٹم کے لیے امکانی لیاپونوو فنکشن بنائیں
        ایک سادہ سسٹم کے لیے، اکثر V(x) = x^T P x استعمال کریں جہاں P مثبت واضح ہے
        """
        # ایک سادہ مثال کے لیے، ایک 2-اسٹیٹ سسٹم پر غور کریں
        P = np.array([[2, 0], [0, 1]])  # مثبت واضح میٹرکس
        V = state.T @ P @ state
        return V

    def check_stability(self, state_trajectory):
        """
        چیک کریں کہ کیا لیاپونوو فنکشن سسٹم ٹریجیکٹریز کے ساتھ کم ہو رہا ہے
        """
        V_values = [self.construct_lyapunov_function(state) for state in state_trajectory]

        # چیک کریں کہ کیا V کم ہو رہا ہے (سٹیبیلٹی کی حالت)
        for i in range(1, len(V_values)):
            if V_values[i] > V_values[i-1]:
                return False, f"Lyapunov function increased at step {i}"

        return True, "Lyapunov function decreasing - system appears stable"
```

## اعلیٰ کنٹرول میتھڈولوژیز

### ماڈل پریڈکٹو کنٹرول (MPC)

ماڈل پریڈکٹو کنٹرول ایک طاقتور آپٹیمائزیشن-بیسڈ نقطہ نظر کی نمائندگی کرتا ہے جو ہر وقت قدم پر محدود-افق کے بہترین کنٹرول مسائل کو حل کرتا ہے۔ فارمولیشن میں عام طور پر شامل ہے:

**کم سے کم** Σ(k=0 to N-1) l(x_k, u_k) + V_f(x_N)
**م subject to:** x_{k+1} = f(x_k, u_k), x_0 = x_current
**اور:** x_min ≤ x_k ≤ x_max, u_min ≤ u_k ≤ u_max

جہاں l اسٹیج کاسٹ کی نمائندگی کرتا ہے، V_f ٹرمنل کاسٹ، اور قیود اسٹیٹس اور کنٹرولس کو باؤنڈ کرتے ہیں۔

```python
import cvxpy as cp

class ModelPredictiveController:
    def __init__(self, A, B, Q, R, N, state_constraints=None, control_constraints=None):
        self.A = A  # اسٹیٹ ٹرانزیشن میٹرکس
        self.B = B  # کنٹرول ان پٹ میٹرکس
        self.Q = Q  # اسٹیٹ کاسٹ میٹرکس
        self.R = R  # کنٹرول کاسٹ میٹرکس
        self.N = N  # پریڈکشن ہوریزن
        self.state_constraints = state_constraints
        self.control_constraints = control_constraints

    def solve_mpc(self, x_current):
        """
        MPC آپٹیمائزیشن مسئلہ حل کریں
        """
        # آپٹیمائزیشن متغیرات کی وضاحت کریں
        X = cp.Variable((self.N + 1, self.A.shape[0]))  # اسٹیٹ سیکوئنس
        U = cp.Variable((self.N, self.B.shape[1]))      # کنٹرول سیکوئنس

        # اہداف کا فنکشن
        cost = 0
        for k in range(self.N):
            cost += cp.quad_form(X[k, :], self.Q)
            cost += cp.quad_form(U[k, :], self.R)
        cost += cp.quad_form(X[self.N, :], self.Q)  # ٹرمنل کاسٹ

        # قیود
        constraints = [X[0, :] == x_current]

        for k in range(self.N):
            constraints.append(X[k+1, :] == self.A @ X[k, :] + self.B @ U[k, :])

            if self.control_constraints:
                constraints.append(U[k, :] <= self.control_constraints[1])
                constraints.append(U[k, :] >= self.control_constraints[0])

        # آپٹیمائزیشن مسئلہ حل کریں
        problem = cp.Problem(cp.Minimize(cost), constraints)
        problem.solve()

        if problem.status == cp.OPTIMAL:
            return U.value[0, :]  # پہلا کنٹرول ان پٹ واپس کریں
        else:
            raise Exception(f"MPC optimization failed with status: {problem.status}")
```

### سلائیڈنگ موڈ کنٹرول

سلائیڈنگ موڈ کنٹرول ایک مضبوط کنٹرول میتھوڈولو جی ہے جو سسٹم اسٹیٹ کو ایک متعینہ سلائیڈنگ سطح کے ساتھ فولو کرنے پر مجبور کرتا ہے، مماثل غیر یقینی کے خلاف بے حسی فراہم کرتا ہے۔

سلائیڈنگ سطح عام طور پر اس طرح بیان کی جاتی ہے:
**s(x) = Cx = 0**

جہاں C کو اس طرح منتخب کیا جاتا ہے کہ سسٹم سٹیبل ہو جب s(x) = 0 کو قید کیا جائے۔

کنٹرول لا اس کے دو اجزاء پر مشتمل ہے:
**u = u_eq + u_sw**

جہاں u_eq مساوی کنٹرول ہے اور u_sw سوئچنگ کنٹرول ہے۔

```python
class SlidingModeController:
    def __init__(self, system_params, sliding_surface_matrix, switching_gain=1.0):
        self.C = sliding_surface_matrix
        self.k = switching_gain
        self.system_params = system_params

    def sliding_surface(self, state):
        """سلائیڈنگ سطح کی قیمت کمپیوٹ کریں"""
        return self.C @ state

    def control_law(self, state, reference_state=None):
        """
        سلائیڈنگ موڈ کنٹرول لا کمپیوٹ کریں
        """
        # سلائیڈنگ سطح
        s = self.sliding_surface(state)

        # مساوی کنٹرول (لکیری سسٹم کا فرض کریں)
        # u_eq = -B^(-1) * (A*x - x_dot_desired)
        u_eq = self.compute_equivalent_control(state, reference_state)

        # سوئچنگ کنٹرول
        u_sw = -self.k * np.sign(s)

        # کل کنٹرول
        u_total = u_eq + u_sw

        return u_total

    def compute_equivalent_control(self, state, reference_state):
        """مساوی کنٹرول کا جزو کمپیوٹ کریں"""
        # یہ مخصوص سسٹم ڈائنا مکس پر منحصر ہوگا
        # سادہ نفاذ
        return np.zeros_like(state)
```

### پیرامیٹر ایسٹیمیشن کے ساتھ ایڈاپٹو کنٹرول

ایڈاپٹو کنٹرول سسٹم آن لائن کنٹرولر پیرامیٹرز کو ایڈجسٹ کرتے ہیں تاکہ سسٹم کی غیر یقینی اور پیرامیٹر کی تبدیلیوں کا مقابلہ کیا جا سکے۔

ماڈل ریفرنس ایڈاپٹو کنٹرول (MRAC) نقطہ نظر لیاپونوو سٹیبیلٹی تجزیہ سے حاصل کردہ پیرامیٹر اپ ڈیٹ لا کا استعمال کرتا ہے:

**θ̇ = -Γφ(x)e**

جہاں θ پیرامیٹر ویکٹر کی نمائندگی کرتا ہے، Γ ایڈاپٹیشن گین میٹرکس ہے، φ(x) ریگریسر ویکٹر ہے، اور e ٹریکنگ غلطی ہے۔

```python
class ModelReferenceAdaptiveController:
    def __init__(self, initial_params, adaptation_gain, reference_model):
        self.θ = initial_params.copy()
        self.Γ = adaptation_gain
        self.reference_model = reference_model
        self.param_history = []

    def update_params(self, regressor, tracking_error):
        """
        گریڈینٹ ڈیسینٹ کا استعمال کرکے پیرامیٹر اپ ڈیٹ کریں
        """
        param_update = -self.Γ @ regressor @ tracking_error
        self.θ += param_update
        self.param_history.append(self.θ.copy())
        return self.θ

    def control_law(self, state, reference_state, regressor):
        """
        ایڈاپٹو کنٹرول لا کمپیوٹ کریں
        """
        # موجودہ پیرامیٹر ایسٹیمیٹس کے مطابق کنٹرول
        control_output = self.θ @ regressor
        return control_output

    def persistent_excitation_check(self, regressor_history, window_size=10):
        """
        دائمی تحریک کی حالت چیک کریں
        """
        if len(regressor_history) < window_size:
            return False

        # چیک کریں کہ کیا ریگریسر کافی تحریک فراہم کرتا ہے
        # یہ انفارمیشن میٹرکس کا درجہ چیک کرنے میں شامل ہے
        recent_regressors = np.array(regressor_history[-window_size:])
        information_matrix = np.sum([
            np.outer(φ, φ) for φ in recent_regressors
        ], axis=0)

        # چیک کریں کہ کیا میٹرکس مکمل درجہ ہے (دائمی تحریک کی حالت)
        rank = np.linalg.matrix_rank(information_matrix)
        return rank == information_matrix.shape[0]
```

## آپٹیمل کنٹرول اور ٹریجیکٹری آپٹیمائزیشن

### لکیری چوکریٹک ریگولیٹر (LQR)

لکیری چوکریٹک ریگولیٹر لکیری سسٹم کے لیے بہترین کنٹرول فراہم کرتا ہے جس میں چوکریٹک قیمت کے فنکشن ہوتے ہیں۔ بہترین کنٹرول لا ہے:

**u* = -Kx**

جہاں K = R^(-1)B^T P، اور P الجبرک ریکیٹی ایکویشن کا حل ہے:

**A^T P + PA - PBR^(-1)B^T P + Q = 0**

```python
import scipy.linalg as la

class LinearQuadraticRegulator:
    def __init__(self, A, B, Q, R):
        self.A = A
        self.B = B
        self.Q = Q
        self.R = R

        # الجبرک ریکیٹی ایکویشن حل کریں
        self.P = la.solve_continuous_are(A, B, Q, R)

        # بہترین گین میٹرکس کمپیوٹ کریں
        self.K = la.inv(R) @ self.B.T @ self.P

    def control_law(self, state):
        """بہترین LQR کنٹرول کمپیوٹ کریں"""
        return -self.K @ state

    def cost_to_go(self, state):
        """لامحدود-افق کی قیمت-کو-جانا کمپیوٹ کریں"""
        return state.T @ self.P @ state
```

### غیر لکیری ٹریجیکٹری آپٹیمائزیشن

غیر لکیری سسٹم کے لیے، ٹریجیکٹری آپٹیمائزیشن مسائل اس طرح فارمولیٹ کیے جاتے ہیں:

**کم سے کم** ∫[t₀ to t_f] L(x(t), u(t), t) dt + φ(x(t_f))
**م subject to:** ẋ = f(x, u, t), x(t₀) = x₀, g(x, u) ≤ 0

ان مسائل کو عام طور پر براہ راست میتھڈ (کولوکیشن، شوٹنگ) یا بالواسطہ میتھڈ (پونتریاگن کا اصول) کا استعمال کرکے حل کیا جاتا ہے۔

```python
from scipy.optimize import minimize

class NonlinearTrajectoryOptimizer:
    def __init__(self, system_dynamics, initial_state, final_state, time_horizon):
        self.f = system_dynamics
        self.x0 = initial_state
        self.xf = final_state
        self.tf = time_horizon

    def trajectory_cost(self, trajectory_vars):
        """
        ٹریجیکٹری کی قیمت کمپیوٹ کریں
        trajectory_vars = [x0, x1, ..., xN, u0, u1, ..., uN-1]
        """
        n_states = len(self.x0)
        n_controls = len(trajectory_vars) - (self.tf + 1) * n_states  # سادہ
        n_points = self.tf + 1

        states = trajectory_vars[:n_states * n_points].reshape(n_points, n_states)
        controls = trajectory_vars[n_states * n_points:].reshape(n_points - 1, -1)

        # چلنے والی قیمت کمپیوٹ کریں
        running_cost = 0
        for i in range(n_points - 1):
            # مثال: چوکریٹک قیمت
            running_cost += 0.5 * (states[i] @ states[i] + controls[i] @ controls[i])

        # ٹرمنل قیمت
        terminal_cost = 0.5 * (states[-1] - self.xf) @ (states[-1] - self.xf)

        return running_cost + terminal_cost

    def trajectory_constraints(self, trajectory_vars):
```

## سٹوکاسٹک کنٹرول اور ایسٹیمیشن

### کیلمن فلٹر

کیلمن فلٹر لکیری سسٹم کے لیے بہترین اسٹیٹ ایسٹیمیشن فراہم کرتا ہے جس میں گاؤسین نوائز ہوتا ہے:

**پریڈکشن:**
- x̂_{k|k-1} = A x̂_{k-1|k-1} + B u_k
- P_{k|k-1} = A P_{k-1|k-1} A^T + Q

**اپ ڈیٹ:**
- K_k = P_{k|k-1} H^T (H P_{k|k-1} H^T + R)^(-1)
- x̂_{k|k} = x̂_{k|k-1} + K_k (y_k - H x̂_{k|k-1})
- P_{k|k} = (I - K_k H) P_{k|k-1}

```python
class ExtendedKalmanFilter:
    def __init__(self, state_dim, measurement_dim, process_noise, measurement_noise):
        self.n = state_dim
        self.m = measurement_dim
        self.Q = process_noise
        self.R = measurement_noise
        self.P = np.eye(state_dim) * 0.1  # ابتدائی کوواریئنس
        self.x = np.zeros(state_dim)      # ابتدائی اسٹیٹ

    def predict(self, control_input, f_func, F_func):
        """
        غیر لکیری ڈائنا مکس کا استعمال کرکے پریڈکشن اسٹیپ
        f_func: غیر لکیری اسٹیٹ ٹرانزیشن فنکشن
        F_func: اسٹیٹ ٹرانزیشن فنکشن کا جیکوبین
        """
        # اسٹیٹ کی پریڈکشن
        self.x = f_func(self.x, control_input)

        # کوواریئنس کی پریڈکشن
        F = F_func(self.x, control_input)
        self.P = F @ self.P @ F.T + self.Q

    def update(self, measurement, h_func, H_func):
        """
        غیر لکیری پیمائش ماڈل کا استعمال کرکے اپ ڈیٹ اسٹیپ
        h_func: غیر لکیری پیمائش فنکشن
        H_func: پیمائش فنکشن کا جیکوبین
        """
        # انوویشن کمپیوٹ کریں
        y_pred = h_func(self.x)
        innovation = measurement - y_pred

        # جیکوبین کمپیوٹ کریں
        H = H_func(self.x)

        # کیلمن گین کمپیوٹ کریں
        S = H @ self.P @ H.T + self.R
        K = self.P @ H.T @ np.linalg.inv(S)

        # اسٹیٹ اور کوواریئنس اپ ڈیٹ کریں
        self.x = self.x + K @ innovation
        self.P = (np.eye(self.n) - K @ H) @ self.P
```

### سٹوکاسٹک آپٹیمل کنٹرول

سٹوکاسٹک آپٹیمل کنٹرول غیر یقینی کے ساتھ والے سسٹم کو ہیملٹن-جیکوبی-بلمن ایکویشن کا استعمال کرکے حل کرتا ہے:

**-∂V/∂t = min_u {L(x, u) + ∇V · f(x, u) + (1/2) Tr[σ^T ∇²V σ]}**

جہاں V ویلیو فنکشن ہے، L چلنے والی قیمت ہے، f سسٹم ڈائنا مکس کی نمائندگی کرتا ہے، اور σ ڈفیوژن اجزاء کی نمائندگی کرتا ہے۔

### ریل ٹائم آپریٹنگ سسٹم

روبوٹک کنٹرول سسٹم کو متعین وقت کا رویہ چاہیے:

```python
import threading
import time
import queue

class RealTimeControlSystem:
    def __init__(self, control_frequency=1000):  # 1kHz
        self.control_frequency = control_frequency
        self.dt = 1.0 / control_frequency
        self.running = False
        self.control_thread = None
        self.sensor_queue = queue.Queue()
        self.command_queue = queue.Queue()
        self.timing_stats = {'min': float('inf'), 'max': 0, 'avg': 0}
        self.iteration_count = 0

    def control_loop(self):
        """ہارڈ ریل ٹائم کنٹرول لوپ"""
        period = self.dt
        next_start = time.time()

        while self.running:
            start_time = time.time()

            # سینسر ڈیٹا کو پروسیس کریں
            sensor_data = self.get_sensor_data()

            # کنٹرول الگورتھم انجام دیں
            control_output = self.compute_control(sensor_data)

            # کنٹرول کمانڈز لاگو کریں
            self.send_commands(control_output)

            # ٹائم کی اعداد و شمار کا حساب لگائیں
            elapsed = time.time() - start_time
            self.timing_stats['min'] = min(self.timing_stats['min'], elapsed)
            self.timing_stats['max'] = max(self.timing_stats['max'], elapsed)

            self.iteration_count += 1
            if self.iteration_count == 1:
                self.timing_stats['avg'] = elapsed
            else:
                self.timing_stats['avg'] = (self.timing_stats['avg'] * (self.iteration_count - 1) + elapsed) / self.iteration_count

            # ٹائم کو برقرار رکھیں
            next_start += period
            sleep_time = next_start - time.time()

            if sleep_time > 0:
                time.sleep(sleep_time)
            else:
                # ڈیڈ لائن چھوٹ گئی
                print(f"Control deadline missed by {abs(sleep_time):.4f}s")

    def start(self):
        """ریل ٹائم کنٹرول شروع کریں"""
        self.running = True
        self.control_thread = threading.Thread(target=self.control_loop, daemon=True)
```

```python
import torch
import torch.nn as nn

class NeuralNetworkController(nn.Module):
    def __init__(self, state_dim, action_dim, hidden_dim=256):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(state_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, hidden_dim),
            nn.ReLU(),
            nn.Linear(hidden_dim, action_dim)
        )

    def forward(self, state):
        return self.network(state)

class LearningBasedController:
    def __init__(self, state_dim, action_dim):
        self.controller = NeuralNetworkController(state_dim, action_dim)
        self.optimizer = torch.optim.Adam(self.controller.parameters())
        self.replay_buffer = []

    def update_policy(self, states, actions, rewards, next_states):
        """
        مضبوطی سیکھنے کا استعمال کرکے نیورل نیٹ ورک کنٹرولر اپ ڈیٹ کریں
        """
        states = torch.FloatTensor(states)
        actions = torch.FloatTensor(actions)
        rewards = torch.FloatTensor(rewards)

        # قیمت کمپیوٹ کریں (مثال: پالیسی گریڈینٹ)
        predicted_actions = self.controller(states)
        loss = torch.mean((predicted_actions - actions)**2)

        # بیک پروپیگیٹ اور اپ ڈیٹ
```

```python
class MultiRobotController:
    def __init__(self, num_robots, communication_topology):
        self.num_robots = num_robots
        self.topology = communication_topology
        self.robot_controllers = [None] * num_robots

    def consensus_control(self, robot_states, desired_formation):
        """
        فارمیشن کنٹرول کے لیے روبوٹس میں اتفاق حاصل کریں
        """
        consensus_errors = []

        for i in range(self.num_robots):
            # پڑوسیوں کی بنیاد پر اتفاق کا جزو کمپیوٹ کریں
            neighbor_sum = 0
            neighbor_count = 0

            for j in range(self.num_robots):
                if self.topology[i, j] > 0:  # منسلک
                    neighbor_sum += robot_states[j]
                    neighbor_count += 1

            if neighbor_count > 0:
                consensus_term = (neighbor_sum / neighbor_count) - robot_states[i]
                consensus_errors.append(consensus_term)

        return consensus_errors
```
