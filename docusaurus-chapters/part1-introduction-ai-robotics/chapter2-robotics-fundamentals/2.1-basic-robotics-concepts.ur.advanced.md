# روبوٹکس کے بنیادی تصورات (اردو ایڈوانسڈ)

## روبوٹکس کی ریاضیاتی بنیادیں

### ہوموجینیس ٹرانسفارمیشنز

روبوٹکس میں، ہم 3D سپیس میں پوزیشن اور اورینٹیشن کو ظاہر کرنے کے لیے ہوموجینیس ٹرانسفارمیشن میٹرکس استعمال کرتے ہیں۔ ایک ہوموجینیس ٹرانسفارمیشن T ∈ SE(3) (سپیشل یوکلڈئن گروپ) ایک 4×4 میٹرکس ہے:

```
T = [R   p]
    [0   1]
```

جہاں R ∈ SO(3) ایک 3×3 روٹیشن میٹرکس ہے اور p ∈ ℝ³ ایک پوزیشن ویکٹر ہے۔ روٹیشن میٹرکس R کو آرتھوگونلیٹی کنڈیشن R^T R = I اور det(R) = 1 کو پورا کرنا چاہیے۔

### ڈینوٹ-ہارٹنبرگ (DH) کنونشن

DH کنونشن روبوٹک مینیپولیٹرز میں کوآرڈینیٹ فریموں کو وضاحت کرنے کا ایک نظامی طریقہ فراہم کرتا ہے۔ ہر جوائنٹ i کو چار پیرامیٹرز کے ذریعے ظاہر کیا جاتا ہے:

- aᵢ: لنک لمبائی (کامن نارمل کے ساتھ فاصلہ)
- αᵢ: لنک ٹوسٹ (z-ایکسز کے درمیان اینگل)
- dᵢ: لنک آف سیٹ (پچھلے z-ایکسز کے ساتھ فاصلہ)
- θᵢ: جوائنٹ اینگل (پچھلے z-ایکسز کے گرد گھوماؤ)

فریم i-1 اور i کے درمیان ٹرانسفارمیشن میٹرکس ہے:

```
Tᵢ^(i-1) = [cθᵢ   -sθᵢcαᵢ   sθᵢsαᵢ   aᵢcθᵢ]
           [sθᵢ    cθᵢcαᵢ  -cθᵢsαᵢ   aᵢsθᵢ]
           [0      sαᵢ       cαᵢ      dᵢ   ]
           [0      0         0        1    ]
```

## روبوٹ کنیمیٹکس

### فارورڈ کنیمیٹکس

فارورڈ کنیمیٹکس جوائنٹ ویریبلز q = [θ₁, θ₂, ..., θₙ]ᵀ کے دیے گئے ہونے پر اینڈ ایفیکٹر کا پوز کمپیوٹ کرتا ہے:

**پوزیشن**: pₑ = f(q)
**اورینٹیشن**: Rₑ = R(q)

مکمل پوز اس طرح ظاہر کیا گیا ہے:
```
Tₑ = [Rₑ   pₑ]
     [0    1 ]
```

### جیکوبین میٹرکس

جیکوبین میٹرکس J(q) جوائنٹ ویلوسیٹیز کو اینڈ ایفیکٹر ویلوسیٹیز سے جوڑتی ہے:

```
[ṗₑ] = J(q) [θ̇₁]
[ωₑ]         [⋮ ]
             [θ̇ₙ]
```

جہاں ṗₑ لینئر ویلوسیٹی ہے اور ωₑ اینڈ ایفیکٹر کی اینگولر ویلوسیٹی ہے۔

جیکوبین کو اس طرح کمپیوٹ کیا جا سکتا ہے:

**لینئر ویلوسیٹی کمپونینٹ**:
```
Jvᵢ = zᵢ₋₁ × (pₑ - pᵢ₋₁) ریوولوٹ جوائنٹس کے لیے
Jvᵢ = zᵢ₋₁ پرزمیٹک جوائنٹس کے لیے
```

**اینگولر ویلوسیٹی کمپونینٹ**:
```
Jωᵢ = zᵢ₋₁ ریوولوٹ جوائنٹس کے لیے
Jωᵢ = 0 پرزمیٹک جوائنٹس کے لیے
```

### انورس کنیمیٹکس

انورس کنیمیٹکس اینڈ ایفیکٹر کے مطلوبہ پوز T_d کے دیے گئے ہونے پر جوائنٹ ویریبلز q کو حل کرتا ہے:

**اینالیٹیکل سلوشنز**: کلوزڈ فارم سلوشنز مخصوص روبوٹ جیومیٹریز کے لیے موجود ہیں (مثلاً 6-DOF روبوٹس جن کے وسٹ جوائنٹس مل جاتے ہیں)۔

**نیو میریکل سلوشنز**: جنرل کیسز کے لیے دہرائے والے طریقے:

```python
def inverse_kinematics_jacobian(robot, target_pose, initial_guess, max_iterations=100, tolerance=1e-6):
    """
    جیکوبین بیسڈ انورس کنیمیٹکس سلوشن
    """
    q = np.array(initial_guess)

    for i in range(max_iterations):
        # کرنٹ اینڈ ایفیکٹر پوز کمپیوٹ کریں
        current_pose = robot.forward_kinematics(q)

        # پوز ایرر کیلکولیٹ کریں
        error = calculate_pose_error(target_pose, current_pose)

        # کنورجنس چیک کریں
        if np.linalg.norm(error) < tolerance:
            break

        # جیکوبین کمپیوٹ کریں
        J = robot.jacobian(q)

        # جوائنٹ ویلوسیٹی اپڈیٹ کیلکولیٹ کریں
        # سنگولریٹیز کو ہینڈل کرنے کے لیے ڈیمپڈ لیسٹ سکوئرز استعمال کریں
        damping = 0.01
        J_damped = J.T @ np.linalg.inv(J @ J.T + damping**2 * np.eye(6))
        dq = J_damped @ error

        # جوائنٹ اینگلز اپ ڈیٹ کریں
        q += dq

    return q
```

### سنگولیریٹی اینالیسز

سنگولیریٹیز اس وقت ہوتی ہیں جب جیکوبین رینک کھو دیتی ہے، جس سے ڈیگریز آف فریڈم کا نقصان ہوتا ہے۔ کنڈیشن نمبر سنگولیریٹی کے قریب ہونے کا اشارہ کرتا ہے:

**کنڈیشن نمبر**: κ(J) = ||J|| ||J⁻¹||

```python
def analyze_singularities(jacobian, threshold=1000):
    """
    روبوٹ سنگولیریٹی کنڈیشنز کا تجزیہ کریں
    """
    condition_number = np.linalg.cond(jacobian)
    is_singular = condition_number > threshold

    return {
        'condition_number': condition_number,
        'is_singular': is_singular,
        'rank': np.linalg.matrix_rank(jacobian)
    }
```

## روبوٹ ڈائنامکس

### لاگرینجین فارمولیشن

روبوٹ ڈائنامکس کو لاگرینجین اپروچ کا استعمال کرکے ظاہر کیا جا سکتا ہے:

**کائینیٹک انرجی**: T = ½ q̇ᵀ M(q) q̇
**پوٹینشل انرجی**: V = V(q)

**لاگرینجین**: L = T - V

موشن کے ایکویشنز آئلر-لاگرینج ایکویشنز کے ذریعے دیے گئے ہیں:

```
d/dt(∂L/∂q̇) - ∂L/∂q = τ
```

یہ جنرل فارم میں نتیجہ دیتا ہے:

```
M(q)q̈ + C(q, q̇)q̇ + G(q) = τ
```

جہاں:
- M(q): انیرشیا میٹرکس
- C(q, q̇): کوریولس اور سینٹریفوگل فورسز
- G(q): گریویٹی فورسز
- τ: جوائنٹ ٹورکس

### نیوٹن-ایولر فارمولیشن

ریکر سیو نیوٹن-ایولر الگورتھم انورس ڈائنامکس کے موثر کمپیوٹیشن کا طریقہ فراہم کرتا ہے:

```python
def newton_euler_inverse_dynamics(q, qdot, qddot, robot_params):
    """
    ریکر سیو نیوٹن-ایولر انورس ڈائنامکس الگورتھم
    """
    n = len(q)  # جوائنٹس کی تعداد

    # لنک پیرامیٹرز کو شروع کریں
    v = [np.zeros(6) for _ in range(n)]  # سپیشل ویلوسیٹیز
    a = [np.zeros(6) for _ in range(n)]  # سپیشل ایکسیلریشنز
    f = [np.zeros(6) for _ in range(n)]  # سپیشل فورسز
    tau = np.zeros(n)  # جوائنٹ ٹورکس

        pass

    # بیک ورڈ ریکرشن: فورسز اور ٹورکس کا حساب لگائیں
    for i in range(n-1, -1, -1):
        # لنک ماسز، انیرشیاز، اور بیرونی فورسز کی بنیاد پر فورسز کا حساب لگائیں
        # سپیشل فورسز سے جوائنٹ ٹورکس کا حساب لگائیں
        pass

    return tau
```

## کنٹرول تھیوری میں روبوٹکس

### فیڈ فارورڈ کے ساتھ PID کنٹرول

بہتر کارکردگی کے لیے فیڈ فارورڈ ٹرمس کے ساتھ بہتر PID:

```python
class AdvancedPIDController:
    def __init__(self, kp, ki, kd, feedforward_gain=1.0):
        self.kp = kp
        self.ki = ki
        self.kd = kd
        self.kf = feedforward_gain
        self.integral = 0
        self.previous_error = 0

    def update(self, target, current, target_derivative=0, dt=0.001):
        error = target - current
        self.integral += error * dt
        derivative = (error - self.previous_error) / dt

        # PID کے ساتھ فیڈ فارورڈ
        output = (self.kp * error +
                 self.ki * self.integral +
                 self.kd * derivative +
                 self.kf * target_derivative)

        self.previous_error = error
        return output
```

### کمپیوٹڈ ٹورک کنٹرول

سٹیک ٹریجکٹری فالو کرنے کے لیے روبوٹ ڈائنامکس کو لینئرائز کرتا ہے:

```python
class ComputedTorqueController:
    def __init__(self, robot_model):
        self.model = robot_model
        self.kp = np.eye(robot_model.dof) * 100  # پوزیشن گینز
        self.kd = np.eye(robot_model.dof) * 20   # ویلوسیٹی گینز

    def compute_control(self, q_desired, qd_desired, qdd_desired,
                       q_current, qd_current):
        """
        کمپیوٹڈ ٹورک کنٹرول لا: τ = M(q)(qdd_d + Kp*e + Kd*ed) + C(q,qd)qd + g(q)
        """
        # ایرر کا حساب لگائیں
        pos_error = q_desired - q_current
        vel_error = qd_desired - qd_current

        # فیڈ بیک کریکشن کے ساتھ مطلوبہ ایکسیلریشن
        qdd_feedforward = (qdd_desired +
                          self.kp @ pos_error +
                          self.kd @ vel_error)

        # انورس ڈائنامکس
        M = self.model.mass_matrix(q_current)
        C = self.model.coriolis_matrix(q_current, qd_current)
        G = self.model.gravity_vector(q_current)

        # کنٹرول لا
        tau = M @ qdd_feedforward + C @ qd_current + G

        return tau
```

## سینسر انٹیگریشن اور سٹیٹ اسٹیمیشن

### ایکسٹینڈڈ کیلمین فلٹر

غیر لکیری سسٹم کے لیے نوائزی پیمائشات کے ساتھ:

```python
class ExtendedKalmanFilter:
    def __init__(self, state_dim, control_dim, measurement_dim):
        self.n = state_dim
        self.m = measurement_dim

        # کوواریئنس میٹرکسز کو شروع کریں
        self.P = np.eye(state_dim) * 10  # سٹیٹ کوواریئنس
        self.Q = np.eye(state_dim) * 0.1  # پروسیس نوائز
        self.R = np.eye(measurement_dim) * 1  # میزورمنٹ نوائز

    def predict(self, x, u, dt):
        """پریڈکٹ اسٹیپ: x_k = f(x_{k-1}, u_k)"""
        # پروسیس ماڈل کا جیکوبین
        F = self.compute_jacobian_f(x, u)

        # سٹیٹ کی پریڈکٹ کریں
        x_pred = self.process_model(x, u, dt)

        # کوواریئنس کی پریڈکٹ کریں
        self.P = F @ self.P @ F.T + self.Q

        return x_pred

    def update(self, x_pred, z):
        """اپ ڈیٹ اسٹیپ: میزورمنٹ z کو شامل کریں"""
        # میزورمنٹ جیکوبین
        H = self.compute_jacobian_h(x_pred)

        # اینویشن کوواریئنس
        S = H @ self.P @ H.T + self.R

        # کیلمین گین
        K = self.P @ H.T @ np.linalg.inv(S)

        # اینویشن
        y = z - self.measurement_model(x_pred)

        # سٹیٹ کو اپ ڈیٹ کریں
        x_updated = x_pred + K @ y

        # کوواریئنس کو اپ ڈیٹ کریں
        I = np.eye(len(x_updated))
        self.P = (I - K @ H) @ self.P

        return x_updated
```

## ایڈوانسڈ ایکچویٹر ماڈلز

### گیئر باکس کے ساتھ DC موٹر

ٹرانسمیشن کے ساتھ الیکٹرک ایکچویٹر کا تفصیلی ماڈل:

```python
class DCMotorWithGearbox:
    def __init__(self, motor_params, gear_ratio, efficiency):
        """
        motor_params: R, L, J, B, Kt, Ke کے ساتھ ڈکٹ
        gear_ratio: آؤٹ پٹ/ان پٹ اسپیڈ ریشیو
        efficiency: مکینیکل کارکردگی کا گیئر باکس
        """
        self.motor = DCMotorModel(**motor_params)
        self.gear_ratio = gear_ratio
        self.efficiency = efficiency

    def electrical_dynamics(self, v, i, omega_load):
        """گیئر باکس کے ذریعے لوڈ کو دیکھتے ہوئے الیکٹریکل ڈائنامکس"""
        omega_motor = self.gear_ratio * omega_load
        return self.motor.electrical_dynamics(v, i, omega_motor)

    def mechanical_output(self, i, omega_load, load_torque=0):
        """آؤٹ پٹ ٹورک اور ایکسیلریشن کمپیوٹ کریں"""
        motor_torque = self.motor.Kt * i
        reflected_load = load_torque / (self.gear_ratio * self.efficiency)
        net_torque = motor_torque - reflected_load

        # موٹر ایکسیلریشن
        motor_acc = (net_torque - self.motor.B * self.gear_ratio * omega_load) / self.motor.J
        # لوڈ ایکسیلریشن
        load_acc = self.gear_ratio * motor_acc

        return {
            'output_torque': net_torque * self.gear_ratio * self.efficiency,
            'load_acceleration': load_acc
        }
```

### ROS2 نوڈ امپلیمنٹیشن

```python
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import JointState
from control_msgs.msg import JointTrajectoryControllerState
from trajectory_msgs.msg import JointTrajectory, JointTrajectoryPoint
from builtin_interfaces.msg import Duration

class AdvancedRobotController(Node):
    def __init__(self):
        super().__init__('advanced_robot_controller')

        # پبلشرز اور سبسکرائبرز
        self.joint_state_sub = self.create_subscription(
            JointState, 'joint_states', self.joint_state_callback, 10)

        self.trajectory_sub = self.create_subscription(
            JointTrajectory, 'joint_trajectory', self.trajectory_callback, 10)

        self.controller_state_pub = self.create_publisher(
            JointTrajectoryControllerState, 'controller_state', 10)

        # کنٹرول ٹائمر
        self.timer = self.create_timer(0.001, self.control_loop)  # 1kHz

        # انٹرنل سٹیٹ
        self.current_joint_positions = None
        self.current_joint_velocities = None
        self.desired_trajectory = None
        self.trajectory_index = 0
        self.controller = ComputedTorqueController(robot_model)

    def joint_state_callback(self, msg):
        """ان کمنگ جوائنٹ اسٹیٹ میسیجز کو پروسیس کریں"""
        self.current_joint_positions = np.array(msg.position)
        self.current_joint_velocities = np.array(msg.velocity)

    def trajectory_callback(self, msg):
        """ان کمنگ ٹریجکٹری کمانڈز کو پروسیس کریں"""
        self.desired_trajectory = msg
        self.trajectory_index = 0

    def control_loop(self):
        """مین کنٹرول لوپ جو 1kHz پر چل رہا ہے"""
        if (self.current_joint_positions is not None and
            self.current_joint_velocities is not None):

            # ٹریجکٹری سے مطلوبہ حالت حاصل کریں
            if self.desired_trajectory and self.trajectory_index < len(self.desired_trajectory.points):
                desired_point = self.desired_trajectory.points[self.trajectory_index]
                q_desired = np.array(desired_point.positions)
                qd_desired = np.array(desired_point.velocities)
                qdd_desired = np.array(desired_point.accelerations)

                # کنٹرول ٹورکس کمپیوٹ کریں
                torques = self.controller.compute_control(
                    q_desired, qd_desired, qdd_desired,
                    self.current_joint_positions, self.current_joint_velocities)

                # کنٹرولر اسٹیٹ پبلش کریں
                controller_state = JointTrajectoryControllerState()
                controller_state.joint_names = self.desired_trajectory.joint_names
                controller_state.actual.positions = self.current_joint_positions.tolist()
                controller_state.desired.positions = q_desired.tolist()
                self.controller_state_pub.publish(controller_state)

                # ٹریجکٹری انڈیکس میں اضافہ کریں
                self.trajectory_index += 1
```

## سیفٹی اور ویریفکیشن

### فارمل ویریفکیشن میتھڈس

```python
def verify_robot_safety(trajectory, robot_model, environment):
    """
    سیفٹی پراپرٹیز کی فارمل ویریفکیشن
    """
    # کولیژن فری پاتھ چیک کریں
    for t in trajectory:
        robot_pose = robot_model.forward_kinematics(t.joint_angles)
        if check_collision(robot_pose, environment):
            return False, "کولیژن ڈیٹیکٹ ہو گئی"

    # جوائنٹ لیمٹس چیک کریں
    for q in trajectory:
        if not robot_model.check_joint_limits(q):
            return False, "جوائنٹ لیمٹ ویولیشن"

    # ڈائنامک کنٹرینٹس چیک کریں
    for i in range(1, len(trajectory)):
        q1, q2 = trajectory[i-1], trajectory[i]
        dt = q2.time - q1.time
        vel = (q2.joint_angles - q1.joint_angles) / dt
        if np.any(np.abs(vel) > robot_model.max_velocities):
            return False, "ویلوسیٹی لیمٹ ویولیشن"

    return True, "ٹریجکٹری محفوظ ہے"
```

## کلیدی نکات

- روبوٹکس کو لکیری الجبرا اور کیلکولس جیسی مضبوط ریاضیاتی بنیادوں کی ضرورت ہوتی ہے
- کنیمیٹکس، ڈائنامکس، اور کنٹرول ایک دوسرے سے جڑے ہوئے مضامین ہیں
- ایڈوانسڈ کنٹرول ٹیکنیکس ہائی پرفارمنس روبوٹک سسٹم کو فعال کرتی ہیں
- سینسر فیوژن اور سٹیٹ اسٹیمیشن اصل دنیا کے کام کے لیے اہم ہے
- سیفٹی اور ویریفکیشن عملی ڈپلائمنٹ کے لیے ضروری ہے
- جدید روبوٹکس کلاسیکل طریقوں کو مشین لرننگ کے ساتھ ضم کرتا ہے
