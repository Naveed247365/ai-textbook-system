# Robot Dynamics

In this subchapter, we'll explore the fundamental principles of robot dynamics - the study of forces and torques required to create motion in robotic systems. Understanding dynamics is crucial for designing controllers that can accurately move robots and interact with their environment.

## Introduction to Robot Dynamics

Robot dynamics is the study of the relationship between forces acting on a robot mechanism and the accelerations they produce. While kinematics describes the geometric aspects of motion (position, velocity, acceleration), dynamics considers the forces and torques that cause these motions.

The fundamental equation of robot dynamics is:

**M(q)q̈ + C(q, q̇)q̇ + G(q) = τ**

Where:
- M(q) is the mass/inertia matrix
- C(q, q̇)q̇ represents Coriolis and centrifugal forces
- G(q) represents gravitational forces
- τ represents applied joint torques
- q, q̇, q̈ are joint positions, velocities, and accelerations respectively

This equation is essential for:
- Robot control design
- Trajectory planning
- Simulation
- Force control applications

## Rigid Body Dynamics

Rigid body dynamics forms the foundation for understanding how individual links of a robot move under applied forces. A rigid body is an idealized solid object that does not deform under applied forces.

### Newton-Euler Equations

For a rigid body, the motion is governed by Newton's second law for translation and Euler's equation for rotation:

**Translation:** F = ma
**Rotation:** τ = Iα + ω × (Iω)

Where F is force, m is mass, a is linear acceleration, τ is torque, I is the inertia tensor, α is angular acceleration, and ω is angular velocity.

```python
import numpy as np

class RigidBody:
    def __init__(self, mass, inertia_tensor, position=[0,0,0], orientation=[0,0,0]):
        self.mass = mass  # Mass in kg
        self.inertia_tensor = np.array(inertia_tensor)  # 3x3 inertia tensor
        self.position = np.array(position, dtype=float)  # Position vector
        self.orientation = np.array(orientation, dtype=float)  # Orientation angles
        self.velocity = np.zeros(3)  # Linear velocity
        self.angular_velocity = np.zeros(3)  # Angular velocity

    def update_motion(self, forces, torques, dt):
        """Update position and orientation based on applied forces and torques"""
        # Calculate linear acceleration (F = ma)
        linear_acceleration = np.array(forces) / self.mass

        # Update velocity and position
        self.velocity += linear_acceleration * dt
        self.position += self.velocity * dt

        # Calculate angular acceleration (τ = Iα + ω × (Iω))
        # For simplicity, we'll ignore the cross-product term in this example
        # A full implementation would require quaternion rotation for accurate orientation
        angular_acceleration = np.linalg.solve(self.inertia_tensor, torques)

        # Update angular velocity and orientation
        self.angular_velocity += angular_acceleration * dt
        self.orientation += self.angular_velocity * dt

        return self.position, self.orientation
```

### Center of Mass and Moment of Inertia

The center of mass is the point where the total mass of the body can be considered to be concentrated. The moment of inertia quantifies an object's resistance to rotational motion about a particular axis.

For a system of particles:
- Center of mass: R_cm = Σ(m_i * r_i) / Σ(m_i)
- Moment of inertia: I = Σ(m_i * r_i^2) for rotation about an axis

## Lagrangian Formulation

The Lagrangian formulation provides a systematic approach to deriving equations of motion for complex mechanical systems. It's based on the difference between kinetic and potential energy.

### The Lagrangian

The Lagrangian L is defined as:
**L = T - V**

Where T is the total kinetic energy and V is the total potential energy of the system.

### Lagrange's Equation

For a system with n degrees of freedom:
**d/dt(∂L/∂q̇_i) - ∂L/∂q_i = Q_i**

Where q_i are the generalized coordinates, Q_i are the generalized forces (including applied forces and constraint forces).

```python

        return tau

### Advantages of Lagrangian Method

1. **Systematic**: Provides a consistent approach for complex systems
2. **Coordinate-invariant**: Can use any set of generalized coordinates
3. **Conservative**: Naturally handles conservative forces through potential energy
4. **Scalable**: Works well for systems with many degrees of freedom

## Newton-Euler Formulation

The Newton-Euler formulation is an alternative approach that directly applies Newton's and Euler's laws to each link of a robot. It's computationally efficient, especially for recursive algorithms.

### Recursive Newton-Euler Algorithm

The algorithm works in two passes:
1. **Outward pass**: Calculate velocities and accelerations from base to tip
2. **Inward pass**: Calculate forces and torques from tip to base

class PlanarRobotDynamics:
    def __init__(self, link1_mass, link2_mass, link1_length, link2_length):
        self.m1 = link1_mass
        self.m2 = link2_mass
        self.l1 = link1_length  # Length of link 1
        self.l2 = link2_length  # Length of link 2

    def mass_matrix(self, q1, q2):
        """Calculate the 2x2 mass matrix for a 2-DOF planar robot"""
        # For a 2-DOF planar robot, the mass matrix is:
        # M = [[m11, m12], [m21, m22]]
        # where the elements depend on the joint angles

        m11 = (self.m1 + self.m2) * self.l1**2 + self.m2 * self.l2**2 + \
              2 * self.m2 * self.l1 * self.l2 * np.cos(q2)

        m12 = self.m2 * self.l2**2 + self.m2 * self.l1 * self.l2 * np.cos(q2)

        m21 = m12  # Symmetric matrix

        m22 = self.m2 * self.l2**2

        return np.array([[m11, m12], [m21, m22]])

    def coriolis_matrix(self, q1, q2, q1_dot, q2_dot):
        """Calculate the Coriolis matrix for a 2-DOF planar robot"""
        c1 = -self.m2 * self.l1 * self.l2 * np.sin(q2) * (2*q1_dot + q2_dot)
        c2 = self.m2 * self.l1 * self.l2 * np.sin(q2) * q1_dot

        return np.array([[0, c1], [0, c2]])

    def gravity_vector(self, q1, q2):
        """Calculate the gravity vector for a 2-DOF planar robot"""
        g = 9.81  # gravitational acceleration

        g1 = -(self.m1 + self.m2) * g * self.l1 * np.sin(q1) - \
              self.m2 * g * self.l2 * np.sin(q1 + q2)

        g2 = -self.m2 * g * self.l2 * np.sin(q1 + q2)

        return np.array([g1, g2])

    def inverse_dynamics(self, q, q_dot, q_ddot):
        """Calculate required torques for desired motion"""
        M = self.mass_matrix(q[0], q[1])
        C = self.coriolis_matrix(q[0], q[1], q_dot[0], q_dot[1])
        G = self.gravity_vector(q[0], q[1])

        tau = M @ q_ddot + C @ q_dot + G
        return tau
```

### Computational Efficiency

The Newton-Euler algorithm has O(n) computational complexity, making it highly efficient for robots with many degrees of freedom. This is why it's often preferred in real-time control applications.

## Dynamics of Closed Kinematic Chains

Some robots have closed kinematic chains (e.g., parallel robots, robots with constraints). These require special treatment:

- **Constraint equations**: Additional equations to account for the closed loops
- **Lagrange multipliers**: Used to incorporate constraint forces
- **Index reduction**: Techniques to convert higher-index DAEs to lower-index ones

## Practical Considerations

### Friction Modeling

Real robots experience friction, which significantly affects dynamics:

- **Coulomb friction**: Constant force opposing motion
- **Viscous friction**: Velocity-dependent damping
- **Static friction**: Prevents motion until threshold is exceeded

```python
def friction_model(q_dot, coulomb_friction=1.0, viscous_friction=0.1):
    """Simple friction model"""
    # Signum function for Coulomb friction
    coulomb = np.sign(q_dot) * coulomb_friction
    # Linear velocity damping
    viscous = viscous_friction * q_dot
    return coulomb + viscous
```

### Parameter Identification

Accurate dynamic models require precise knowledge of robot parameters (masses, inertias, etc.):

- **Offline identification**: Using experimental data to estimate parameters
- **Online adaptation**: Adjusting parameters during operation
- **Persistence of excitation**: Ensuring trajectories excite all dynamic modes

## Applications of Robot Dynamics

1. **Model-based control**: Using dynamic models for feedforward control
2. **Trajectory optimization**: Finding energy-efficient paths
3. **Simulation**: Predicting robot behavior in virtual environments
4. **Force control**: Controlling interaction forces with the environment
5. **Safety**: Predicting and limiting forces/torques to prevent damage

## Summary

Robot dynamics provides the mathematical foundation for understanding how forces and torques affect robot motion. The fundamental equation M(q)q̈ + C(q, q̇)q̇ + G(q) = τ describes the relationship between applied torques and resulting motion. Two main approaches exist for deriving these equations: the Lagrangian method (systematic, energy-based) and the Newton-Euler method (efficient, force-based). Understanding these dynamics is essential for effective robot control and simulation.
